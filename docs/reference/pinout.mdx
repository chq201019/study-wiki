## ⚠️ 禁止使用

| 引脚 | 原因 |
| --- | --- |
| **GPIO35 / 36 / 37** | WROOM-1 的 Octal Flash/PSRAM 占用，**接了会损坏固件甚至变砖** |
| GPIO19 / 20 | 用原生 USB 时被占用（不用 USB 时可用） |
| GPIO43 / 44 | UART0 调试口，占用后看不到日志 |
| GPIO0 | 复位时被采样，接模块可能导致意外进下载模式 |
| GPIO45 | 决定 Flash 电压，选错会开不了机 |
| GPIO46 | strapping 脚，复位瞬间被采样，外设慎接 |

![ESP32-S3 引脚能力分区：先认禁区再排外设——GPIO35/36/37 被 Octal Flash 与 PSRAM 占用、接了会写坏固件甚至变砖，GPIO33/34 模组内部建议避开，GPIO19/20 用原生 USB 时被占用，GPIO43/44 是 UART0 调试口，GPIO0/3/45/46 是复位瞬间被采样的 strapping 脚；ADC1 在 GPIO1～10、ADC2 在 GPIO11～20，剩下的（GPIO1～18 等）才是自由引脚；S3 没有任何仅输出脚](/img/diagrams/esp32-pin-capability-map.svg)

## 深睡眠可唤醒引脚

Deep Sleep 时**只有 RTC 域 GPIO0～GPIO21 能作为唤醒源**。想用 GPIO22 以上唤醒，只能用 `esp_sleep_enable_ext1_wakeup()` 配合 RTC IO，或改用 Light Sleep。

## RGB LED 版本差异

| 板子版本 | RGB LED |
| --- | --- |
| ESP32-S3-DevKitC-1 **v1.0**（首批） | **GPIO48** |
| ESP32-S3-DevKitC-1 **v1.1** | **GPIO38** |

不确定时两个都写上，或看板上丝印或日期。

## 常用引脚规划建议

| 功能 | 推荐引脚 | 理由 |
| --- | --- | --- |
| I2C | 8 / 9 | Arduino 默认值，也是 S3 的 FSPIHD/FSPIHD 外设脚但平时空着 |
| SPI | 12 / 11 / 13 / 10 | Arduino 默认值（FSPI 完整一组） |
| 备用 UART | 16(TX) / 17(RX) | 没有额外外设功能冲突（S3 没有 DAC，别按老教程避开 25/26） |
| ADC（只用 ADC1） | 1～10 | **WiFi 开启时 ADC2 不可用** |
| 触摸 | 1～14 | |
| LED | 4 / 5 | |

| 模块 | 电源 | 信号 |
| --- | --- | --- |
| SSD1306 OLED | 3V3 | SDA→8, SCL→9 |
| DHT11/22 | 3V3 | DATA→任意 + 4.7kΩ 上拉 |

| 舵机 | **独立 5V** | 信号→任意 |

## 查芯片实际信息

```bash
# Flash 大小、MAC 地址、芯片型号
esptool.py --chip esp32s3 --port COM5 flash_id
```

**模块型号命名规则**：`ESP32-S3-WROOM-1-N16R8` = N16R8 表示 16MB Flash + 8MB PSRAM。
