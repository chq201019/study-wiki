## 全站通用约定

| 项 | 值 |
| --- | --- |
| 芯片 | ESP32-S3-WROOM-1 |
| 调试串口 | GPIO43(TX) / GPIO44(RX)，115200 8N1 |
| Arduino 核心 | arduino-esp32 3.3.x |
| ESP-IDF | v5.5.x |
| **禁止使用** | **GPIO35 / GPIO36 / GPIO37**（Flash/PSRAM 占用） |
| 深度睡眠可唤醒引脚 | GPIO0～GPIO21（RTC 域） |
