# 库与版本清单

## 1. 版本基线

| 项 | 本教程采用 | 说明 |
| --- | --- | --- |
| **ESP-IDF** | **v5.5.x** | 本教程锁定此基线；6.x 已发布（stable 已到 6.1），尚未迁移 |
| **arduino-esp32** | **3.3.x** | 基于 IDF 5.5.x |
| 硬件 | ESP32-S3-WROOM-1-N16R8 | 16MB Flash / 8MB PSRAM |

**IDF 5.2 → 5.3 → 5.4 → 5.5 之间 API 有变动**（主要是 I2C/SPI 新驱动、ADC oneshot），跨大版本抄代码要先核对 API。

## 5. 版本锁定

### IDF 项目

```bash
idf.py add-dependency "组件名@版本"
idf.py fullclean          # 依赖变化后必须
```

`dependencies.lock` 记录所有组件的确切版本，**必须提交到 git**。

### Arduino 项目

`platform.txt` 或开发板管理器里固定版本号。团队协作时在 `README` 里写清：

```
开发板：esp32:esp32:esp32s3
核心版本：3.3.11
分区方案：16MB with spiffs
```

### 配图钉死的做法

用 `arduino-cli` 把核心文件锁进 git：

```bash
arduino-cli core install esp32:esp32@3.3.11
arduino-cli lib install "Adafruit SSD1306@2.5.13"
arduino-cli compile --fqbn esp32:esp32:esp32s3 --libraries . .
```

## 6. 跨版本迁移

从旧版本 IDF 迁到 5.5：

| 变化 | 处理 |
| --- | --- |
| `driver/i2c.h` → `driver/i2c_master.h` | 重写 I2C 代码 |
| `driver/spi.h` → `driver/spi_master.h` | 重写 SPI 代码 |
| `adc.h` → `esp_adc/adc_oneshot.h` | 重写 ADC 代码 |
| `esp_wifi.h` 的事件 API | 基本兼容 |
| `esp_ota_ops.h` | 基本兼容 |
| `nvs_flash_init` 行为 | 更严格，建议检查返回值 |
| 分区表默认变化 | 检查 partitions.csv |

**升级后第一件事**：跑一遍所有单元测试和外设自检，别直接上项目。
