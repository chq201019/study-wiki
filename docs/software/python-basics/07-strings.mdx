# 07 字符串入门

**本课目标**：会创建字符串、能做切片，熟练使用 8 个最常用的字符串方法。

## 怎么创建字符串

```python
a = "双引号可以"
b = '单引号也可以'
c = """三个引号
可以跨行
"""
print(a)
print(b)
print(c)
```

输出：

```text
双引号可以
单引号也可以
三个引号
可以跨行
```

:::tip[单引号还是双引号？]
Python 两种都行，效果完全一样。**选一种坚持用**就行（团队规范通常用双引号）。

唯一要分开的场景：字符串里有引号。

```python
print("他说'你好'")        # 用双引号包，里面放单引号
print('他说"你好"')        # 用单引号包，里面放双引号
```
:::

## 转义字符

有些字符没法直接打出来（比如换行），要用**反斜杠加字母**表示：

| 写法 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 制表符（Tab） |
| `\\` | 一个反斜杠本身 |
| `\'` | 单引号 |
| `\"` | 双引号 |

```python
print("第一行\n第二行")
print("姓名\t年龄")
print("路径：D:\\code\\python")
```

输出：

```text
第一行
第二行
姓名	年龄
路径：D:\code\python
```

:::warning[Windows 路径的坑]
```python
print("D:\code\new")     # \n 被当成换行了！
```

会输出：

```text
D:\code
ew
```

**两种解法**：用 `\\` 转义，或者用**原始字符串**在引号前加 `r`：

```python
print(r"D:\code\new")
```

输出：

```text
D:\code\new
```

`r` 表示「原样输出，不处理转义」。**写路径、写正则时都该用 `r""`**。
:::

## 拼接与重复

```python
first = "张"
last = "三"
print(first + last)       # 张三
print("=" * 30)           # 等号重复 30 次
print("ab" * 3)           # ababab
```

:::warning[不要把字符串和数字直接相加]
```python
age = 18
print("年龄：" + age)      # TypeError
```

必须转换：

```python
print("年龄：" + str(age))
```

更推荐用 f-string（见下），自动帮你转换。
:::

## f-string：最好用的格式化（必学）

在引号前加 `f`，然后用 `{}` 嵌变量：

```python
name = "小明"
age = 18
score = 95.678

print(f"我叫{name}，今年{age}岁")
print(f"成绩：{score}")
print(f"成绩保留两位：{score:.2f}")
print(f"计算：{age * 2}")
print(f"直接调函数：{name.upper()}")
```

输出：

```text
我叫小明，今年18岁
成绩：95.678
成绩保留两位：95.68
计算：36
直接调函数：小明
```

:::tip[`{}` 里能写任何表达式]
不只是变量，还能写运算、函数调用：

```python
print(f"1+1={1+1}")                # 1+1=2
print(f"{'大写'.upper()}")          # 大写
print(f"{3.14159:.2f}")            # 3.14
```

**这是 Python 3.6+ 最推荐的格式化方式**，比旧的 `%` 和 `.format()` 都清晰。
:::

### 对齐与补零

```python
print(f"|{'名字':<8}|{'分数':>6}|")
print(f"|{'小明':<8}|{95:>6}|")
print(f"|{'张三丰':<8}|{100:>6}|")
print(f"编号 {7:03d}")
```

输出：

```text
|名字      |    分数|
|小明      |    95|
|张三丰    |   100|
编号 007
```

| 格式 | 含义 |
| --- | --- |
| `<8` | 左对齐，占 8 宽 |
| `>6` | 右对齐，占 6 宽 |
| `^10` | 居中，占 10 宽 |
| `:.2f` | 小数保留 2 位 |
| `:03d` | 整数补零到 3 位 |
| `:,` | 千分位分隔 |

## 索引：取出单个字符

```python
s = "Python"
print(s[0])      # P
print(s[3])      # h
print(s[-1])     # n  最后一个
print(s[-2])     # o  倒数第二个
```

:::info[下标从 0 开始]
这与人类习惯不同，但几乎所有编程语言都这样。

**记忆方法**：下标的意思是「距离开头的偏移量」。第 1 个字符偏移 0，第 2 个偏移 1……

负数表示「从末尾倒数」，`-1` 是最后一个。这个设计非常好用。
:::

## 切片：取一段

语法：`变量[起点:终点]`

```python
s = "Python"
print(s[1:4])     # yth    取下标 1、2、3（不含 4）
print(s[:3])      # Pyt    从头开始
print(s[3:])      # hon    到结尾
print(s[:])       # Python 全部
print(s[::2])     # Pto    每 2 个取 1 个
print(s[::-1])    # nohtyP 反转字符串
```

:::warning[切片是「含头不含尾」]
`s[1:4]` 取的是下标 1、2、3，**不包括 4**。

初学者容易以为包括 4。这个设计的理由是：`s[0:5]` 正好取 5 个字符，`s[5:]` 接在后面，分段不会重叠也不会漏掉。
:::

**`s[::-1]` 反转字符串**是 Python 的经典技巧，`-1` 表示倒着走。

## 8 个最常用的字符串方法

```python
s = "  Hello World  "

print(repr(s.strip()))                  # 去两端空格
print(s.strip().upper())                # 全大写
print(s.strip().lower())                # 全小写
print(s.strip().replace("World", "Python"))   # 替换
print("a,b,c".split(","))               # 按分隔符切成列表
print("-".join(["a", "b", "c"]))        # 用分隔符连接成字符串
print(s.strip().startswith("He"))       # 是否以...开头
print(s.strip().endswith("ld"))         # 是否以...结尾
```

输出：

```text
'Hello World'
HELLO WORLD
hello world
Hello Python
['a', 'b', 'c']
a-b-c
True
True
```

### 补充几个高频方法

```python
print("abc".find("z"))          # -1，找不到返回 -1
print("abc".count("a"))         # 1，统计出现次数
print("hello".isalpha())        # True，全是字母吗
print("123".isdigit())          # True，全是数字吗
print("  ".isspace())           # True，全是空白吗
print(repr("  x  ".lstrip()))   # 'x  '，只去左边
print(repr("  x  ".rstrip()))   # '  x'，只去右边
```

| 方法 | 作用 | 注意 |
| --- | --- | --- |
| `strip()` | 去两端空白 | 不改变原字符串（返回新的） |
| `split(sep)` | 切成列表 | 不传参数时按任意空白切 |
| `join(list)` | 列表拼成字符串 | 是「分隔符.join()」，方向别搞反 |
| `find()` | 找子串位置 | 找不到返回 `-1`，不报错 |
| `in` 运算符 | 判断是否包含 | `"ell" in "Hello"` → True |

:::danger[字符串是不可变的]
```python
s = "hello"
s.upper()          # 返回新字符串
print(s)           # 还是 hello！
```

所有字符串方法**都返回新字符串，不改原值**。必须重新赋值：

```python
s = s.upper()
print(s)           # HELLO
```

这是新手最常犯的错：调了 `strip()` 却发现没生效。
:::

## 中文字符串的一个特点

```python
print(len("你好abc"))
print("你好abc"[0])
```

输出：

```text
5
你
```

`len()` 数的是**字符个数**，不是字节数。中文一个字符算 1。这比 C 语言方便得多（C 里一个中文占 3 字节，`strlen` 得到 3）。

## 常见错误

| 代码 | 报错/结果 | 原因 | 正确做法 |
| --- | --- | --- | --- |
| `"abc" + 5` | TypeError | 不能和数字相加 | `"abc" + str(5)` 或 f-string |
| `s.upper()` 后 `print(s)` | 没变化 | 字符串不可变 | `s = s.upper()` |
| `s[100]` | IndexError | 下标越界 | 先 `len(s)` 判断 |
| `"D:\new\test"` | 路径错乱 | `\n` 被转义 | `r"D:\new\test"` |
| `"abc".find("z")` 当异常处理 | 得到 -1 | find 不抛异常 | 用 `in` 判断更清晰 |
| `"-".join("abc")` | `a-b-c`（可用） | 但 `"abc".join("-")` 才常被误写 | 记住是「分隔符.join(序列)」 |
