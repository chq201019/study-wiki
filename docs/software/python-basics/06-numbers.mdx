# 06 数字与运算

**本课目标**：掌握所有算术运算，搞清 `//` 和 `%`，并理解浮点数为什么会有精度问题。

## 两种数字

Python 里最常用的数字有两类：

| 类型 | 说明 | 例子 |
| --- | --- | --- |
| `int` 整数 | 没有小数点的 | `42`、`-7`、`0` |
| `float` 浮点数 | 带小数点的 | `3.14`、`-0.5`、`2.0` |

```python
a = 42
b = 3.14
print(type(a))
print(type(b))
```

输出：

```text
<class 'int'>
<class 'float'>
```

:::tip[Python 的整数没有大小限制]
C、Java 里整数会溢出（超过范围就变成负数）。**Python 不会**——整数想要多大就多大，只受内存限制。

```python
print(2 ** 100)
```

输出：

```text
1267650600228229401496703205376
```

这个特性在算大数时很方便，但对性能敏感的场景要注意：超大整数运算会变慢。
:::

## 四则运算

```python
print(7 + 3)      # 加
print(7 - 3)      # 减
print(7 * 3)      # 乘
print(7 / 3)      # 除
```

输出：

```text
10
4
21
2.3333333333333335
```

:::warning[除法 `/` 永远返回浮点数]
```python
print(10 / 2)      # 5.0，不是 5
print(10 / 5)      # 2.0，不是 2
print(type(10 / 2))  # <class 'float'>
```

就算能整除，结果也是 `float`。要整数结果用 `//`，见下。
:::

## 整除与取余：最容易搞混的两个

### `//` 整除：只要整数部分

```python
print(7 // 3)      # 2
print(7 // 2)      # 3
print(7.5 // 2)    # 3.0
```

### `%` 取余：只要余数

```python
print(7 % 3)       # 1
print(10 % 5)      # 0
print(7 % 2)       # 1
```

两者关系：

```text
7 ÷ 3 = 2 余 1
       ↑     ↑
     7//3  7%3
```

### 取余的三个经典用途

**① 判断奇偶**

```python
n = 7
if n % 2 == 0:
    print(f"{n} 是偶数")
else:
    print(f"{n} 是奇数")
```

输出：

```text
7 是奇数
```

**② 循环取值（每 N 个做一次）**

```python
for i in range(1, 8):
    if i % 3 == 0:
        print(f"{i} 是 3 的倍数")
```

输出：

```text
3 是 3 的倍数
6 是 3 的倍数
```

**③ 拆分时间**

```python
total_seconds = 3725
hours = total_seconds // 3600
minutes = (total_seconds % 3600) // 60
seconds = total_seconds % 60
print(f"{hours} 小时 {minutes} 分 {seconds} 秒")
```

输出：

```text
1 小时 2 分 5 秒
```

:::warning[负数的整除和取余会颠覆你的直觉]
```python
print(-7 // 2)    # -4   不是 -3
print(-7 % 2)     # 1    不是 -1
```

Python 的 `//` 是**向下取整**（往更小的方向），不是「去掉小数部分」。

- `-7 / 2 = -3.5`，向下取整 → `-4`
- 余数满足 `a == (a // b) * b + (a % b)`，所以 `-7 % 2` 必须是 `1`

**这个规则是为了让取余结果永远和除数同号**（`-7 % 2` 和 `7 % 2` 都是 `1`），在算循环下标时更好用。C 语言的规则不同，注意别混。
:::

## 幂运算

```python
print(2 ** 10)      # 1024
print(2 ** 0.5)     # 1.4142135623730951（开平方）
print(9 ** 0.5)     # 3.0
```

`**` 是幂，不是异或（异或是 `^`，但 Python 里 `^` 是按位异或，见 [C 位运算](../c/bitops)）。

## 浮点数的坑：0.1 + 0.2

先看结果：

```python
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
```

输出（本机实测）：

```text
0.30000000000000004
False
```

**这不是 Python 的 bug，是所有语言都有的问题**（C、Java、JavaScript 全都一样）。

### 为什么会这样

:::tip[深入一点：二进制表示不了 0.1]
计算机用二进制存数字。整数能精确表示，但**小数不行**——就像十进制表示不了 1/3（0.3333... 永远写不完）。

`0.1` 在二进制里是无限循环小数，存进 64 位浮点数时被**截断**了。两个被截断的数相加，误差就露出来了。

**第一遍读不懂可以跳过**，记住结论：**浮点数不能用来精确比较相等**。
:::

### 正确做法

**① 比较时用误差范围**

```python
a = 0.1 + 0.2
b = 0.3
print(abs(a - b) < 1e-9)      # True
```

**② 金额用「分」做单位，全用整数**

```python
price_fen = 1999          # 19.99 元
count = 3
total_fen = price_fen * count
print(f"总价 {total_fen / 100:.2f} 元")
```

输出：

```text
总价 59.97 元
```

**③ 需要高精度时用 `decimal` 模块**

```python
from decimal import Decimal

print(Decimal("0.1") + Decimal("0.2"))
```

输出：

```text
0.3
```

:::danger[涉及钱的代码永远不要用 float]
这是编程界最经典的事故来源之一。银行系统、电商结算**一律用整数（以分为单位）或 Decimal**，绝不用 `float`。

差额可能只有几厘钱，但账目对不上就是大问题。
:::

## round() 的舍入规则会出乎意料

```python
print(round(2.5))
print(round(3.5))
print(round(0.5))
print(round(1.5))
```

输出（本机实测）：

```text
2
4
0
2
```

:::warning[Python 3 的 round 是「银行家舍入」]
`round(2.5)` 得到 `2`，不是 `3`。`round(0.5)` 得到 `0`，不是 `1`。

规则是**「四舍六入五成双」**：正好在中间时，往**偶数**方向靠。目的是避免大量数据累加时偏差总是往一个方向偏。

**如果你要的是「四舍五入」**，用：

```python
import math
print(math.floor(x + 0.5))    # 对正数是四舍五入
```

或者用 `decimal` 指定舍入模式。
:::

## 类型转换

```python
print(int("42"))        # 字符串 → 整数
print(int(3.99))        # 浮点 → 整数（截断，不是四舍五入！）
print(float("3.14"))    # 字符串 → 浮点
print(str(42))          # 数字 → 字符串
```

输出：

```text
42
3
3.14
42
```

:::warning[int() 是截断，不是四舍五入]
```python
print(int(3.99))    # 3
print(int(-3.99))   # -3
```

**直接砍掉小数部分**，不管后面是多少。要四舍五入用 `round()`。
:::

## 常见错误

| 错误写法 | 报错 | 原因 | 正确写法 |
| --- | --- | --- | --- |
| `int("3.14")` | ValueError | int 不认识小数点 | `int(float("3.14"))` |
| `"3" + 4` | TypeError | 字符串不能和数字相加 | `int("3") + 4` |
| `1 / 0` | ZeroDivisionError | 除数为零 | 先判断除数 |
| `0.1 + 0.2 == 0.3` | 结果是 False | 浮点精度 | 用误差比较 |
| `round(2.5)` 期望 3 | 得到 2 | 银行家舍入 | 用 math.floor(x+0.5) |
