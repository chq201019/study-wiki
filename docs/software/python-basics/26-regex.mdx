# 26 正则表达式入门

**本课目标**：能用正则从文本里提取需要的信息，看懂常见的正则写法。

## 为什么需要正则

**需求**：从一段文字里找出所有手机号。

```python
text = "联系13800138000或13900139000，备用电话是 010-12345678"
```

用字符串方法试：

```python
# 找一个手机号？得知道它从哪开始、有多长
# 11 位数字？但怎么区分手机号和别的数字？
```

很麻烦。正则专门解决这类「按模式找文本」的问题：

```python
import re

phones = re.findall(r"1[3-9]\d{9}", text)
print(phones)
```

输出（本机实测）：

```text
['13800138000', '13900139000']
```

**一行搞定。**

:::tip[正则是什么]
**正则表达式 = 描述文本模式的语言。**

就像「通配符 `*.txt` 表示所有 txt 文件」，正则能表达更精确的模式：

- `\d{11}` = 11 个数字
- `1[3-9]\d{9}` = 1 开头、第二位 3-9、后面 9 个数字
- `\w+@\w+\.\w+` = 粗略的邮箱格式
:::

## 四个核心函数

```python
import re
```

### ① search：找第一个匹配

```python
text = "日期是 2026-10-18，请记住"

m = re.search(r"\d{4}-\d{2}-\d{2}", text)
if m:
    print(m.group())
```

输出：

```text
2026-10-18
```

找不到时返回 `None`。

### ② findall：找出所有匹配

```python
text = "a1b22c333"
print(re.findall(r"\d+", text))
```

输出：

```text
['1', '22', '333']
```

**返回列表**。有分组时返回元组列表（见下）。

### ③ sub：替换

```python
text = "a   b    c"
print(re.sub(r"\s+", " ", text))
```

输出：

```text
a b c
```

把「一个或多个空白」统一替换成单个空格。

### ④ match：从开头匹配

```python
print(re.match(r"\d+", "123abc"))
print(re.match(r"\d+", "abc123"))
```

输出：

```text
<re.Match object; span=(0, 3), match='123'>
None
```

:::warning[`match` 只从开头匹配]
`re.match(r"\d+", "abc123")` 返回 `None`，因为字符串**不是以数字开头**。

想「在任意位置找」，用 `re.search`。

```python
re.search(r"\d+", "abc123")     # 能找到 123
```
:::

## 必须用原始字符串 r""

:::danger[写正则永远加 `r` 前缀]
```python
# ❌ 危险
re.findall("\d+", text)

# ✅ 正确
re.findall(r"\d+", text)
```

不加 `r` 的话，Python 会先处理字符串转义：`"\d"` 里的 `\d` 不是有效转义，虽然目前能工作，但 `"\b"`、`"\n"`、`"\t"` 会被**真的转义成特殊字符**，导致正则失效。

**规则：正则一律写 `r"..."`。**
:::

## 字符类：匹配什么字符

| 写法 | 含义 | 例子 |
| --- | --- | --- |
| `\d` | 一个数字 | `0-9` |
| `\D` | 非数字 | 除数字外 |
| `\w` | 字母数字下划线 | `a-z A-Z 0-9 _` |
| `\W` | 非单词字符 | 空白、标点 |
| `\s` | 空白（空格/Tab/换行） | —— |
| `\S` | 非空白 | —— |
| `.` | **任意字符**（除换行） | —— |
| `[abc]` | a 或 b 或 c | 自定义集合 |
| `[^abc]` | 不是 a/b/c | 取反 |
| `[a-z]` | 小写字母区间 | 范围 |

```python
print(re.findall(r"\d", "a1b2"))          # ['1', '2']
print(re.findall(r"\w+", "hi there_42!")) # ['hi', 'there_42']
print(re.findall(r"[aeiou]", "hello"))    # ['e', 'o']
print(re.findall(r"[^0-9]", "a1b2"))      # ['a', 'b']
```

:::warning[`.` 不匹配换行]
```python
re.findall(r".", "a\nb")      # ['a', 'b']，没有 \n
```

要匹配包括换行，用 `re.DOTALL` 标志：

```python
re.findall(r".", "a\nb", re.DOTALL)   # ['a', '\n', 'b']
```
:::

## 量词：出现几次

| 写法 | 含义 |
| --- | --- |
| `*` | 0 次或多次 |
| `+` | **1 次或多次** |
| `?` | 0 次或 1 次 |
| `{n}` | 恰好 n 次 |
| `{n,}` | 至少 n 次 |
| `{n,m}` | n 到 m 次 |

```python
print(re.findall(r"\d+", "a1b22c333"))     # ['1', '22', '333']
print(re.findall(r"\d*", "a1b"))           # ['', '1', '']
print(re.findall(r"\d{3}", "1 22 333 4444"))  # ['333', '444']
print(re.findall(r"\d{2,3}", "1 22 333 4444"))  # ['22', '333', '444']
```

:::warning[`*` 会匹配空字符串]
```python
re.findall(r"\d*", "ab")     # ['', '', '']
```

`*` 表示「0 次也可以」，所以在没有数字的地方匹配了空字符串。

**日常用 `+`（至少一次）更符合直觉**，`*` 只在确实允许空的时候用。
:::

## 常用速记：手机号、邮箱、日期

```python
# 中国大陆手机号：1 开头，第二位 3-9，共 11 位
r"1[3-9]\d{9}"

# 粗略邮箱
r"[\w.+-]+@[\w-]+\.[\w.]+"

# 日期 YYYY-MM-DD
r"\d{4}-\d{2}-\d{2}"

# 时间 HH:MM
r"\d{2}:\d{2}"

# 整数（可负）
r"-?\d+"

# 小数
r"-?\d+\.\d+"

# 十六进制颜色 #RRGGBB
r"#[0-9a-fA-F]{6}"
```

实测：

```python
text = "电话13800138000和13900139000，邮箱 a.b@test.com"

print(re.findall(r"1[3-9]\d{9}", text))
print(re.findall(r"[\w.+-]+@[\w-]+\.[\w.]+", text))
```

输出：

```text
['13800138000', '13900139000']
['a.b@test.com']
```

## 分组：提取部分内容

**圆括号 `()` 表示分组**，可以只提取关心的部分。

```python
text = "日期是 2026-10-18"

m = re.search(r"(\d{4})-(\d{2})-(\d{2})", text)
print(m.group(0))     # 整体
print(m.group(1))     # 第一组：年
print(m.group(2))     # 月
print(m.group(3))     # 日
print(m.groups())     # 所有组
```

输出（本机实测）：

```text
2026-10-18
2026
10
18
('2026', '10', '18')
```

:::tip[`group(0)` 是整个匹配]
| 写法 | 得到 |
| --- | --- |
| `group(0)` | 完整匹配的字符串 |
| `group(1)` | 第 1 个括号的内容 |
| `groups()` | 所有括号内容组成的元组 |

**没有括号时 `group(0)` 仍是完整匹配**，只是没有组可取。
:::

### 分组命名（更清晰）

```python
m = re.search(
    r"(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})",
    "2026-10-18"
)
print(m.group("year"), m.group("month"), m.group("day"))
```

输出：

```text
2026 10 18
```

`(?P<名字>...)` 给组起名，比记数字靠得住。

### 非捕获分组

如果只是想用括号「分组」但不要提取，用 `(?:...)`：

```python
re.findall(r"(?:ab)+", "ababab")     # ['ababab']
```

## 贪婪 vs 懒惰

:::danger[这是正则最反直觉的一点]
```python
text = "<a><b>"

print(re.findall(r"<.+>", text))      # ['<a><b>']    ← 贪婪
print(re.findall(r"<.+?>", text))     # ['<a>', '<b>'] ← 懒惰
```

**默认是贪婪的**：`+` 和 `*` 会尽可能匹配更多字符。
:::

| 写法 | 模式 |
| --- | --- |
| `.*` | 贪婪（尽量多） |
| `.*?` | 懒惰（尽量少） |

:::tip[什么时候需要懒惰]
处理 HTML/XML 标签时几乎总是要用懒惰：

```python
html = "<p>第一段</p><p>第二段</p>"

# 贪婪：把所有段落当成一个
re.findall(r"<p>.*</p>", html)    # ['<p>第一段</p><p>第二段</p>']

# 懒惰：正确分开
re.findall(r"<p>.*?</p>", html)   # ['<p>第一段</p>', '<p>第二段</p>']
```

**规律：只要想「匹配到第一个结束符就停」，就加 `?`。**
:::

## 锚点：限定位置

| 写法 | 含义 |
| --- | --- |
| `^` | 字符串开头 |
| `$` | 字符串结尾 |
| `\b` | 单词边界 |

```python
print(bool(re.match(r"^\d+$", "123")))    # True  整个字符串都是数字
print(bool(re.match(r"^\d+$", "12a")))    # False
```

:::tip[`^\d+$` 用来校验「整串都是数字」]
```python
def is_all_digits(s):
    return re.fullmatch(r"\d+", s) is not None
```

或者用 `re.fullmatch`（等价于加了 `^...$`），更简洁。

**注意**：`re.match(r"\d+", "12a")` 会**成功**（匹配到 `12`），因为它只要求开头匹配。校验整个字符串必须用 `^...$` 或 `fullmatch`。
:::

## 编译正则（性能优化）

如果同一个正则会**重复使用**（尤其在循环里），先编译：

```python
import re

PHONE = re.compile(r"1[3-9]\d{9}")

texts = ["电话13800138000", "无", "另一个13900139000"]
for t in texts:
    found = PHONE.findall(t)
    print(found)
```

输出：

```text
['13800138000']
[]
['13900139000']
```

编译后可以反复 `.findall()` / `.search()` / `.sub()`。性能更好，而且正则集中定义便于维护。

## 实战：从日志提取信息

```python
import re

log = """
2026-10-18 14:30:01 INFO  用户登录成功 id=1024
2026-10-18 14:30:15 ERROR 数据库连接失败 code=5001
2026-10-18 14:31:02 WARN  响应超时 耗时=3200ms
"""

pattern = re.compile(
    r"(?P<date>\d{4}-\d{2}-\d{2})\s+"
    r"(?P<time>\d{2}:\d{2}:\d{2})\s+"
    r"(?P<level>INFO|WARN|ERROR)\s+"
    r"(?P<msg>.+)"
)

for m in pattern.finditer(log):
    d = m.groupdict()
    print(f"[{d['level']}] {d['date']} {d['time']} — {d['msg']}")
```

输出：

```text
[INFO] 2026-10-18 14:30:01 — 用户登录成功 id=1024
[ERROR] 2026-10-18 14:30:15 — 数据库连接失败 code=5001
[WARN] 2026-10-18 14:31:02 — 响应超时 耗时=3200ms
```

:::tip[`finditer` 和 `groupdict`]
- `finditer()` 逐个返回 Match 对象（省内存，适合大文本）
- `groupdict()` 把命名分组返回成字典

**这个「命名分组 + groupdict」的组合是解析日志最实用的手法。**
:::

## 常见错误

| 错误 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| 忘了 `r` 前缀 | 正则失效 | 字符串转义 | 加 `r""` |
| `.` 不匹配换行 | 漏内容 | 默认行为 | 加 `re.DOTALL` |
| 贪婪导致匹配过多 | 结果是一大块 | 默认贪婪 | 加 `?` |
| 用 match 找中间内容 | 返回 None | match 只看开头 | 用 `search` |
| `match` 校验整串 | 部分匹配也算成功 | 只校验开头 | 用 `fullmatch` 或 `^...$` |
| 特殊字符没转义 | 语法错或结果错 | `.` `*` `+` `(` 等有特殊含义 | 加 `\` 转义 |
| 正则太复杂 | 无法维护 | —— | 拆分或用字符串方法 |

:::danger[要匹配字面的特殊字符，必须转义]
```python
# 想匹配字面的点
re.findall(r"a.b", "a.b axb")     # ['a.b', 'axb'] ← . 匹配了任意字符

# 转义后
re.findall(r"a\.b", "a.b axb")    # ['a.b']
```

**需要转义的字符**：`. * + ? ( ) [ ] { } ^ $ | \`

提示：想匹配一串特殊字符，可以用 `re.escape()` 自动转义。
:::
