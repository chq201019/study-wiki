# 04 编辑器与第一个项目

**本课目标**：用 VS Code 写出并运行一个正式的项目（而不是散落的单文件）。

## 为什么不用记事本

理论上一行 `print` 写在记事本里也能跑。但编辑器能给你三样东西，缺了会非常痛苦：

| 能力 | 说明 |
| --- | --- |
| **语法高亮** | 关键字变色，一眼看出拼写错误 |
| **自动补全** | 打一半按 Tab，不用记全名 |
| **错误提示** | 少个括号当场红线标出，不用运行才发现 |

## 安装 VS Code

下载 [https://code.visualstudio.com/](https://code.visualstudio.com/) 并安装（免费，跨平台）。

### 装完必做的两件事

**① 安装 Python 扩展**

打开 VS Code，按 `Ctrl+Shift+X`（macOS 是 `Cmd+Shift+X`）打开扩展面板，搜索 `Python`，安装 **Microsoft 官方**那个（下载量最多的）。

这个扩展提供：代码补全、报错提示、一键运行、调试。

**② 选中你的 Python 解释器**

按 `Ctrl+Shift+P` 打开命令面板，输入 `Python: Select Interpreter`，选中你装的 Python 3。

:::danger[这一步最容易漏，漏了会莫名其妙]
如果 VS Code 选中的是别的 Python（或者根本没选），会出现：

- 明明 `pip install` 装了库，代码里却提示找不到模块
- 点运行没反应或报奇怪的错

**排查方法**：看 VS Code 窗口右下角，应该显示 `Python 3.11.x` 之类的字样。点它可以切换。
:::

## 建立项目结构

:::warning[不要把代码散在桌面]
新手习惯在桌面建 `test.py`、`test2.py`、`新建文件夹/test.py`……三天后就找不到东西了。

**从第一天就用规范的目录结构。**
:::

### 建目录

在 `D:\code`（或你喜欢的英文路径）下建一个文件夹，叫 `python-learn`：

```bash
mkdir D:\code\python-learn
cd /d D:\code\python-learn
```

### 在 VS Code 里打开

```bash
code .
```

（如果提示 `code` 不是命令，就在 VS Code 里用「文件 → 打开文件夹」）

:::tip[为什么要在「文件夹」级别打开]
VS Code 打开文件夹后，左侧会显示整个项目结构，终端也会自动定位到这个文件夹。这样运行文件不用来回 `cd`。

**永远打开文件夹，不要只打开单个文件。**
:::

## 第一个正式项目

在项目里建一个文件 `main.py`，内容如下：

```python
"""我的第一个 Python 项目"""

def greet(name: str) -> None:
    """向指定的人打招呼"""
    print(f"你好，{name}！")
    print("欢迎来到 Python 的世界。")


def main() -> None:
    """程序入口"""
    print("=" * 30)
    print("第一个项目 开始运行")
    print("=" * 30)

    greet("同学")

    # 做一点计算
    a, b = 17, 5
    print(f"\n{a} + {b} = {a + b}")
    print(f"{a} ÷ {b} = {a / b}")
    print(f"{a} 除以 {b} 的余数 = {a % b}")

    print("\n程序结束")


if __name__ == "__main__":
    main()
```

运行：

```bash
python main.py
```

输出：

```text
==============================
第一个项目 开始运行
==============================
你好，同学！
欢迎来到 Python 的世界。

17 + 5 = 22
17 ÷ 5 = 3.4
17 除以 5 的余数 = 2

程序结束
```

### 这段代码在讲什么

先别急着全懂，看结构就行：

| 部分 | 作用 |
| --- | --- |
| `def greet(name)` | 定义了一个「函数」，把打招呼的动作打包起来 |
| `f"你好，{name}"` | f-string，把变量的值嵌进字符串 |
| `def main()` | 主函数，程序主要逻辑放这 |
| `if __name__ == "__main__":` | 固定写法，意思是「直接运行这个文件时才执行 main()」 |

:::tip[最后那行固定写法的意义]
`if __name__ == "__main__":` 看着奇怪，但它是 Python 的标准结构。

作用：让这个文件**既能直接运行，又能被别人 import 使用**。如果直接运行，`main()` 会被调用；如果被别人 import，`main()` 不会自动跑。

现在照着写就行，[第 18 课](./18-modules)会讲清楚原理。
:::

## VS Code 的四个实用技巧

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + /` | 注释/取消注释选中的行 |
| `Ctrl + S` | 保存（**养成随手保存的习惯**） |
| `Ctrl + ~` | 打开/关闭终端 |
| `F5` | 调试运行（可以打断点） |

:::danger[改了代码没反应？八成是没保存]
VS Code 里未保存的文件，标签页上有个白点。**不保存就运行，跑的还是旧代码。**

这是新手最经典的自坑：改了半小时代码，一直运行的却是旧版本。

按 `Ctrl + S`，或者开启自动保存（文件 → 自动保存）。
:::

## 目录结构建议

以后内容多了，按这个结构组织：

```text
python-learn/
├── main.py              # 主程序
├── notes/               # 学习笔记
├── exercises/           # 每课的练习题
│   ├── lesson05.py
│   └── lesson06.py
└── projects/            # 小项目
    └── guess_number.py
```

不用一开始就分这么细，但**养成「一个项目一个文件夹」的习惯**，别到处乱放。
