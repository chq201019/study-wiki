# 03 认识终端与运行方式

**本课目标**：会用终端运行 `.py` 文件，知道什么是「当前目录」。

## 终端不是黑魔法

**终端（Terminal）是一个用打字代替点击的窗口。** 你在文件管理器里点击文件夹进入，在终端里是输入 `cd 文件夹名`。两者做的是同一件事。

为什么要学它？因为：

- 程序**必须**在终端里运行和看输出
- 报错信息也出现在终端里
- 装库、跑脚本、管理项目全在终端

:::tip[别怕它]
新手看到黑色窗口就紧张，觉得「一不小心会搞坏电脑」。

实际上：**在终端里敲命令，除了 `rm`/`del` 这类删除命令，其他基本都不会破坏系统。** 输错了顶多报个「命令不存在」。放心试。
:::

## 怎么打开

| 系统 | 方法 |
| --- | --- |
| **Windows** | `Win + R` → 输入 `cmd` → 回车；或在文件夹地址栏输入 `cmd` 回车（会直接定位到该文件夹） |
| **macOS** | `Command + 空格` → 输入 `Terminal` → 回车 |
| **Linux** | `Ctrl + Alt + T`（大多数桌面环境） |

## 最重要的概念：当前目录

终端永远「站在」某个文件夹里，这个文件夹叫**当前工作目录（current directory）**。

**运行 `python 某文件.py` 时，程序是按当前目录去找这个文件的。** 找错了就会报「找不到文件」——这是新手最常遇到的第一个错误。

### 看自己在哪

```bash
# Windows
cd

# macOS / Linux
pwd
```

输出类似 `C:\Users\你的名字` 或 `/home/你的名字`，这就是当前位置。

### 切换位置

```bash
cd D:\code\python
```

```bash
# macOS / Linux
cd ~/code/python
```

### 看当前有哪些文件

```bash
# Windows
dir

# macOS / Linux
ls
```

:::warning[路径里有空格要加引号]
`cd D:\my code` 会失败，因为终端以为你要去 `D:\my` 这个位置。

正确写法：`cd "D:\my code"` —— **加双引号**。

这也是为什么建议项目路径不要带空格。
:::

## 运行 Python 文件的完整流程

假设你在 `D:\code` 下建了一个文件 `hello.py`，内容是：

```python
print("程序开始运行")
print("1 + 1 =", 1 + 1)
```

运行它：

```bash
cd /d D:\code
python hello.py
```

输出：

```text
程序开始运行
1 + 1 = 2
```

:::info[Windows 上 `cd /d` 是什么]
Windows 的 `cd` 只能在同一盘符内切换。要从 C 盘跳到 D 盘，必须加 `/d` 参数：`cd /d D:\code`。

macOS/Linux 没有盘符概念，直接 `cd /path` 就行。
:::

## 必须会的 5 条命令

| 作用 | Windows | macOS / Linux |
| --- | --- | --- |
| 看当前目录 | `cd` | `pwd` |
| 列出文件 | `dir` | `ls` |
| 切换目录 | `cd 路径` | `cd 路径` |
| 返回上一级 | `cd ..` | `cd ..` |
| 清屏 | `cls` | `clear` |

再加三条实用技巧：

```bash
# ↑ 上箭头：调出上一条命令（最省时间的功能）
# Tab 键：自动补全文件名/路径，不用手打全称
# Ctrl + C：强制中断正在运行的程序（卡死时救命）
```

:::tip[Tab 补全是效率神器]
输入 `python hel` 然后按 `Tab`，会自动补成 `python hello.py`（如果只有这一个文件匹配）。

**养成习惯：能按 Tab 就别手打。** 少打错字，效率翻倍。
:::

## 三种运行 Python 的方式

| 方式 | 命令 | 适合 |
| --- | --- | --- |
| 交互模式 | `python` | 快速试验代码片段 |
| 运行文件 | `python 文件名.py` | 写正儿八经的程序 |
| 直接执行表达式 | `python -c "print(1+1)"` | 一行命令验证想法 |

## 常见问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `can't open file 'xxx.py'` | 当前目录不对 | 用 `dir`/`ls` 确认文件在不在这，用 `cd` 切过去 |
| `python: command not found` | PATH 问题 | 见[上一课](./02-install) |
| 中文显示成乱码 | 终端编码问题 | Windows 执行 `chcp 65001` 切到 UTF-8 |
| 按了 `Ctrl+S` 终端卡住 | 终端里 `Ctrl+S` 是「暂停输出」 | 按 `Ctrl+Q` 恢复 |
| 程序卡住不动 | 在等输入或死循环 | `Ctrl+C` 中断 |
