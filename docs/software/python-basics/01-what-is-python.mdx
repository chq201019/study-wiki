# 01 Python 是什么，装哪个版本

**本课目标**：搞清楚 Python 是干什么的，以及你该装哪个版本。不用动手，10 分钟读完。

## Python 是一门「说话」的语言

编程语言的本质是**你用一种人能读的方式，命令电脑做事**。

电脑真正能懂的只有 0 和 1（机器码）。但直接写机器码太痛苦了，所以有人发明了「高级语言」——你写接近英文的句子，再由一个叫**解释器**的程序翻译成机器码。

Python 就是这类语言里**最接近人话**的一个。对比一下同一件事的两种写法：

```text
C 语言（要管内存、要写头文件）：
    #include <stdio.h>
    int main(void) { printf("你好\n"); return 0; }

Python（一行）：
    print("你好")
```

Python 的设计哲学是「**让简单的事保持简单**」。这也是它成为最流行语言之一的原因。

## 它能干什么

不要被「编程」两个字吓到，它其实就是一套自动化工具。真实用途举例：

| 你在做的事 | Python 能帮你做 |
| --- | --- |
| 手动改几百个文件名 | 一个脚本 3 秒改完 |
| 从网页上复制数据到 Excel | 自动抓取并生成表格 |
| 统计一堆 CSV 里的销售数据 | 几行代码算出结论 |
| 控制硬件、读取传感器 | 配合树莓派/ESP32 读取并上报 |
| 训练 AI 模型 | PyTorch、TensorFlow 都是 Python 接口 |

:::info[Python 不擅长什么]
说清楚边界才不会用错工具：

- **极高性能要求的场景**（游戏引擎、操作系统内核）→ 用 C/C++
- **手机 App** → 用 Kotlin/Swift，Python 生态弱
- **前端网页界面** → 用 JavaScript

Python 的定位是「**胶水 + 自动化 + 数据分析 + AI**」。这个定位已经足够覆盖绝大多数需求。
:::

## 版本：只装 3.x，别碰 2.x

Python 有两大版本线：

| 版本 | 状态 |
| --- | --- |
| Python 2 | **2020 年已停止维护**，绝对不要用 |
| **Python 3** | 当前主线，选它 |

网络上有些老教程还在用 Python 2 的写法（比如 `print "你好"` 不带括号），照抄会报错。**看到 `print` 后面没括号的教程，直接关掉。**

### Python 3 内部还要选小版本

Python 3 有很多小版本（3.8、3.9、3.10……）。建议：

| 场景 | 建议版本 |
| --- | --- |
| 新学，没有特殊要求 | **3.11 或 3.12**（稳定、库支持好） |
| 要用最新的语法特性 | 3.13+（但部分第三方库可能没跟上） |
| 学校/公司指定 | 按指定的来 |

:::tip[怎么查你电脑上有没有 Python]
打开终端（Windows 按 `Win+R` 输入 `cmd` 回车），输入：

```bash
python --version
```

如果显示 `Python 3.x.x` 就说明已经有了。如果提示「不是内部或外部命令」，说明没装或没加进 PATH——下一课讲怎么装。
:::

## 装在哪里：这是新手第一个坑

:::danger[路径里不要有中文和空格]
Python 装到含中文或空格的路径下（比如 `C:\Users\张三\我的程序\`），后面安装第三方库时经常莫名失败，而且报错信息完全看不出是路径问题。

**安装时留意安装路径，或者用默认路径就行**，但项目文件不要放在中文目录里。
:::
