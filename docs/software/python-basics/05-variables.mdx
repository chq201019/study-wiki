# 05 变量与赋值

**本课目标**：理解变量是「名字贴在值上」，会正确命名和使用变量。

## 变量就是一个名字

**变量 = 一个存放数据的名字。** 你把值给它，之后用名字就能取回这个值。

```python
age = 18
print(age)
```

输出：

```text
18
```

`age = 18` 念作「把 18 赋给 age」。之后写 `age`，Python 就把 18 拿出来。

## 最重要的一句话：名字指向值

很多人把变量想成「一个盒子，把值装进去」。这个比喻会导致误解。

**更准确的理解是：值在内存里，变量只是贴在值上的一个标签。**

```python
a = 10
b = a          # b 也贴上同一个 10
a = 20         # a 换贴到 20 上，b 没动
print(a, b)
```

输出：

```text
20 10
```

:::tip[为什么这个区别重要]
如果变量是「盒子」，`b = a` 应该是「把 a 盒子里的东西倒进 b 盒子」，那 a 改成 20，b 应该还是 10 —— 结果一样，看不出区别。

但换成列表就看出来了（[第 11 课](./11-list)会展开）：

```python
x = [1, 2, 3]
y = x          # y 和 x 贴在同一个列表上
x.append(4)    # 修改这个列表
print(y)       # [1, 2, 3, 4] —— y 也变了！
```

**因为它们贴的是同一个东西。** 从第一天就建立「标签」而不是「盒子」的心智模型，能避免后面无数的坑。
:::

## 赋值是「先算右边，再贴左边」

```python
x = 5
x = x + 3      # 先算 5 + 3 = 8，再把 8 贴到 x 上
print(x)
```

输出：

```text
8
```

`x = x + 3` 看着像数学方程（无解），但在编程里完全合法：**右边先算出一个新值，再让 x 指向它。**

### 简写形式

```python
x = 10
x += 5    # 等价于 x = x + 5   → 15
x -= 3    # 等价于 x = x - 3   → 12
x *= 2    # 等价于 x = x * 2   → 24
x /= 4    # 等价于 x = x / 4   → 6.0
print(x)
```

输出：

```text
6.0
```

| 写法 | 含义 |
| --- | --- |
| `+=` | 加后赋值 |
| `-=` | 减后赋值 |
| `*=` | 乘后赋值 |
| `/=` | 除后赋值 |
| `//=` | 整除后赋值 |
| `%=` | 取余后赋值 |
| `**=` | 幂后赋值 |

## 一次赋多个值

```python
# 同时赋不同的值
a, b, c = 1, 2, 3
print(a, b, c)

# 同时赋相同的值
x = y = z = 100
print(x, y, z)

# 交换两个变量（一行搞定，不用临时变量）
a, b = b, a
print(a, b)
```

输出：

```text
1 2 3
100 100 100
2 1
```

**最后那个交换是 Python 的特色**。其他语言要写：

```text
临时变量写法（C/Java 等需要这样）：
    temp = a; a = b; b = temp;
```

## 命名规则：必须遵守的

| 规则 | 合法 | 不合法 |
| --- | --- | --- |
| 只能含字母、数字、下划线 | `user_name` | `user-name`（有横线） |
| 不能以数字开头 | `name1` | `1name` |
| 不能是关键字 | `age` | `if`、`for`、`class` |
| 区分大小写 | `Age` 和 `age` 是两个 | —— |

Python 的关键字（不能用作变量名）：

```text
False  None   True   and    as     assert  async   await
break  class  continue def   del    elif    else    except
finally for   from   global if     import  in      is
lambda nonlocal not  or     pass   raise   return  try
while  with   yield
```

## 命名习惯：这些没人强制，但很重要

```python
# 好
user_age = 18
total_price = 99.5
is_valid = True
max_retry_count = 3

# 差（能跑，但别人看不懂，一周后你自己也看不懂）
a = 18
x = 99.5
flag = True
n = 3
```

| 类型 | 惯例 | 例子 |
| --- | --- | --- |
| 变量、函数 | 全小写 + 下划线 | `user_name`、`get_age()` |
| 常量 | 全大写 + 下划线 | `MAX_SIZE`、`PI` |
| 类名 | 每个单词首字母大写 | `StudentInfo` |
| 布尔值 | 用 `is_` / `has_` 开头 | `is_ready`、`has_error` |

:::tip[命名的黄金标准]
**「不用看代码，只看名字就知道它装的是什么」。**

`user_count` 比 `n` 好，`is_logged_in` 比 `flag` 好。多打几个字母，能省下未来几小时的调试时间。
:::

## 查看变量的类型

Python 是**动态类型语言**：变量本身没有类型，值才有。

```python
x = 10
print(type(x))

x = "现在变成字符串了"
print(type(x))
```

输出：

```text
<class 'int'>
<class 'str'>
```

**同一个变量可以先存整数、再存字符串**——因为变量只是标签，换个值就换了个类型。

```python
age = 18
print(type(age))       # <class 'int'>
age = "十八"
print(type(age))       # <class 'str'>
```

:::warning[但这不代表该这么做]
能这么做 ≠ 应该这么做。**同一个变量反复换类型会让代码难以理解**，是坏习惯。

`type()` 的正确用法是**调试时确认数据是什么类型**——尤其是从文件、网络读来的数据，你以为是数字其实是字符串，这类 bug 极难发现。
:::

## 常见错误

### 用了没定义的变量

```python
print(score)
```

输出：

```text
NameError: name 'score' is not defined
```

**解决**：先赋值再用。`NameError` 是最常见的错误之一，看到它就去找「这个变量在哪赋值的」。

### 拼写错误

```python
user_name = "小明"
print(user_nmae)
```

输出：

```text
NameError: name 'user_nmae' is not defined
```

:::tip[大写字母和拼写错误的排查技巧]
`NameError` 有 90% 是两种情况：**拼错了**，或者**大小写不对**（`UserName` vs `username`）。

逐个字母对照赋值那一行，别凭感觉看。
:::
