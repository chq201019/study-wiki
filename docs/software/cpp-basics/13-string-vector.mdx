# 13 std::string 与 std::vector

**本课目标**：用标准库类型替代 C 的 `char[]` 和 `malloc`，不再手管内存。

## 对比：C vs C++

:::danger[C 的写法（[C 第 13/20 课](../c-basics/13-string)）]
```c
char buf[32];
strncpy(buf, src, 31);
buf[31] = '\0';                  /* 忘了就出问题 */

char *arr = malloc(n * sizeof(int));
if (!arr) return -1;
/* ... 用了 ... */
free(arr);                       /* 忘了就泄漏 */
```
:::

**C++ 的写法**：

```cpp
std::string s = src;             /* 自动管长度和内存 */
std::vector<int> arr(n);         /* 自动分配和释放 */
```

**不用管长度、不用管 `\0`、不用 `free`。**

## `std::string` 基础

```cpp
#include <string>

std::string s = "hello";
s += " world";                   /* 直接拼接 */
std::cout << s.size();           /* 11，不含 '\0' */
std::cout << s;                  /* 直接输出 */
```

### 常用操作

```cpp
std::string s = "hello world";

/* 长度 */
s.size();        s.length();          /* 都是 11 */

/* 子串 */
s.substr(0, 5);                       /* "hello" */
s.substr(6);                          /* "world" */

/* 查找 */
s.find("world");                      /* 6 */
s.find("xyz");                        /* std::string::npos（找不到） */

/* 替换 */
s.replace(0, 5, "HI");                /* "HI world" */

/* 比较 */
s == "hello";                         /* 直接比，不用 strcmp */
```

本机实测：

```text
substr=hello
find=6  npos=18446744073709551615
```

:::danger[`find` 找不到返回 `npos`，别当成"随便一个负数"]
```cpp
if (s.find("xyz")) { }               /* ⚠️ 错：6 也是"真"，0 才是"假" */

if (s.find("xyz") != std::string::npos) { }    /* ✅ 正确判断 */
```

`npos` 是 `size_t` 能表示的最大值（`18446744073709551615`），**不是 -1**。

**判断"找到没有"必须和 `npos` 比较。**
:::

### 和 C 字符串互转

```cpp
std::string a = "abc";

const char *c = a.c_str();       /* string → const char* */
std::string b(c);                /* const char* → string */
```

:::warning[`c_str()` 返回的指针别保存]
```cpp
const char *p = s.c_str();
s += "more";                     /* 可能重新分配内存 */
/* p 现在可能指向已释放的内存 */
```

**只在立即使用时有效**（比如传给 `printf`）。
:::

### 遍历

```cpp
std::string s = "abc";

for (char c : s) { }                 /* 按值 */
for (const char &c : s) { }          /* 只读引用 */
for (char &c : s) { c = toupper(c); }  /* 可修改 */
```

## `std::vector` 基础

```cpp
#include <vector>

std::vector<int> v = {1, 2, 3};
v.push_back(4);                  /* 末尾添加 */

std::cout << v.size();           /* 4 */
std::cout << v[0];               /* 1 */
```

### 容量与大小

```cpp
std::vector<int> v;
std::cout << v.size();           /* 当前元素个数 */
std::cout << v.capacity();       /* 当前能装多少不用重新分配 */
```

:::tip[扩容规律：实测翻倍]
本机实测：

```text
  size=1 cap=1
  size=2 cap=2
  size=3 cap=4
  size=5 cap=8
  size=9 cap=16
  size=17 cap=32
```

**容量按 2 倍增长**。这样 `push_back` 的**均摊成本是 O(1)**。

（和 [C 第 30 课](../c-basics/30-project-scores) 手写动态数组的思路完全一样，只是标准库帮你做了。）
:::

### 预留容量

```cpp
std::vector<int> v;
v.reserve(1000);                 /* 一次性预留，避免反复扩容 */
for (int i = 0; i < 1000; i++) v.push_back(i);
```

**知道大概要装多少时，`reserve` 能显著提速。**

### 访问元素

```cpp
std::vector<int> v = {1, 2, 3};

v[0]              /* 不检查越界（快） */
v.at(0)           /* 越界抛 std::out_of_range（安全） */
v.front()         /* 第一个 */
v.back()          /* 最后一个 */
```

:::danger[`[]` 越界不报错，`at()` 会抛异常]
```cpp
v[100]            /* ❌ UB，可能崩溃也可能静默 */
v.at(100)         /* ✅ 抛 std::out_of_range */
```

**和 C 数组一样，`[]` 不检查。**

**调试期用 `at()`，性能敏感的确定位置用 `[]`。**
:::

### 增删

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};

v.push_back(6);                          /* 末尾加 */
v.pop_back();                            /* 删末尾 */
v.insert(v.begin() + 1, 99);             /* 索引1处插入 */
v.erase(v.begin() + 1);                  /* 删索引1 */

v.clear();                               /* 清空（容量不变） */
```

本机实测：

```text
删索引1后: 1 3 4 5
```

:::warning[中间插入/删除是 O(n)]
`insert`/`erase` 在中间时**要把后面的元素全部前移**。

**频繁在中间增删，应该用 `std::list`**（第 17 课对比）。
:::

## 二维数组

```cpp
/* 方式一：vector 的 vector（每行可不等长） */
std::vector<std::vector<int>> m(2, std::vector<int>(3, 7));

/* 方式二：一维模拟（内存连续，更快） */
int rows = 2, cols = 3;
std::vector<int> flat(rows * cols, 0);
/* 访问 flat[r * cols + c] */
```

本机实测：`m[1][2]=7 行数=2 列数=3`

:::tip[两种方式的取舍]
| 方式 | 优点 | 缺点 |
| --- | --- | --- |
| `vector<vector<T>>` | 语法自然 `m[i][j]` | 每行单独分配，内存不连续 |
| 一维模拟 | 内存连续、cache 友好、一次分配 | 要自己算下标 |

**数据量大、性能敏感时用一维模拟**（嵌入式尤其如此）。
:::

## 完整示例

```cpp
#include <iostream>
#include <string>
#include <vector>

int main() {
    /* ---- string ---- */
    std::string text = "Alice,Bob,Carol";

    std::vector<std::string> names;
    size_t start = 0;
    while (true) {
        size_t pos = text.find(',', start);
        if (pos == std::string::npos) {
            names.push_back(text.substr(start));
            break;
        }
        names.push_back(text.substr(start, pos - start));
        start = pos + 1;
    }

    std::cout << "解析出 " << names.size() << " 个名字：\n";
    for (const auto &n : names) {
        std::cout << "  " << n << "\n";
    }

    /* ---- vector ---- */
    std::vector<int> nums;
    nums.reserve(names.size());
    for (size_t i = 0; i < names.size(); i++) {
        nums.push_back(static_cast<int>(names[i].size()));
    }

    int total = 0;
    for (int x : nums) total += x;

    std::cout << "名字总长度：" << total << "\n";
    std::cout << "size=" << nums.size()
              << " capacity=" << nums.capacity() << "\n";

    return 0;
}
```

输出：

```text
解析出 3 个名字：
  Alice
  Bob
  Carol
名字总长度：13
size=3 capacity=3
```

:::tip[注意 `capacity=3`]
因为用了 `reserve(3)`，一次分配到位，**没有发生扩容**。

对比不 reserve 的话，可能 cap 是 4。
:::

## 常见错误

| 错误 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| `find` 结果当布尔用 | 逻辑错 | 0 才是假 | 与 `npos` 比较 |
| `[]` 越界 | UB/崩溃 | 不检查 | 用 `at()` |
| 保存 `c_str()` 指针 | 野指针 | 重新分配后失效 | 立即使用 |
| 循环里 `push_back` 不 reserve | 慢 | 反复扩容 | 预估后 `reserve` |
| 遍历时 `erase` | 崩溃/漏删 | 迭代器失效 | 用 `erase-remove` 惯用法 |
| 中间频繁 `insert` | 慢 | O(n) | 改用 `std::list` |
| `vector<bool>` 当普通容器 | 行为异常 | 特化实现 | 用 `vector<char>` |

:::danger[遍历时不能直接 `erase`]
```cpp
for (auto it = v.begin(); it != v.end(); ++it) {
    if (*it < 0) v.erase(it);        /* ❌ it 失效，++it 崩溃 */
}
```

**正确写法：erase 返回下一个有效迭代器**

```cpp
for (auto it = v.begin(); it != v.end(); ) {
    if (*it < 0) it = v.erase(it);   /* ✅ 用返回值 */
    else ++it;
}
```

或者用 C++20 的 `std::erase_if(v, 谓词)`，一行搞定。
:::
