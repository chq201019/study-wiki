# 03 引用与 const

**本课目标**：掌握引用这个 C++ 独有概念，知道函数参数该怎么传。

## 引用是什么

**引用 = 一个变量的别名。**

```cpp
int n = 42;
int &r = n;          /* r 是 n 的别名 */

r = 99;
std::cout << n;      /* 99 —— 改 r 就是改 n */
```

本机实测：

```text
n=99 (通过引用改)
&n=0x62778ffd78 &r=0x62778ffd78 (同地址)
```

**`&n` 和 `&r` 完全相同**——它们就是同一个东西，两个名字。

## 引用 vs 指针

| | 引用 `int &r` | 指针 `int *p` |
| --- | --- | --- |
| 本质 | 别名（不占额外空间） | 存地址的变量（8 字节） |
| 必须初始化 | ✅ 必须 | ❌ 可以不初始化（但危险） |
| 能改绑 | ❌ 一旦绑定终身不变 | ✅ 可以指向别的 |
| 能否为 null | ❌ 不能 | ✅ 可以 `nullptr` |
| 访问 | 直接用 `r` | 要 `*p` |
| `sizeof` | **被引用类型的大小** | 指针大小（8） |

本机实测 `sizeof`：

```cpp
int n = 5;
int &r = n;
std::cout << sizeof(r);      /* 4 —— 不是 8！ */
```

:::danger[引用不能改绑，这一点最容易误解]
```cpp
int n = 5, m = 10;
int &r = n;

r = m;              /* 你以为让 r 指向 m？错！ */
```

**这是赋值**：把 `m` 的值 10 赋给 `r`（也就是赋给 `n`）。

本机实测：

```text
n=10 m=10          ← n 被改成了 10，m 没变
```

**引用一旦绑定，终身只能指那一个变量。** 想"改绑"只能用指针。
:::

## 引用必须初始化

```cpp
int &r;             /* ❌ 编译错误 */
int &r = n;         /* ✅ 必须立刻绑定 */
```

因为引用是别名，"没有指向谁的别名"没有意义。

## 引用的典型用途

### 用途一：让函数修改实参

```cpp
void add_one(int &x) {
    x++;                    /* 直接改实参 */
}

int main() {
    int n = 5;
    add_one(n);
    std::cout << n;         /* 6 */
}
```

对比 C 要传指针：

```c
void add_one(int *x) { (*x)++; }
add_one(&n);              /* 调用要写 & */
```

:::tip[引用让调用语法更自然]
```cpp
/* C 风格 */
swap(&a, &b);
add_one(&n);

/* C++ 引用风格 */
swap(a, b);
add_one(n);
```

**调用处看不出"会被修改"**，所以命名或注释要说清楚。
:::

### 用途二：避免复制大对象

```cpp
void print(const std::string &s) {      /* 传引用，不复制 */
    std::cout << s;
}

std::string big(1000000, 'x');
print(big);            /* 只传地址，不复制 1MB 数据 */
```

:::danger[不加 `&` 会复制整个对象]
```cpp
void bad(std::string s);        /* 每次调用复制一份字符串 */

std::string big(1000000, 'x');
bad(big);                       /* 复制 1MB！ */
```

**大对象（字符串、vector、结构体）作参数一律传引用。**
:::

## `const` 引用：只读且不复制

```cpp
void print(const std::string &s) {
    std::cout << s;              /* 能读 */
    /* s += "x";   ❌ 不能改 */
}
```

:::tip[`const T &` 是 C++ 最常用的参数形式]
```cpp
void func(const std::string &s);
void func(const std::vector<int> &v);
void func(const MyStruct &obj);
```

**两个好处一次拿到**：

1. **不复制**（性能）
2. **不会意外修改实参**（安全）

**规矩：只读的大对象参数，一律用 `const T &`。**
:::

### `const` 引用能绑定临时值

```cpp
const int &a = 42;                    /* ✅ 可以 */
int &b = 42;                          /* ❌ 不能绑定字面量 */

const std::string &s = std::string("临时");
```

**这是为什么 `print(const std::string &s)` 能接受 `print("hello")` 这样的字面量参数。**

## 什么时候用引用，什么时候用指针

| 场景 | 用哪个 |
| --- | --- |
| 参数要修改实参 | **引用** `T&` |
| 参数只读、对象较大 | **`const T&`** |
| 参数可以是"没有" | **指针**（可以 `nullptr`） |
| 需要改绑指向 | **指针** |
| 需要指针运算 | **指针** |
| 成员变量指向外部对象 | **指针**（引用成员有几个坑） |

:::tip[经验法则]
> **能用引用就用引用，需要"可能为空"或"要改绑"时才用指针。**

C++ 代码里引用的使用频率远高于指针——因为大多数时候你确实有个对象，且不会换。
:::

## 引用作返回值

```cpp
int &at(std::vector<int> &v, size_t i) {
    return v[i];                 /* 返回引用，可读可写 */
}

at(v, 0) = 100;                  /* 直接赋值 */
```

:::danger[不要返回局部变量的引用]
```cpp
int &bad() {
    int x = 42;
    return x;             /* ❌ x 在函数返回时就销毁了 */
}
```

返回的引用指向**已经被回收的栈内存**——和 C 里返回局部变量地址是同一类错误（[C 第 29 课](../c-basics/29-debug)）。

**编译器通常会警告**：

```text
warning: reference to local variable 'x' returned
```

**看到这个警告一定要修。**
:::

## 完整示例

```cpp
#include <iostream>
#include <string>
#include <vector>

/* ① 引用修改实参 */
void scale(std::vector<int> &v, int factor) {
    for (int &x : v) {
        x *= factor;
    }
}

/* ② const 引用：只读、不复制 */
void print(const std::vector<int> &v) {
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << "\n";
}

/* ③ 引用返回：可写 */
int &first(std::vector<int> &v) {
    return v[0];
}

int main() {
    std::vector<int> nums = {1, 2, 3, 4};

    print(nums);           /* 1 2 3 4 */
    scale(nums, 10);
    print(nums);           /* 10 20 30 40 */

    first(nums) = 99;      /* 通过返回的引用直接改 */
    print(nums);           /* 99 20 30 40 */

    return 0;
}
```

输出：

```text
1 2 3 4
10 20 30 40
99 20 30 40
```

## 常见错误

| 错误 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| `int &r;` | 编译错 | 引用必须初始化 | `int &r = n;` |
| `r = m` 想改绑 | 实参被改 | 这是赋值 | 用指针 |
| 大对象参数不加 `&` | 慢 | 复制了整个对象 | `const T&` |
| 返回局部变量引用 | UB / 崩溃 | 已销毁 | 返回值或堆对象 |
| `int &r = 42;` | 编译错 | 不能绑字面量 | `const int &r = 42;` |
| 对引用取 `nullptr` | 编译错 | 引用不能为空 | 用指针 |
