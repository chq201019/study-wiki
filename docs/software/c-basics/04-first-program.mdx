# 04 第一个完整程序

**本课目标**：能逐行解释一个 C 程序的每个部分在做什么。

## 完整程序

```c
#include <stdio.h>

int main(void) {
    printf("你好，C 语言！\n");
    return 0;
}
```

编译运行：

```bash
gcc -std=c17 -Wall -Wextra hello.c -o hello
.\hello
```

输出：

```text
你好，C 语言！
```

看起来简单，但每一行都有讲究。**逐行讲透。**

## 第一行：`#include <stdio.h>`

```c
#include <stdio.h>
```

**含义**：把 `stdio.h` 这个文件的内容**原样复制到这里**（第 3 课讲过，预处理阶段做的事）。

`stdio` = **st**andard **i**nput **o**utput（标准输入输出）。这个头文件里声明了 `printf`、`scanf`、`fopen` 等函数。

:::danger[不写会怎样]
```c
int main(void) {
    printf("hi\n");       /* 没有 #include <stdio.h> */
    return 0;
}
```

编译警告：

```text
warning: implicit declaration of function 'printf'
```

**现在**在很多编译器上还能跑（因为它自动猜了函数签名），但这是**未定义行为**——换个平台或者函数返回值不是 `int` 时就会出问题。

**规矩：用到哪个函数，就 include 对应的头文件。**
:::

### 尖括号 和 双引号 的区别

```c
#include <stdio.h>      /* 尖括号：从系统头文件目录找 */
#include "myheader.h"   /* 双引号：先找当前目录，再找系统目录 */
```

| 写法 | 查找顺序 | 用于 |
| --- | --- | --- |
| `<xxx.h>` | 系统目录 | 标准库、第三方库 |
| `"xxx.h"` | 当前目录 → 系统目录 | 自己写的头文件 |

## 第二行：`int main(void)`

```c
int main(void)
```

这是**程序入口**——操作系统启动你的程序后，**第一件事就是调用 `main`**。

逐个部分看：

| 部分 | 含义 |
| --- | --- |
| `int` | 返回值类型是整数 |
| `main` | **固定名字**，不能改 |
| `(void)` | 不接收参数 |

:::warning[`(void)` 和 `()` 的区别]
```c
int main(void)      /* 明确表示：不接收任何参数 */
int main()          /* 老式写法：表示"参数未指定" */
```

在 C 里这两者**技术上不同**。`main()` 是旧式写法（K&R 时代遗留），现代代码应该写 `(void)`。

还有个带参数的版本：

```c
int main(int argc, char *argv[])    /* 接收命令行参数 */
```

第 27 课会讲。
:::

### 花括号 `{ }`

```c
int main(void) {
    /* 函数体 */
}
```

花括号圈出**函数体**——这个函数要执行的代码。C 用花括号划分代码块，不像 Python 用缩进。

:::tip[C 的缩进只是给人看的]
```c
int main(void){int a=1;if(a){printf("x\n");}return 0;}
```

这一行完全合法，能编译能跑——但没人愿意读。

**缩进和换行对 C 没有语法意义**，但**对读代码的人有意义**。所以务必规范缩进（4 空格）。
:::

## 第三行：`printf`

```c
printf("你好，C 语言！\n");
```

`printf` = **print formatted**（格式化打印）。

### 分号不能少

```c
printf("hi\n")      /* ❌ 报错 */
printf("hi\n");     /* ✅ */
```

**C 的每条语句必须以分号结尾。** 这是新手最高频的错误。

### `\n` 是什么

`\n` 是**转义字符**，表示换行。

```c
printf("第一行\n第二行\n");
```

输出：

```text
第一行
第二行
```

常用转义：

| 写法 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 制表符（Tab） |
| `\\` | 一个反斜杠 |
| `\"` | 双引号 |
| `\r` | 回车 |

:::warning[不加 `\n` 会怎样]
```c
printf("第一行");
printf("第二行");
```

输出：

```text
第一行第二行
```

**粘在一起了！** `printf` 不会自动换行（这点和 Python 的 `print` 不同）。

**注意**：有些终端里如果最后一行没有 `\n`，提示符会紧贴在内容后面，看起来像程序没输出完。
:::

## 第四行：`return 0`

```c
return 0;
```

**含义**：程序正常结束，并把 `0` 返回给操作系统。

| 返回值 | 含义 |
| --- | --- |
| `0` | 成功 |
| 非 0 | 失败（具体数字表示错误类型） |

:::tip[这个返回值真的有用]
在终端里可以用 `echo $?` 查看上一个程序的返回值：

```bash
./hello
echo $?
```

输出：

```text
0
```

这让你能在脚本里判断程序是否成功：

```bash
if ./hello; then
    echo "成功了"
else
    echo "失败了"
fi
```

**所以 `return 0` 不是摆设，是给调用方（shell、其他程序）看的信号。**
:::

### 不写 return 会怎样

```c
int main(void) {
    printf("hi\n");
}
```

**C99 及以后标准规定**：`main` 函数末尾如果不写 `return`，隐式返回 `0`。

**建议还是写**——明确表达意图，也兼容老编译器。

## 完整对照：每一行的作用

```c
#include <stdio.h>       ← 引入 printf 的声明

int main(void) {         ← 程序入口（返回 int，不收参数）

    printf("hi\n");      ← 调用打印函数，语句以分号结束

    return 0;            ← 告诉系统"正常退出"
}
```

**四个部分，缺一不可**（`return 0` 可省但建议写）。

## 再看一个复杂点的例子

```c
#include <stdio.h>

int main(void) {
    int age = 18;
    double height = 1.75;
    char grade = 'A';
    const char *name = "小明";

    printf("姓名：%s\n", name);
    printf("年龄：%d\n", age);
    printf("身高：%.2f 米\n", height);
    printf("等级：%c\n", grade);

    return 0;
}
```

输出：

```text
姓名：小明
年龄：18
身高：1.75 米
等级：A
```

### 这里出现了新东西

| 写法 | 含义 | 第几课讲 |
| --- | --- | --- |
| `int age = 18;` | 声明整数变量 | 05 |
| `double height = 1.75;` | 双精度浮点 | 07 |
| `char grade = 'A';` | 单个字符 | 05 |
| `const char *name` | 字符串（指针！） | 13 |
| `%s` `%d` `%f` `%c` | 格式化占位符 | 08 |

**不用现在全懂**，知道程序能跑通就够了。

:::warning[`%d` 和变量的类型必须匹配]
```c
int n = 42;
printf("%d\n", n);       /* ✅ 正确 */
printf("%s\n", n);       /* ❌ 把整数当字符串打印 → 崩溃或乱码 */
```

**格式符写错不会编译报错**（`printf` 是可变参数，编译器管不了），只会在运行时出怪事。

第 08 课会详细讲所有格式符。**这是 C 里最容易犯的隐形错误之一。**
:::

## 常见错误

| 错误 | 报错 | 原因 |
| --- | --- | --- |
| 漏分号 | `expected ';'` | 每条语句都要分号 |
| 漏 `#include <stdio.h>` | `implicit declaration of printf` | 用函数前要 include |
| 用中文标点 | 各种奇怪错误 | `；` `（）` `“”` 都不合法 |
| `main` 拼错 | `undefined reference to 'main'` | 必须叫 `main` |
| 花括号不配对 | `expected '}'` | 检查 `{` 和 `}` 数量 |
| `printf` 写成 `Printf` | `implicit declaration` | C **区分大小写** |
| `\n` 写成 `/n` | 内容里出现 `/n` | 是反斜杠不是斜杠 |

:::danger[中文标点是隐形杀手]
```c
int main(void)｛           /* 用了全角花括号 */
    printf（"hi\n"）;      /* 用了全角括号 */
｝
```

报错可能是：

```text
error: stray '\357' in program
```

**看起来完全不知所云。** 原因是你输入法没切回英文。

**排查技巧**：报 `stray` 开头或提到奇怪字符的错误，先检查有没有全角符号。
:::
