# 12 数组

**本课目标**：会声明和遍历数组，理解"连续内存"，并且知道越界有多危险。

## 声明数组

```c
int a[5];              /* 5 个 int，未初始化 */
int b[5] = {1, 2, 3, 4, 5};   /* 全部初始化 */
```

**方括号里的数字是元素个数**，不是最大下标。

:::danger[下标从 0 开始，到 n-1 结束]
```c
int a[5];        /* 下标是 0,1,2,3,4 */
a[0] = 1;        /* ✅ 第一个 */
a[4] = 5;        /* ✅ 最后一个 */
a[5] = 6;        /* ❌ 越界！不存在 a[5] */
```

**5 个元素的数组，最大下标是 4。** 忘掉这点就会越界。
:::

## 访问与修改

```c
int a[5] = {10, 20, 30, 40, 50};

printf("%d\n", a[0]);       /* 10 */
printf("%d\n", a[4]);       /* 50 */

a[2] = 99;
printf("%d\n", a[2]);       /* 99 */
```

**注意**：C 数组不检查下标范围。`a[100]` 也会"正常工作"——它只是访问了数组后面的内存。

## 初始化方式

```c
int a[5] = {1, 2, 3, 4, 5};    /* 逐个初始化 */
int b[5] = {1, 2};             /* 后面自动补 0：{1,2,0,0,0} */
int c[5] = {0};                /* 全部 0（常用技巧） */
int d[] = {1, 2, 3};           /* 省略大小，自动推导为 3 */
```

本机实测：

```c
int b[5] = {1, 2};
/* 输出：1 2 0 0 0 */

int c[5] = {0};
/* 输出：0 0 0 0 0 */
```

:::tip[`= {0}` 是最常用的清零写法]
```c
int buffer[1024] = {0};        /* 整个数组清零 */
char str[256] = {0};           /* 字符串缓冲区清零 */
```

**只要给第一个元素初始化为 0，剩下的自动全 0。**

这比写循环干净得多，而且编译器会优化成高效的内存清零指令。
:::

:::warning[没初始化的数组是垃圾值]
```c
int a[5];              /* 没有初始化 */
printf("%d\n", a[0]);  /* 随机值 */
```

和普通变量一样，**局部数组不初始化就是垃圾**。

**规矩：数组声明时就初始化**，哪怕只是 `= {0}`。
:::

## 遍历数组

```c
int a[5] = {10, 20, 30, 40, 50};

for (int i = 0; i < 5; i++) {
    printf("%d ", a[i]);
}
```

输出：

```text
10 20 30 40 50
```

:::danger[`<=` 是最常见的越界原因]
```c
for (int i = 0; i <= 5; i++) {      /* ❌ i=5 时越界 */
    printf("%d ", a[i]);
}

for (int i = 0; i < 5; i++) {       /* ✅ */
    printf("%d ", a[i]);
}
```

**5 个元素，循环条件用 `< 5`，不是 `<= 5`。**
:::

### 用 sizeof 算元素个数

```c
int a[5] = {1, 2, 3, 4, 5};

size_t count = sizeof(a) / sizeof(a[0]);
printf("%zu\n", count);      /* 5 */
```

本机实测：`sizeof(a)=20`（5 × 4 字节），`sizeof(a[0])=4`，相除得 5。

:::warning[这个方法只在数组的"出生地"有效]
```c
void print_all(int arr[]) {
    /* arr 这里是指针，不是数组！ */
    size_t n = sizeof(arr) / sizeof(arr[0]);   /* ❌ 算出来是错的 */
}

int main(void) {
    int a[5] = {1,2,3,4,5};
    print_all(a);        /* 数组传参退化为指针 */
}
```

在函数内部，`sizeof(arr)` 得到的是**指针大小（8）**，不是数组大小。

**规则**：`sizeof` 求元素个数只能在**数组定义的那个作用域**里用。跨函数传数组必须**额外传长度**。

第 18 课会详细讲这个机制。
:::

## 越界：C 不检查，后果自负

:::danger[这是 C 最危险的行为之一]
```c
int a[5] = {1, 2, 3, 4, 5};
a[10] = 999;              /* 语法没问题，编译没问题 */
```

**不会报错，不会崩溃（至少这次不会）。** 它只是往数组后面的内存写了 999。

那块内存可能是：

- 别的变量 → 那个变量被莫名其妙改了
- 函数返回地址 → 程序跳到随机位置崩溃
- 未映射区域 → 段错误（Segmentation fault）
:::

### 越界的典型后果

| 后果 | 说明 |
| --- | --- |
| **看起来正常** | 最可怕的情况，隐藏的 bug |
| 其他变量被改 | `x` 明明没赋值却变了 |
| 段错误崩溃 | `Segmentation fault` |
| 程序行为诡异 | 换台机器结果不同 |

:::warning[为什么"看起来正常"最可怕]
你写 `a[5] = 1`（越界 1 个），恰好那块内存没被用到，程序跑得好好的。

**然后**：换个编译器、开优化、加几行代码——崩溃了。而且很难联想到是那个越界。

**这是 C 项目里最难查的一类 bug。**
:::

### 怎么避免

```c
/* ① 循环边界写对 */
for (int i = 0; i < n; i++)        /* 不是 <= */

/* ② 访问前检查 */
if (i >= 0 && i < n) {
    a[i] = value;
}

/* ③ 用常量定义大小，别到处写数字 */
#define MAX_SIZE 100
int a[MAX_SIZE];
for (int i = 0; i < MAX_SIZE; i++)

/* ④ 调试时开检查（见第 29 课） */
```

## 二维数组

```c
int m[2][3] = {
    {1, 2, 3},
    {4, 5, 6},
};
```

**`m[2][3]` 是 2 行 3 列。**

```c
printf("%d\n", m[0][0]);       /* 1 */
printf("%d\n", m[1][2]);       /* 6 */
```

本机实测：`sizeof(m) = 24`（2×3×4 字节）。

### 遍历二维数组

```c
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        printf("%d ", m[i][j]);
    }
    printf("\n");
}
```

输出：

```text
1 2 3
4 5 6
```

:::info[二维数组在内存里其实是"一行"]
`m[2][3]` 在内存中连续存放 6 个 int：

```text
[1][2][3][4][5][6]
```

`m[1][2]` 实际是**第 `1*3 + 2 = 5` 个元素**（下标从 0 数）。

这叫"行优先"（row-major）存储。理解这点对后面学指针很重要。
:::

## 数组的特点

:::warning[数组不能整体赋值]
```c
int a[5] = {1,2,3,4,5};
int b[5];
b = a;              /* ❌ 编译错误 */
```

**数组名不是变量，不能被赋值。**

要复制数组：

```c
for (int i = 0; i < 5; i++) {
    b[i] = a[i];
}

/* 或者用 memcpy */
#include <string.h>
memcpy(b, a, sizeof(a));
```
:::

### 也不能整体比较

```c
if (a == b) { }            /* ❌ 比较的是地址，永远不等 */
```

要比较内容：

```c
int equal = 1;
for (int i = 0; i < 5; i++) {
    if (a[i] != b[i]) { equal = 0; break; }
}
```

## 完整示例

```c
#include <stdio.h>

#define COUNT 5

int main(void) {
    int scores[COUNT] = {85, 92, 78, 95, 88};
    int sum = 0;
    int max = scores[0];
    int min = scores[0];

    for (int i = 0; i < COUNT; i++) {
        sum += scores[i];
        if (scores[i] > max) max = scores[i];
        if (scores[i] < min) min = scores[i];
    }

    printf("成绩：");
    for (int i = 0; i < COUNT; i++) {
        printf("%d ", scores[i]);
    }
    printf("\n");

    printf("总分：%d\n", sum);
    printf("平均：%.2f\n", (double)sum / COUNT);
    printf("最高：%d\n", max);
    printf("最低：%d\n", min);

    return 0;
}
```

输出：

```text
成绩：85 92 78 95 88
总分：438
平均：87.60
最高：95
最低：78
```

## 常见错误

| 错误 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| `for (i = 0; i <= n; i++)` | 越界 | 多跑一次 | 用 `<` |
| `int a[n]`（n 是变量） | 编译错（C99 前） | 大小必须编译期确定 | 用常量或 `malloc` |
| `b = a` 复制数组 | 编译错 | 数组不能赋值 | 用循环或 `memcpy` |
| `if (a == b)` | 永远不等 | 比的是地址 | 逐元素比较 |
| 未初始化 | 垃圾值 | 局部数组不清零 | `= {0}` |
| 函数里 `sizeof` 算长度 | 得到指针大小 | 数组退化为指针 | 额外传长度 |

:::danger[`int a[n]` 里的 n 必须是常量]
```c
int n = 5;
int a[n];          /* ⚠️ C99 之前是错误，C99 起是"变长数组" */

const int SIZE = 5;
int b[SIZE];       /* ✅ 常量 */
```
:::

:::warning[`const int` 在 C 里不算"常量表达式"]
```c
const int n = 5;
int a[n];          /* ⚠️ C 里这不是编译期常量 */
```

**要编译期常量用 `#define`**：

```c
#define N 5
int a[N];          /* ✅ */
```

这是 C 和 C++ 的区别之一（C++ 里 `const int` 可以）。
:::

需要运行时决定大小，用动态内存：

```c
int *arr = malloc(n * sizeof(int));
/* ... 用完 ... */
free(arr);
```
