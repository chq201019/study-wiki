# 09 运算符与类型转换

**本课目标**：掌握所有运算符，理解隐式转换这个隐形坑。

## 算术运算符

```c
int a = 7, b = 2;

printf("%d\n", a + b);      /* 9  加 */
printf("%d\n", a - b);      /* 5  减 */
printf("%d\n", a * b);      /* 14 乘 */
printf("%d\n", a / b);      /* 3  除（整数除法！） */
printf("%d\n", a % b);      /* 1  取余 */
```

:::warning[`%` 只能用于整数]
```c
double x = 7.5;
printf("%f\n", x % 2);      /* ❌ 编译错误 */
```

浮点数取余要用 `fmod()`（在 `<math.h>`）。

```c
#include <math.h>
printf("%f\n", fmod(7.5, 2.0));   /* 1.500000 */
```
:::

## 整数除法：最容易掉进的坑

本机实测：

```c
int a = 7, b = 2;
printf("7/2 = %d\n", a / b);           /* 3 */
printf("7/2.0 = %f\n", a / 2.0);       /* 3.500000 */
printf("(double)7/2 = %f\n", (double)a / b);  /* 3.500000 */
```

:::danger[赋给 double 也救不了整数除法]
```c
double r = a / b;               /* a、b 都是 int */
printf("%f\n", r);              /* 3.000000，不是 3.5 */
```

**因为除法先算完了**：`a / b` 是整数除法得 3，然后才把 3 转成 3.0 赋给 `r`。

**正确做法**：转换要发生在**除法之前**：

```c
double r1 = (double)a / b;      /* ✅ 3.5 */
double r2 = a / (double)b;      /* ✅ 3.5 */
double r3 = (double)a / (double)b;  /* ✅ 3.5 */
```

**这个错误极其常见**，因为结果"看起来像是正确的小数"，只是值是错的。
:::

## `++` 和 `--`

```c
int i = 5;
i++;          /* i 变成 6 */
i--;          /* i 变成 5 */
```

### 前置 vs 后置

```c
int i = 5;
int a = i++;      /* a=5, i=6   后置：先用再加 */
i = 5;
int b = ++i;      /* b=6, i=6   前置：先加再用 */
```

| 写法 | 含义 | `a = i++` 后 |
| --- | --- | --- |
| `i++` | 后置 | `a` 是旧值，`i` 加 1 |
| `++i` | 前置 | `a` 是新值，`i` 已加 1 |

:::danger[不要在同一表达式里多次修改同一变量]
```c
int i = 5;
printf("%d %d %d\n", i, i++, i);    /* 未定义行为！ */
```

本机编译时警告：

```text
warning: unsequenced modification and access to 'i'
```

**C 标准规定这是未定义行为**——不同编译器、不同优化等级可能得到完全不同的结果。

**规矩：一个表达式里只改一次同一个变量。** 分成多条语句写清楚。
:::

## 关系与逻辑运算符

```c
printf("%d\n", 5 > 3);      /* 1（真） */
printf("%d\n", 5 < 3);      /* 0（假） */
printf("%d\n", 5 >= 5);     /* 1 */
printf("%d\n", 5 == 5);     /* 1 */
printf("%d\n", 5 != 3);     /* 1 */
```

:::info[C 没有真正的布尔类型（C99 之前）]
关系运算的结果是 **`int` 的 0 或 1**。

- `0` = 假
- **任何非 0** = 真（不只是 1！）

```c
if (42) {           /* 42 是真 */
    printf("会执行\n");
}
```

C99 加了 `<stdbool.h>`：

```c
#include <stdbool.h>
bool ok = true;     /* true 就是 1 */
```
:::

### 逻辑运算符

```c
printf("%d\n", 1 && 1);     /* 1  and */
printf("%d\n", 1 && 0);     /* 0 */
printf("%d\n", 1 || 0);     /* 1  or */
printf("%d\n", !0);         /* 1  not */
```

### 短路求值

```c
int x = 0;
if (x != 0 && 10 / x > 1) {      /* 左边假，右边不执行 */
    printf("不会执行\n");
} else {
    printf("短路生效，未发生除零\n");
}
```

**输出：`短路生效，未发生除零`**（本机实测）

:::tip[短路是防止除零的常用手法]
```c
if (count > 0 && total / count > 10) { ... }
```

如果 `count` 是 0，`&&` 右边根本不会算，避免了崩溃。

**但注意**：把有副作用的表达式放右边（比如 `func()`），它可能不执行。
:::

## 隐式类型转换

**当不同类型一起运算时，C 会自动转换**。规则是"向更大、更精确的类型靠"。

### 整数提升

```c
char a = 10;
char b = 20;
printf("%d\n", a + b);      /* 30 */
```

`char` 运算时会先**提升为 `int`**。这叫整数提升。

### 常见转换方向

```c
int i = 10;
double d = 3.5;
double r = i + d;          /* int 转成 double，结果 13.5 */
```

**顺序大致是**：

```text
char/short → int → unsigned int → long → unsigned long → float → double
                                          （向精度更高、范围更大的方向）
```

:::warning[int 和 unsigned 混用 → 转成 unsigned]
```c
int a = -1;
unsigned int b = 1;
if (a < b) { ... }        /* 结果是假！a 被转成 4294967295 */
```

第 06 课讲过这个坑，这里再强调一次：**看到 `-Wsign-compare` 警告一定要处理。**
:::

## 强制类型转换

```c
(类型)表达式
```

本机实测：

```c
double d = 3.99;
printf("%d\n", (int)d);         /* 3   截断，不是四舍五入 */
printf("%d\n", (int)(-3.99));   /* -3  向零截断 */
```

:::danger[`(int)` 是截断，不是四舍五入]
```c
(int)3.99      /* 3 */
(int)3.01      /* 3 */
(int)-3.99     /* -3 */
```

**直接砍掉小数部分**。要四舍五入用 `round()`：

```c
#include <math.h>
printf("%.0f\n", round(3.99));    /* 4 */
```
:::

### 什么时候需要强制转换

```c
/* ① 整数除法要小数 */
double avg = (double)total / count;

/* ② 抑制警告（明确表示"我知道会丢精度"） */
int i = (int)some_double;

/* ③ 指针类型转换（第 20 课讲） */
void *p = malloc(100);
int *arr = (int *)p;

/* ④ 明确无符号比较 */
if ((size_t)n < sizeof(arr))
```

:::tip[强制转换是"我知道我在做什么"的声明]
类型转换会告诉编译器（和读代码的人）："这里类型不同是故意的，别警告我"。

**但转换不会消除隐患**——`(int)3.99` 得到 3 这个精度损失是真的发生了。

**滥用强制转换会掩盖真问题。** 只在确实需要时用，并且加注释说明原因。
:::

## 复合赋值运算符

```c
int x = 10;
x += 5;      /* x = x + 5   → 15 */
x -= 3;      /* 12 */
x *= 2;      /* 24 */
x /= 4;      /* 6 */
x %= 4;      /* 2 */
x <<= 2;     /* 8  左移 */
x >>= 1;     /* 4  右移 */
x &= 3;      /* 0  按位与 */
x |= 8;      /* 8  按位或 */
x ^= 1;      /* 9  按位异或 */
```

位运算见第 28 课。

## 三目运算符

```c
int a = 5, b = 3;
int max = (a > b) ? a : b;
printf("%d\n", max);      /* 5 */
```

语法：`条件 ? 值1 : 值2`

**只在简单场景用**。嵌套三目会很难读：

```c
/* ❌ 难读 */
int x = a > b ? (a > c ? a : c) : (b > c ? b : c);

/* ✅ 用函数或 if 更清晰 */
```

## 运算符优先级

```c
int r = 2 + 3 * 4;        /* 14，不是 20（先乘后加） */
int s = (2 + 3) * 4;      /* 20，用括号强制 */
```

常用优先级（从高到低）：

| 优先级 | 运算符 |
| --- | --- |
| 高 | `()` `[]` `->` `.` |
| ↑ | `!` `~` `++` `--` `(类型)` `*` `&`（一元） |
| | `*` `/` `%` |
| | `+` `-` |
| | `<<` `>>` |
| | `<` `<=` `>` `>=` |
| | `==` `!=` |
| | `&` `^` `\|` |
| | `&&` `\|\|` |
| 低 | `?:` `=` `+=` 等 |

:::tip[记不住优先级就加括号]
```c
int r = a + b * c;              /* 要靠记忆 */
int r = a + (b * c);            /* 明确表示意图 */
```

**括号不花钱，但能防止 bug 和减少阅读负担。** 复杂的表达式一律加括号。
:::

## 完整示例

```c
#include <stdio.h>

int main(void) {
    int a = 7, b = 2;

    printf("整数除法：%d / %d = %d\n", a, b, a / b);
    printf("转成浮点：%.2f\n", (double)a / b);
    printf("取余：%d %% %d = %d\n", a, b, a % b);

    /* 优先级 */
    printf("2 + 3 * 4 = %d\n", 2 + 3 * 4);
    printf("(2 + 3) * 4 = %d\n", (2 + 3) * 4);

    /* 三目 */
    int x = 10, y = 20;
    printf("较大值：%d\n", (x > y) ? x : y);

    /* 复合赋值 */
    int n = 10;
    n += 5;
    printf("n 加 5 后：%d\n", n);

    return 0;
}
```

输出：

```text
整数除法：7 / 2 = 3
转成浮点：3.50
取余：7 % 2 = 1
2 + 3 * 4 = 14
(2 + 3) * 4 = 20
较大值：20
n 加 5 后：15
```

## 常见错误

| 错误 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| `double r = a / b;` | 结果是整数 | 除法先算完 | `(double)a / b` |
| `x % 2` 用在 double 上 | 编译错 | `%` 只支持整数 | 用 `fmod()` |
| 同表达式里 `i++` 多次 | 结果随机 | 未定义行为 | 拆分语句 |
| `if (a = b)` | 恒为真 | 赋值不是比较 | 用 `==` |
| 有符号无符号比较 | 判断反了 | 隐式转换 | 统一类型 |
| `(int)3.99` 期望 4 | 得到 3 | 截断不是四舍五入 | 用 `round()` |
| 忘加括号 | 优先级错 | 记错优先级 | 加括号 |

:::danger[`if (a = b)` 这个经典错误]
```c
int a = 0, b = 5;
if (a = b) {          /* 赋值！a 变成 5，条件为真 */
    printf("会执行\n");
}
```

本意可能是 `if (a == b)`，但少写一个 `=` 就变成赋值，而且**永远为真**（除非 b 是 0）。

**编译器会警告**：

```text
warning: using the result of an assignment as a condition without parentheses
```

**对策**：养成写 `if (5 == a)` 的习惯（把常量放左边，少一个 `=` 就编译报错）。或者认真看警告。
:::
