# 18 指针与数组

**本课目标**：彻底搞清数组和指针的关系，看懂 `*(arr + i)` 这类写法。

## 先说结论

:::info[三句话]
1. **数组名在大多数表达式里会"退化"成指向首元素的指针**
2. **`a[i]` 等价于 `*(a + i)`**
3. **但数组不是指针**——`sizeof` 和 `&` 下就露馅了
:::

## 验证等价性

```c
#include <stdio.h>

int main(void) {
    int arr[5] = {10, 20, 30, 40, 50};
    int *p = arr;              /* 数组名直接赋给指针 */

    printf("arr[2]   = %d\n", arr[2]);
    printf("*(arr+2) = %d\n", *(arr + 2));
    printf("*(p+2)   = %d\n", *(p + 2));
    printf("p[2]     = %d\n", p[2]);
    printf("2[p]     = %d\n", 2[p]);        /* 居然也合法！ */

    return 0;
}
```

本机实测输出：

```text
arr[2]   = 30
*(arr+2) = 30
*(p+2)   = 30
p[2]     = 30
2[p]     = 30
```

**五种写法全等价。**

:::danger[别真的写 `2[p]`]
```c
2[p]        /* 等价于 *(2+p) = *(p+2) = p[2] */
```

因为加法满足交换律，`2[p]` 和 `p[2]` 完全一样。

**但这是纯炫技，可读性极差。永远写 `p[2]`。**
:::

## 为什么 `a[i]` 等于 `*(a+i)`

:::tip[深入一点：编译器就是这么翻译的]
C 标准规定：`a[i]` **定义为** `*(a + i)`。

所以不是"两者碰巧相等"，而是**同一种东西的两种写法**。

```c
arr[2]
→ *(arr + 2)        /* arr 退化成首元素地址，+2 前进两个 int */
→ 从那个地址取出 int
```

**理解这点，很多"神奇"的 C 代码就不神秘了。**
:::

## 但数组不是指针

:::danger[`sizeof` 立刻揭穿]
```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;

printf("sizeof(arr) = %zu\n", sizeof(arr));   /* 20 = 5×4 */
printf("sizeof(p)   = %zu\n", sizeof(p));     /* 8 = 指针大小 */
```

本机实测：

```text
sizeof(arr)=20 sizeof(p)=8
```

**如果数组就是指针，两者应该一样大。但它们不一样。**
:::

### 关键区别表

| 特性 | 数组 `int arr[5]` | 指针 `int *p` |
| --- | --- | --- |
| `sizeof` | 20（整个数组） | 8（指针本身） |
| 能否赋值 | ❌ `arr = ...` 非法 | ✅ `p = ...` |
| `&arr` 的类型 | `int (*)[5]` | `int **` |
| 内存 | 自身就是数据 | 存别人的地址 |

### `&arr` 和 `&arr[0]` 数值相同但类型不同

```c
printf("%p\n", (void*)&arr);      /* 数组的地址 */
printf("%p\n", (void*)&arr[0]);   /* 首元素的地址 */
```

**数值一样**（都指向同一块内存），但**类型不同**：

- `&arr` 是 `int (*)[5]`（指向整个数组的指针）
- `&arr[0]` 是 `int *`

后果是**加 1 时跳的步长不同**：

```c
printf("%p\n", (void*)(&arr + 1));      /* 跳过整个数组：+20 字节 */
printf("%p\n", (void*)(&arr[0] + 1));   /* 跳过一个元素：+4 字节 */
```

:::tip[这个区别什么时候重要]
二维数组传参时会遇到。日常写一维数组基本不用管。

**记住：`&arr` 是"整个数组的指针"，`&arr[0]` 是"首元素的指针"。**
:::

## 数组传参：退化成指针

:::danger[这是 C 最容易踩的坑之一]
```c
void print_size(int arr[]) {
    printf("%zu\n", sizeof(arr));     /* 8，不是 20！ */
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    printf("%zu\n", sizeof(a));       /* 20 */
    print_size(a);                    /* 8 */
    return 0;
}
```

**函数内部，`arr` 已经是指针了。**
:::

### 为什么

```c
void f(int arr[]);      /* 写法 A */
void f(int *arr);       /* 写法 B —— 完全等价！ */
```

**C 标准规定：数组参数会被自动转换为指针参数。** 两种写法编译器看到的是同一个东西。

所以你**没法**在函数里用 `sizeof` 算出数组长度。

### 正确做法：额外传长度

```c
void print_array(const int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    int n = sizeof(a) / sizeof(a[0]);   /* 在数组的"出生地"算 */
    print_array(a, n);                  /* 把长度一起传 */
    return 0;
}
```

:::tip[标准库也是这么做的]
```c
memcpy(dst, src, n);        /* n 是字节数 */
strncpy(dst, src, n);       /* n 是字符数 */
qsort(arr, n, size, cmp);   /* n 是元素个数 */
```

**C 里凡是接收数组的函数，都要额外接收长度**——因为没有别的办法知道。

（C++ 的 `std::vector` 就是为了解决这个问题。）
:::

## 用指针遍历数组

```c
int arr[5] = {10, 20, 30, 40, 50};

/* 方式一：下标 */
for (int i = 0; i < 5; i++) {
    printf("%d ", arr[i]);
}

/* 方式二：指针 */
for (int *p = arr; p < arr + 5; p++) {
    printf("%d ", *p);
}
```

**两者完全等价**，看团队习惯。下标更直观，指针在某些场景更简洁。

:::warning[指针遍历的边界很关键]
```c
for (int *p = arr; p < arr + 5; p++)     /* ✅ 用 < */
for (int *p = arr; p <= arr + 5; p++)    /* ❌ 多走一步，越界 */
```

`arr + 5` 是**数组末尾之后的位置**，可以用于比较，但**不能解引用**。
:::

## 字符串数组 vs 字符指针

```c
char s1[] = "hello";        /* 数组：6 字节在栈上，可修改 */
char *s2 = "hello";         /* 指针：指向只读区的字面量，不可修改 */
```

| | `char s1[]` | `char *s2` |
| --- | --- | --- |
| `sizeof` | 6 | 8 |
| 能修改内容 | ✅ | ❌ 崩溃 |
| 能改指向 | ❌ | ✅ |

**需要修改就用数组，只读才用指针。**

## 指针数组 vs 数组指针

:::danger[这两个名字极易混淆]
```c
int *arr1[5];        /* 指针数组：5 个指针组成的数组 */
int (*arr2)[5];      /* 数组指针：一个指针，指向含 5 个 int 的数组 */
```
:::

:::tip[读法：看括号]
- `int *arr1[5]` —— `[]` 优先级高于 `*`，所以 `arr1` 先和 `[5]` 结合 → **数组**，元素是 `int *`
- `int (*arr2)[5]` —— 括号把 `*` 提到前面 → `arr2` 是**指针**，指向 `int[5]`

**记忆：名字先和谁结合，就是什么。**
:::

### 指针数组的典型用途：字符串表

```c
const char *names[] = {
    "Alice",
    "Bob",
    "Charlie",
};

for (int i = 0; i < 3; i++) {
    printf("%s\n", names[i]);
}
```

每个元素是一个 `char *`，指向各自的字符串。

## 完整示例：数组求和与查找

```c
#include <stdio.h>

int sum(const int *arr, int n) {
    int total = 0;
    for (int i = 0; i < n; i++) {
        total += arr[i];
    }
    return total;
}

/* 返回指针：找到就返回地址，找不到返回 NULL */
int *find(int *arr, int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) {
            return &arr[i];          /* 返回元素的地址 */
        }
    }
    return NULL;
}

int main(void) {
    int a[] = {3, 1, 4, 1, 5, 9, 2, 6};
    int n = sizeof(a) / sizeof(a[0]);

    printf("总和：%d\n", sum(a, n));

    int target = 5;
    int *found = find(a, n, target);

    if (found) {
        printf("找到 %d，在下标 %td 处\n", target, found - a);
    } else {
        printf("没找到 %d\n", target);
    }

    return 0;
}
```

输出：

```text
总和：31
找到 5，在下标 4 处
```

:::tip[`found - a` 是"指针相减"]
两个指向同一数组的指针相减，得到**元素个数差**。

```c
found - a       /* 得到 4，不是 16 */
```

这是指针运算的另一个便利：**能直接算出下标**。
:::

## 常见错误

| 错误 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| 函数里 `sizeof(arr)` | 得到 8 | 数组退化成指针 | 额外传长度 |
| `arr = p` 想改数组 | 编译错 | 数组名不是左值 | 用 `memcpy` 复制内容 |
| `if (arr1 == arr2)` 比内容 | 永远不等 | 比的是地址 | 逐元素比较 |
| `p <= arr + n` 越界 | 读到垃圾 | 多走一步 | 用 `<` |
| `char *s = "abc"; s[0]='x'` | 崩溃 | 字面量只读 | 用 `char s[]` |
| `int *a[5]` 和 `int (*a)[5]` 搞混 | 类型错 | 结合顺序不同 | 看括号 |
