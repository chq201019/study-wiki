# 28 位运算

**本课目标**：掌握位运算，能直接操作寄存器里的每一位。**嵌入式必修。**

## 为什么要学位运算

在嵌入式里，你经常要：

- 把某个寄存器的**第 3 位置 1**
- 读取**第 12~15 位**表示的值
- 用**一个字节**存 8 个开关状态

**这些都是位操作**，不学就没法配寄存器。

## 六个运算符

| 运算符 | 名称 | 作用 |
| --- | --- | --- |
| `&` | 按位与 | 两位都是 1 才得 1 |
| `\|` | 按位或 | 有一位是 1 就得 1 |
| `^` | 按位异或 | 两位不同得 1 |
| `~` | 按位取反 | 0 变 1，1 变 0 |
| `<<` | 左移 | 整体左移，右边补 0 |
| `>>` | 右移 | 整体右移 |

## 实测：四个逻辑运算

![位运算示意：置位、清位、掩码提取三种操作逐位对照](/img/diagrams/c-bitops.svg)

```c
uint8_t a = 0b11001010;      /* 202 */
uint8_t b = 0b10110101;      /* 181 */
```

本机实测：

```text
a    = 11001010 (202)
b    = 10110101 (181)
a&b  = 10000000 (128)     ← 逐位与，只有第7位都是1
a|b  = 11111111 (255)     ← 逐位或，全部是1
a^b  = 01111111 (127)     ← 逐位异或，不同的位为1
~a   = 00110101           ← 全部取反
```

:::tip[逐位对照着看]
```text
a   = 11001010
b   = 10110101
      --------
a&b = 10000000    两边都是1才得1
a|b = 11111111    有一边是1就得1
a^b = 01111111    不同才得1
```

**竖着一位一位看，就是全部逻辑。**
:::

:::info[`0b` 前缀是二进制字面量]
```c
uint8_t a = 0b11001010;      /* C23 标准，GCC/Clang 早就支持 */
uint8_t b = 0xCA;            /* 十六进制，完全相同 */
uint8_t c = 202;             /* 十进制，也一样 */
```

三种写法**值完全相同**，只是表示方式不同。**位操作时用 `0b` 最直观。**
:::

## 移位

```c
printf("%u\n", 1u << 3);        /* 8，即 2^3 */
```

本机实测：

```text
1<<3 = 8
a>>2 = 00110010     ← 11001010 右移两位，左边补0
```

| 表达式 | 结果 | 含义 |
| --- | --- | --- |
| `1 << 0` | 1 | 2⁰ |
| `1 << 3` | 8 | 2³ |
| `1 << 8` | 256 | 2⁸ |
| `x >> 1` | x/2 | 除以 2（整数） |
| `x << 1` | x*2 | 乘以 2 |

:::danger[移位超范围是未定义行为]
```c
1 << 32          /* ❌ int 只有 32 位，移 32 位是 UB */
1 << -1          /* ❌ 负数移位是 UB */
```

**本机实测**：`1u << 31` = 2147483648（合法，正好是最高位）。

**规矩**：移位数必须 `< 位宽`，且非负。

用 `1u`（无符号）而不是 `1`，避免移进符号位产生 UB。
:::

## 三个必备惯用法

:::tip[① 置位（把第 n 位设为 1）]
```c
x |= (1u << n);
```

**原理**：`|` 运算中，和 1 或得 1，和 0 或保持原值。

```text
x     = 00010001
1<<4  = 00010000
        --------
x|(1<<4)=00010001   ← 第4位变1
```
:::

:::tip[② 清位（把第 n 位设为 0）]
```c
x &= ~(1u << n);
```

**原理**：先取反造一个"只有第 n 位是 0"的掩码，再与。

```text
1<<2       = 00000100
~(1<<2)    = 11111011     ← 只有第2位是0
x          = 00010101
             --------
x & ~(1<<2)= 00010001     ← 第2位被清零
```
:::

:::tip[③ 翻转位（第 n 位取反）]
```c
x ^= (1u << n);
```

**原理**：和 1 异或会翻转，和 0 异或保持。

```text
x        = 00010001
1<<0     = 00000001
           --------
x^=(1<<0)= 00010000     ← 第0位从1变0
```
:::

:::tip[④ 检查位]
```c
if (x & (1u << n)) { ... }        /* 第 n 位是 1 */
if ((x >> n) & 1u) { ... }        /* 等价，更明确 */
```
:::

### 封装成宏

```c
#define BIT(n)            (1u << (n))
#define SET_BIT(x, n)     ((x) |=  BIT(n))
#define CLEAR_BIT(x, n)   ((x) &= ~BIT(n))
#define TOGGLE_BIT(x, n)  ((x) ^=  BIT(n))
#define CHECK_BIT(x, n)   (((x) >> (n)) & 1u)
```

**注意每个参数都加了括号**（第 26 课的宏陷阱）。

本机实测：

```c
uint8_t r = 0;
SET_BIT(r, 0); SET_BIT(r, 2); SET_BIT(r, 4);
/* r = 00010101 (21) */

CLEAR_BIT(r, 2);
/* r = 00010001 (17) */

TOGGLE_BIT(r, 0);
/* r = 00010000 (16) */

CHECK_BIT(r, 4);      /* 1 */
```

## 掩码：提取一段位

:::tip[这是嵌入式最常用的技巧]
```c
uint32_t reg = 0xABCD1234;

uint32_t low8   = reg & 0xFF;              /* 取低 8 位 */
uint32_t bits12 = (reg >> 12) & 0xF;       /* 取第 12~15 位 */
```

本机实测：

```text
reg=0xABCD1234  low8=0x34  bits12-15=0x1
```

**两步走**：

1. **右移**，把目标位段移到最低位
2. **与掩码**，把其他位清掉
:::

### 通用公式

```c
/* 提取从 bit offset 开始、宽 width 的字段 */
uint32_t get_field(uint32_t reg, int offset, int width) {
    uint32_t mask = (1u << width) - 1u;      /* width 个 1 */
    return (reg >> offset) & mask;
}

/* 写入字段 */
uint32_t set_field(uint32_t reg, int offset, int width, uint32_t value) {
    uint32_t mask = (1u << width) - 1u;
    reg &= ~(mask << offset);                /* 先清空那一段 */
    reg |= (value & mask) << offset;         /* 再写入 */
    return reg;
}
```

:::warning[`(1u << width) - 1` 造掩码的原理]
```c
1u << 4        = 00010000
(1u << 4) - 1  = 00001111     ← 4 个 1
```

**减 1 会把"单个 1"变成"下面全 1"。**

这是造位掩码的标准手法。注意 `width` 不能等于位宽（否则 `1u<<32` 是 UB）。
:::

## 实战：寄存器操作

```c
/* 假设某个控制寄存器： */
/* bit 0    : 使能 */
/* bit 1    : 中断使能 */
/* bit 4-6  : 分频系数（0-7） */
/* bit 7    : 保留 */

#define CTRL_EN        BIT(0)
#define CTRL_IE        BIT(1)
#define CTRL_DIV_SHIFT 4
#define CTRL_DIV_MASK  0x7u

uint8_t ctrl = 0;

/* 使能 + 开中断 */
ctrl |= CTRL_EN;
ctrl |= CTRL_IE;

/* 设置分频为 3 */
ctrl = (uint8_t)((ctrl & ~(CTRL_DIV_MASK << CTRL_DIV_SHIFT))
                 | (3u << CTRL_DIV_SHIFT));

/* 检查是否使能 */
if (ctrl & CTRL_EN) {
    printf("已使能\n");
}
```

:::tip[为什么用命名常量而不是数字]
```c
ctrl |= (1u << 0);       /* 0 是什么？ */
ctrl |= CTRL_EN;         /* 一眼就知道是"使能位" */
```

**寄存器位定义的惯例**：用 `#define` 或 `enum` 给每一位起名，代码才能维护。
:::

## 用位域存多个布尔值

```c
/* 不用位域：4 个 bool 占 4 字节 */
struct {
    bool a, b, c, d;
} flags;

/* 用位运算：1 字节存 8 个标志 */
uint8_t flags = 0;
#define FLAG_A  BIT(0)
#define FLAG_B  BIT(1)
#define FLAG_C  BIT(2)
#define FLAG_D  BIT(3)

flags |= FLAG_A | FLAG_C;         /* 同时置两个 */
if (flags & FLAG_A) { ... }
```

:::info[为什么嵌入式偏爱位运算而不是位域]
| | 位运算 | 位域 `struct{unsigned a:1;}` |
| --- | --- | --- |
| 布局确定性 | **完全可控** | 实现定义，不可移植 |
| 访问方式 | 显式，看得见 | 编译器生成的读写序列 |
| 与硬件寄存器 | **推荐** | 有风险 |

**操作硬件寄存器一律用位运算**，位域只用于纯软件的数据压缩。
:::

## 常见错误

| 错误 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| `x & 1 == 0` | 结果错 | `==` 优先级高于 `&` | `(x & 1) == 0` |
| `1 << 32` | UB | 移位超位宽 | 用 `1u << n`，n < 32 |
| 有符号右移负数 | 实现定义 | 符号扩展 | 用无符号类型 |
| `x \|= 1 << n` 用 int | 可能 UB | 移进符号位 | `1u << n` |
| 清位写成 `x &= (1<<n)` | 清不掉 | 掩码反了 | `&= ~(1<<n)` |
| 用 `&&` 代替 `&` | 结果错 | 逻辑与 vs 按位与 | 分清 |

:::danger[`x & 1 == 0` 是经典优先级陷阱]
```c
if (x & 1 == 0)          /* ❌ 等价于 x & (1 == 0) → x & 0 → 恒为假 */
if ((x & 1) == 0)        /* ✅ */
```

`==` 的优先级**高于** `&`。**位运算永远加括号。**
:::
