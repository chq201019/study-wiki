# 11 循环 for / while

**本课目标**：掌握三种循环，会写不会死循环的代码。

## for 循环：C 的写法和其他语言不同

```c
for (int i = 0; i < 5; i++) {
    printf("%d ", i);
}
```

输出：

```text
0 1 2 3 4
```

**三个部分用分号隔开**：

```c
for (初始化 ; 条件 ; 每轮结束后执行) {
    循环体
}
      ↑        ↑         ↑
   int i=0   i<5      i++
```

执行顺序：

1. 初始化（只执行一次）
2. 检查条件 → 真则进循环体
3. 执行循环体
4. 执行 `i++`
5. 回到第 2 步

:::tip[和 Python 的 for 完全不同]
```python
# Python：遍历一个序列
for i in range(5):
    print(i)
```

```c
/* C：三段式的计数循环 */
for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}
```

**C 的 `for` 本质是"带计数器的 while"**，不是"遍历集合"。

C 里想遍历数组：

```c
int arr[5] = {1, 2, 3, 4, 5};
for (int i = 0; i < 5; i++) {
    printf("%d ", arr[i]);
}
```

第 12 课会详细讲数组。
:::

### for 的各种变体

```c
/* 变量在外面声明（C99 之前必须这样） */
int i;
for (i = 0; i < 3; i++) { }

/* 省略初始化 */
int j = 0;
for (; j < 3; j++) { }

/* 省略递增（在循环体内做） */
for (int k = 0; k < 3; ) { k++; }

/* 无限循环，靠内部 break 退出 */
for (;;) {
    if (满足条件) break;
}
```

:::warning[`for (;;)` 是最常见的无限循环写法]
```c
for (;;) {
    /* 服务主循环通常这样写 */
    if (收到退出信号) break;
    do_work();
}
```

等价于 `while (1)`。两种写法都常见，选一种坚持用。
:::

## while 循环

```c
int i = 0;
while (i < 5) {
    printf("%d ", i);
    i++;
}
```

输出：

```text
0 1 2 3 4
```

**条件为真就一直执行**。条件一开始就是假的话，**一次都不执行**：

```c
int m = 10;
while (m < 5) {
    printf("不会执行\n");       /* 本机实测：确实不执行 */
}
```

## do-while：至少执行一次

```c
int n = 10;
do {
    printf("执行一次 n=%d\n", n);
} while (n < 5);
```

本机实测输出：

```text
执行一次 n=10
```

:::tip[do-while 的独特之处]
**先执行，再判断条件**。所以哪怕条件是假的，循环体也至少跑了 1 次。

**典型用途**：菜单循环、输入重试。

```c
int choice;
do {
    printf("1. 开始  2. 退出\n");
    printf("请选择：");
    scanf("%d", &choice);
} while (choice != 1 && choice != 2);    /* 输入不合法就重问 */
```

用户至少看到一次菜单，这正是需要的行为。
:::

**注意 `do-while` 最后的分号**：

```c
do { ... } while (条件);      /* ← 这个分号不能少 */
```

## while 还是 for

| 场景 | 用哪个 |
| --- | --- |
| 知道循环次数 | **for** |
| 遍历数组 / 计数 | **for** |
| 不知道几次，按条件停 | **while** |
| 至少要执行一次 | **do-while** |

```c
/* for：明确次数 */
for (int i = 0; i < 100; i++) { }

/* while：不确定次数 */
while (读取到的数据 != EOF) { }

/* do-while：菜单 */
do { 显示菜单(); } while (用户没选退出);
```

## break：立刻跳出循环

```c
for (int i = 0; i < 10; i++) {
    if (i == 3) break;
    printf("%d ", i);
}
printf("结束\n");
```

输出：

```text
0 1 2 结束
```

**一旦执行 `break`，整个循环立刻结束**。

## continue：跳过本次剩余部分

```c
for (int i = 0; i < 5; i++) {
    if (i % 2 == 0) continue;      /* 偶数跳过 */
    printf("%d ", i);
}
```

输出：

```text
1 3
```

:::warning[`continue` 在 while 里可能导致死循环]
```c
int i = 0;
while (i < 5) {
    if (i == 2) continue;      /* ❌ 死循环！ */
    printf("%d ", i);
    i++;                        /* continue 跳过了这行 */
}
```

`i == 2` 时 `continue` 跳过 `i++`，回到条件检查，`i` 还是 2，**永远出不去**。

**正确做法**：要么把 `i++` 提到 `continue` 之前，要么用 `for`（递增在第三段自动执行）。
:::

## 嵌套循环

```c
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        printf("%d×%d=%d\t", i, j, i * j);
    }
    printf("\n");
}
```

输出：

```text
1×1=1   1×2=2   1×3=3
2×1=2   2×2=4   2×3=6
3×1=3   3×2=6   3×3=9
```

**外层跑一次，内层跑一整个循环。**

### break 只跳出最内层

```c
for (int a = 0; a < 2; a++) {
    for (int b = 0; b < 3; b++) {
        if (b == 1) break;          /* 只跳出内层 */
        printf("a=%d b=%d ", a, b);
    }
}
```

本机实测输出：

```text
a=0 b=0 a=1 b=0
```

**`break` 只终止它所在的那一层循环**，外层继续跑。

:::tip[怎么一次跳出两层]
**方法一：用标志变量**

```c
int found = 0;
for (int i = 0; i < 10 && !found; i++) {
    for (int j = 0; j < 10; j++) {
        if (arr[i][j] == target) {
            found = 1;
            break;
        }
    }
}
```

把 `!found` 加进外层条件，内层跳出后外层也不再继续。

**方法二：用 goto（少见但合法）**

```c
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 10; j++) {
        if (arr[i][j] == target) goto done;
    }
}
done:
printf("找到了\n");
```

**方法三：抽成函数，用 `return`**

```c
int find(int arr[][10], int target) {
    for (int i = 0; i < 10; i++)
        for (int j = 0; j < 10; j++)
            if (arr[i][j] == target) return 1;
    return 0;
}
```

**方法三最清晰**，能抽函数就抽函数。
:::

## 死循环怎么避免

:::danger[三条常见死循环原因]
```c
/* ① 忘了递增 */
int i = 0;
while (i < 10) {
    printf("%d", i);        /* i 永远不变 */
}

/* ② 条件写反 */
for (int i = 10; i > 0; i++) { }     /* i 越来越大，永远 > 0 */

/* ③ continue 跳过了递增（见上文） */
```
:::

**写循环时的自检清单**：

1. 循环变量**一定会变化**吗？
2. 变化的方向**能到达终止条件**吗？
3. 有没有 `continue` 跳过了关键的更新语句？

:::tip[真的卡死了怎么办]
**终端里按 `Ctrl + C`** 强制中断。

这是每个程序员都会用的救命操作。
:::

## 实战：三个经典例子

### 累加求和

```c
#include <stdio.h>

int main(void) {
    int sum = 0;
    for (int i = 1; i <= 100; i++) {
        sum += i;
    }
    printf("1 到 100 的和：%d\n", sum);
    return 0;
}
```

输出：

```text
1 到 100 的和：5050
```

### 判断素数

```c
#include <stdio.h>

int main(void) {
    int n = 97;
    int is_prime = 1;

    if (n < 2) {
        is_prime = 0;
    } else {
        for (int i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                is_prime = 0;
                break;
            }
        }
    }

    printf("%d 是%s\n", n, is_prime ? "素数" : "合数");
    return 0;
}
```

输出：

```text
97 是素数
```

:::tip[为什么循环到 `i * i <= n` 就够]
如果 `n` 有一个大于 `√n` 的因子，那它必然还有一个小于 `√n` 的因子。所以只需要试到 `√n`。

**写成 `i * i <= n` 而不是 `i <= sqrt(n)`**，避免了浮点运算和 `<math.h>` 依赖。
:::

### 倒计时

```c
#include <stdio.h>

int main(void) {
    int count = 5;

    do {
        printf("%d... ", count);
        count--;
    } while (count > 0);

    printf("出发！\n");
    return 0;
}
```

输出：

```text
5... 4... 3... 2... 1... 出发！
```

## 常见错误

| 错误 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| 忘了 `i++` | 死循环 | 循环变量不变 | 检查递增 |
| `for (int i = 0; i <= 5; i++)` 遍历 5 元素数组 | 越界 | `<=` 多了 1 | 用 `<` |
| `while` 里 `continue` 跳过递增 | 死循环 | 见上文 | 改用 `for` |
| `do-while` 漏分号 | 编译错 | 语法要求 | 加 `;` |
| 嵌套 break 想跳两层 | 只跳一层 | break 限制 | 用标志/return |
| `for` 三个部分用逗号 | 编译错 | 要用分号 | `for (i=0; i<5; i++)` |
| 循环变量在循环外还用 | 未定义 | C99 的 `int i` 作用域只在 for 内 | 在外面声明 |

:::warning[`for (int i = 0; ...)` 里 i 的作用域]
```c
for (int i = 0; i < 5; i++) { }
printf("%d\n", i);      /* ❌ error: 'i' undeclared */
```

C99 起，`for` 里声明的变量**只在这个循环内有效**。

要循环结束后还用，就在外面声明：

```c
int i;
for (i = 0; i < 5; i++) { }
printf("%d\n", i);      /* ✅ 输出 5 */
```
:::
