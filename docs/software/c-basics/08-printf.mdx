# 08 格式化输出 printf

**本课目标**：熟练掌握 `printf` 的所有格式控制，不再靠猜。

## 基本结构

```c
printf("格式字符串", 值1, 值2, ...);
```

格式字符串里的 `%` 开头的部分叫**占位符**，会被后面的值依次替换。

```c
printf("我叫%s，今年%d岁\n", "小明", 18);
```

输出：

```text
我叫小明，今年18岁
```

## 类型对照表（必须记住）

| 格式符 | 类型 | 例子 | 输出 |
| --- | --- | --- | --- |
| `%d` | `int`（有符号十进制） | `printf("%d", 42)` | `42` |
| `%u` | `unsigned int` | `printf("%u", 42u)` | `42` |
| `%c` | `char`（单个字符） | `printf("%c", 'A')` | `A` |
| `%s` | 字符串（`char *`） | `printf("%s", "hi")` | `hi` |
| `%f` | `double` / `float` | `printf("%f", 3.14)` | `3.140000` |
| `%e` | 科学计数法 | `printf("%e", 1234.5)` | `1.234500e+03` |
| `%x` | 十六进制（小写） | `printf("%x", 255)` | `ff` |
| `%X` | 十六进制（大写） | `printf("%X", 255)` | `FF` |
| `%o` | 八进制 | `printf("%o", 255)` | `377` |
| `%p` | 指针地址 | `printf("%p", &x)` | `0x7ffd...` |
| `%%` | 一个百分号 | `printf("%%")` | `%` |

:::danger[格式符和实际类型不匹配的后果]
```c
int n = 42;
printf("%s\n", n);      /* 把整数当字符串指针用 */
```

**轻则输出乱码，重则程序崩溃**（把 42 当地址去访问）。

**好消息**：开了 `-Wall`（默认含 `-Wformat`）编译器会警告：

```text
warning: format specifies type 'char *' but the argument has type 'int'
printf("%s\n", n);
        ~~     ^
        %d
```

**编译器甚至直接告诉你该用 `%d`。** 所以务必开警告。
:::

## 长度修饰符：`d` 前面加字母

不同大小的整数需要不同的格式符：

| 修饰符 | 对应类型 | 例子 |
| --- | --- | --- |
| `%hhd` | `signed char` | -128~127 |
| `%hd` | `short` | -32768~32767 |
| `%d` | `int` | 默认 |
| `%ld` | `long` | 平台相关 |
| `%lld` | `long long` | 大整数 |
| `%zu` | `size_t` | `sizeof` 的返回值 |

本机实测：

```c
printf("%hhd\n", (signed char)200);     /* -56 */
printf("%hd\n", (short)70000);          /* 4464 */
printf("%ld\n", 1234567890L);           /* 1234567890 */
printf("%lld\n", 1234567890123LL);      /* 1234567890123 */
printf("%zu\n", sizeof(int));           /* 4 */
```

:::warning[为什么 `200` 打印成 `-56`]
`signed char` 范围是 -128~127。`200` 超出了，按补码回绕：

`200 - 256 = -56`

这不是 `printf` 的错，是**赋值时就溢出了**。同理 `(short)70000` 变成 `4464`。

**这正好演示了上一课讲的整数回绕。**
:::

:::danger[`%zu` 别写成 `%d`]
```c
printf("%d\n", sizeof(int));    /* ❌ 未定义行为 */
printf("%zu\n", sizeof(int));   /* ✅ */
```

`sizeof` 返回 `size_t`（可能是 8 字节），用 `%d`（4 字节）会读错位置。

**在 64 位系统上这通常能"正常"打印小数字，但本质是未定义行为**——换成打印很大的值时就会错。
:::

## 宽度和精度

### 宽度：占几位

```c
printf("[%5d]\n", 42);
printf("[%-5d]\n", 42);
printf("[%05d]\n", 42);
```

输出：

```text
[   42]
[42   ]
[00042]
```

| 写法 | 效果 |
| --- | --- |
| `%5d` | 右对齐，占 5 位 |
| `%-5d` | 左对齐，占 5 位 |
| `%05d` | 补零到 5 位 |

### 浮点精度

```c
double pi = 3.14159265;

printf("%f\n", pi);        /* 3.141593   默认 6 位 */
printf("%.2f\n", pi);      /* 3.14       2 位小数 */
printf("%.0f\n", pi);      /* 3          0 位（会四舍五入） */
printf("%8.3f\n", pi);     /*    3.142   宽 8，3 位小数 */
printf("%-8.3f\n", pi);    /* 3.142       左对齐 */
```

本机实测：

```text
[   3.142]
[3.142   ]
```

### 字符串宽度

```c
printf("[%10s]\n", "hi");
printf("[%-10s]\n", "hi");
printf("[%.2s]\n", "hello");
```

输出：

```text
[        hi]
[hi        ]
[he]
```

`%.2s` 表示**只取前 2 个字符**。

## 其他常用标志

```c
printf("[%+d]\n", 42);      /* [+42]  强制显示正号 */
printf("[% d]\n", 42);      /* [ 42]  正数前加空格 */
printf("[%#x]\n", 255);     /* [0xff] 加 0x 前缀 */
printf("[%#o]\n", 255);     /* [0377] 加 0 前缀 */
```

| 标志 | 作用 |
| --- | --- |
| `+` | 正数也显示 `+` |
| （空格） | 正数前留一个空格 |
| `#` | 十六进制加 `0x`，八进制加 `0` |
| `0` | 用 0 填充空白 |
| `-` | 左对齐 |

## 实战：打印表格

```c
#include <stdio.h>

int main(void) {
    struct {
        const char *name;
        int score;
        double rate;
    } rows[] = {
        {"小明", 95, 0.95},
        {"张三丰", 100, 1.00},
        {"李四", 78, 0.78},
    };

    printf("%-10s%8s%10s\n", "姓名", "分数", "比率");
    printf("%s\n", "--------------------------------");

    for (int i = 0; i < 3; i++) {
        printf("%-10s%8d%9.1f%%\n",
               rows[i].name, rows[i].score, rows[i].rate * 100);
    }
    return 0;
}
```

输出：

```text
姓名            分数        比率
--------------------------------
小明              95      95.0%
张三丰           100     100.0%
李四              78      78.0%
```

:::warning[中文字符宽度问题]
中文字符在终端里通常占 **2 个字符宽度**，但 `printf` 按**字节数**算宽度。

"小明"是 6 字节（UTF-8 每个汉字 3 字节），所以 `%-10s` 实际只补了 4 个空格，看起来不对齐。

**对策**：

- 窄字符内容（纯英文数字）用 `printf` 宽度对齐
- 含中文的表格，要么手动加空格，要么接受轻微不对齐
- 追求完美对齐需要专门的库（如 `wcwidth`）
:::

## `scanf`：输入（配套使用）

`printf` 是输出，`scanf` 是输入。放在一起讲，因为格式符容易混。

```c
int age;
printf("请输入年龄：");
scanf("%d", &age);          /* 注意 & 符号！ */
printf("你今年 %d 岁\n", age);
```

:::danger[`scanf` 必须用 `&` 取地址]
```c
scanf("%d", &age);      /* ✅ 传地址，让 scanf 能写进去 */
scanf("%d", age);       /* ❌ 崩溃或写入随机内存 */
```

**为什么**：`scanf` 需要知道把值写到**哪里**，所以要地址。`printf` 只要值本身，所以不用 `&`。

**这个区别是初学最高频的崩溃原因。**
:::

### scanf 的格式符差异

| 类型 | scanf 格式符 | printf 格式符 |
| --- | --- | --- |
| `int` | `%d` | `%d` |
| `float` | **`%f`** | `%f` |
| `double` | **`%lf`** | `%f` |
| `char` | `%c` | `%c` |
| 字符串 | `%s`（不加 `&`） | `%s` |

:::warning[`double` 在 scanf 里必须用 `%lf`]
```c
double d;
scanf("%f", &d);       /* ❌ 只写了一半，会出错 */
scanf("%lf", &d);      /* ✅ */
```

而 `printf` 里 `%f` 就够了（`float` 会自动提升为 `double`）。

**记忆**：`scanf` 严格区分 `float`(%f) 和 `double`(%lf)；`printf` 不用区分。
:::

### 字符串不加 `&`

```c
char name[32];
scanf("%s", name);      /* 数组名本身就是地址，不用 & */
```

### `%s` 的危险：缓冲区溢出

:::danger[`scanf("%s")` 不检查长度]
```c
char name[10];
scanf("%s", name);      /* 用户输入 100 个字符 → 溢出 */
```

**这是经典的安全漏洞**。正确做法是限制长度：

```c
char name[10];
scanf("%9s", name);     /* 最多读 9 个字符，留 1 个给 '\0' */
```

**注意**：`%9s` 里的数字是"最大读取字符数"，要写成比数组大小**小 1**（留给字符串结束符）。
:::

:::tip[实际项目很少用 scanf]
`scanf` 的问题：输入格式不匹配时容易卡死、难以处理整行输入、缓冲区溢出风险。

**实际项目里常用 `fgets` 读整行，再自己解析**：

```c
char line[256];
if (fgets(line, sizeof(line), stdin)) {
    /* 处理 line */
}
```

第 25 课会详细讲。
:::

## 常见错误

| 错误 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| `%d` 打印 `double` | 乱码/0 | 类型不匹配 | 用 `%f` |
| `%s` 打印 `int` | 崩溃 | 把整数当地址 | 用 `%d` |
| `%zu` 写成 `%d` | 大值时错 | size_t 是 8 字节 | 用 `%zu` |
| `scanf` 忘 `&` | 崩溃 | 需要地址 | 加 `&` |
| `scanf` 读 double 用 `%f` | 值错 | 该用 `%lf` | 改 `%lf` |
| `%s` 无长度限制 | 缓冲区溢出 | 不检查边界 | `%9s` 或 `fgets` |
| `printf("%d")` 少参数 | 打印垃圾 | 占位符比参数多 | 检查参数个数 |
| 忘 `\n` | 输出粘连 | printf 不自动换行 | 加 `\n` |

:::tip[编译器能帮你抓大部分错误]
```bash
gcc -Wall -Wextra -Wformat=2 -c test.c
```

`-Wformat=2` 会检查得更严格（包括 `%s` 长度等）。

**养成开警告编译的习惯，能避免 80% 的格式符错误。**
:::
