# 正则表达式

**本课目标**：能写出正确且不卡死的正则。

## 元字符速查

| 写法 | 含义 |
| --- | --- |
| `.` | 任意字符（**默认不含换行**） |
| `\d` `\D` | 数字 / 非数字 |
| `\w` `\W` | 单词字符（字母数字下划线）/ 非 |
| `\s` `\S` | 空白 / 非空白 |
| `^` `$` | 行首 / 行尾（`re.M` 下是每行） |
| `*` `+` `?` | 0+ / 1+ / 0 或 1 |
| `{n}` `{n,}` `{n,m}` | 精确次数 |
| `[...]` | 字符集（`[^...]` 取反） |
| `\|` | 或 |
| `(...)` | 捕获分组 |
| `(?:...)` | 非捕获分组 |
| `(?P<name>...)` | **命名分组** |

```python
import re

re.findall(r'\d+', 'a1 b22 c333')          # ['1', '22', '333']
re.fullmatch(r'\d{3}-\d{4}', '555-1234')   # 匹配整个字符串
re.search(r'\d+', 'abc123def')             # 第一个匹配（不要求从头）
re.match(r'\d+', 'abc123')                 # None（match 从头开始）
```

:::danger[`re.match` 只从开头匹配，但不要求匹配整个串]
```python
re.match(r'\d+', '123abc')     # ✅ 匹配到 '123'
re.fullmatch(r'\d+', '123abc') # ❌ None（要求整个串）
```

**要"整串完全匹配"用 `fullmatch`** —— 这是校验格式时最常犯的错。
:::

## 贪婪与非贪婪

```python
re.findall(r'<.+>', '<a><b>')       # ['<a><b>']  ← 贪婪，吃到最后一个 >
re.findall(r'<.+?>', '<a><b>')      # ['<a>', '<b>']  ← 非贪婪
```

:::tip[加 `?` 变非贪婪]
`*?` `+?` `??` `{n,m}?` —— 都在量词后加 `?`。

**记忆法：贪婪是"尽可能多"，非贪婪是"够用就停"。**
:::

:::warning[贪婪/非贪婪不是万能解]
**用 `.*?` 处理嵌套结构往往会失败**（正则本身无法正确匹配嵌套括号）。

**嵌套结构请用解析器**（如 HTML/XML/JSON 用专门的库），不要用正则硬啃。
:::

## 分组

```python
m = re.search(r'(\d{4})-(\d{2})-(\d{2})', '2026-01-15')
m.group(0)      # '2026-01-15'（整个匹配）
m.group(1)      # '2026'
m.groups()      # ('2026', '01', '15')
```

```python
# 命名分组，可读性更好
m = re.search(r'(?P<y>\d{4})-(?P<m>\d{2})-(?P<d>\d{2})', s)
m.group('y')        # '2026'
m.groupdict()       # {'y': '2026', 'm': '01', 'd': '15'}
```

:::danger[`group(0)` 与 `group(1)` 容易混]
- **`group(0)`** = 整个匹配
- **`group(1)`** = 第一个捕获组

**如果没写捕获组，`group(1)` 会抛 `IndexError`。**
:::

```python
# 替换时引用分组
re.sub(r'(\w+)\s+(\w+)', r'\2 \1', 'hello world')     # 'world hello'
re.sub(r'(?P<a>\d+)', r'[\g<a>]', 'x1y')               # 'x[1]y'
```

:::warning[替换串里的 `\1` 在原始字符串里写]
```python
re.sub(r'(\d)', r'<\1>', 'a1')      # ✅ r'\1' 是引用分组
re.sub(r'(\d)', '<\1>', 'a1')       # ⚠️ '\1' 被 Python 当成八进制字符
```

**替换串一律用 `r''` 原始字符串。**
:::

## 前后查找（零宽断言）

```python
re.findall(r'\d+(?=元)', '10元 20个 30元')      # ['10', '30']  后面是"元"
re.findall(r'(?<=\$)\d+', '$5 and $12')          # ['5', '12']   前面是 $
re.findall(r'\d+(?!元)', '10元20个')             # 否定后查找
```

| 写法 | 含义 |
| --- | --- |
| `(?=X)` | 后面必须是 X（不消耗） |
| `(?!X)` | 后面不能是 X |
| `(?<=X)` | 前面必须是 X |
| `(?<!X)` | 前面不能是 X |

:::tip["不消耗字符"是什么意思]
```python
re.findall(r'\d+(?=元)', '10元20元')
# ['10', '20']
```

**匹配完 `10` 后，位置仍在 `元` 之前**，所以下一个匹配可以从 `20` 开始 —— **不会因为吃掉 `元` 而漏掉**。
:::

:::danger[后向查找 `(?<=X)` 要求 X 是定长]
```python
re.search(r'(?<=\w+)x', 'abcx')      # ❌ error: look-behind requires fixed-width pattern
re.search(r'(?<=\w{3})x', 'abcx')    # ✅ 定长可以
```

**Python 的 `re` 不支持变长后向查找。**（`regex` 第三方库支持）
:::

## `re` 模块的五个必会函数

```python
re.search(p, s)          # 找第一个，返回 Match 或 None
re.match(p, s)           # 只从开头找
re.fullmatch(p, s)       # 整串匹配
re.findall(p, s)         # 所有匹配（有分组时返回分组元组）
re.finditer(p, s)        # 所有匹配（返回迭代器，含位置信息）
re.sub(p, repl, s, count=0)   # 替换
re.split(p, s)           # 按模式切分
```

:::tip[`finditer` 比 `findall` 信息多]
```python
for m in re.finditer(r'\d+', text):
    print(m.group(), m.start(), m.end())
```

**`findall` 只给字符串；`finditer` 给完整 Match 对象（位置、分组、上下文）。**
:::

:::warning[`findall` 有分组时返回的不一样]
```python
re.findall(r'\d+', 'a1b22')             # ['1', '22']
re.findall(r'(\d)(\d)', 'a12b34')       # [('1','2'), ('3','4')]  ← 元组！
```

**一个分组 → 字符串列表；多个分组 → 元组列表。** 这个行为变化很容易踩。
:::

## 预编译与标志

```python
import re

PATTERN = re.compile(r'\d{3}-\d{4}')     # 复用同一模式时更快
PATTERN.search(text)

re.search(p, s, re.IGNORECASE | re.MULTILINE)
```

| 标志 | 作用 |
| --- | --- |
| `re.I` | 忽略大小写 |
| **`re.M`** | **`^`/`$` 匹配每行首尾** |
| **`re.S`** | **`.` 也匹配换行** |
| `re.X` | 允许注释与空白（可读性） |

:::danger[`^` `$` 默认只匹配整个字符串的首尾]
```python
re.findall(r'^\w+', 'a\nb\nc')                # ['a']  ← 只有第一行
re.findall(r'^\w+', 'a\nb\nc', re.M)          # ['a','b','c']
```

**处理多行文本时必须加 `re.M`** —— 这是"为什么只匹配到第一行"的答案。
:::

```python
# re.X 让复杂正则可读
PATTERN = re.compile(r'''
    ^(?P<ip>\d{1,3}(?:\.\d{1,3}){3})   # IP
    \s-\s-\s
    \[(?P<time>[^\]]+)\]                # 时间
''', re.X)
```

## 灾难性回溯

:::danger[嵌套量词会让匹配时间指数爆炸]
```python
re.match(r'(a+)+$', 'a' * 30 + 'b')     # 会跑很久（几乎卡死）
```

**原因**：`(a+)+` 有大量等价的分组方式，一旦整体失败，回溯要枚举所有组合。
:::

**三个避免手段**：

```python
# ① 用原子分组/占有量词（Python 3.11+ 支持占有量词）
re.match(r'a++b', 'aaab')          # a++ 不回退

# ② 简化模式（去掉不必要的嵌套量词）
re.match(r'a+b', 'aaab')           # ✅ 等价且线性

# ③ 加超时（第三方 regex 库支持 timeout）
import regex
regex.match(r'(a+)+$', s, timeout=1.0)
```

:::warning[**`re` 模块没有超时参数**]
**Python 标准库的 `re` 无法限制匹配时间** —— 一个坏正则可以在服务器上跑满 CPU。

**如果正则来自用户输入（比如搜索框），必须用 `regex` 库的 `timeout`。**
:::

## 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 只匹配到第一行 | 没加 `re.M` | 加标志 |
| `.` 不匹配换行 | 默认行为 | 加 `re.S` |
| 校验格式却通过 | 用了 `search`/`match` | 用 `fullmatch` |
| `findall` 返回元组 | 有多个分组 | 用非捕获组 `(?:)` |
| 替换串 `\1` 报错 | 没用原始字符串 | `r'\1'` |
| 匹配很慢/卡死 | 灾难性回溯 | 简化模式或用 timeout |
| 后向查找报错 | 变长 | 改定长或换 `regex` 库 |
| 中文按字节处理出错 | 编码问题 | 确保 `str` 不是 `bytes` |

:::tip[调试正则的实用方法]
```python
import re
p = re.compile(r'...')
print(p.pattern)
print(re.findall(p, sample))     # 先用小样本验证
```

**或者用 https://regex101.com 逐步可视化**（注意选对 flavor：Python）。
:::
