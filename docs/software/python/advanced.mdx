Python 的"进阶特性"看起来神秘，其实每一个都在解决一个具体问题：
装饰器解决"给函数加功能"，生成器解决"惰性求值"，上下文管理器解决"一定要收尾"。

## 建议的学习方式

这些特性光看会忘，**必须自己写一遍**：

1. **装饰器**：写一个给函数加计时的装饰器
2. **生成器**：手写一个 `yield` 的斐波那契
3. **上下文管理器**：写一个 `with` 打开数据库连接的类
4. **描述符**：用 `__get__`/`__set__` 实现一个类型检查属性
5. **元类**：注册子类的简单元类
