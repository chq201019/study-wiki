# 位操作实战

**本课目标**：不再写出"看起来对但边界就错"的位操作代码。

## 五个基本操作

| 操作 | 写法 | 用途 |
| --- | --- | --- |
| 置位 | `x &#124;= (1u << n)` | 把第 n 位置 1 |
| 清位 | `x &= ~(1u << n)` | 把第 n 位置 0 |
| 取反某位 | `x ^= (1u << n)` | 翻转第 n 位 |
| 读位 | `(x >> n) & 1u` | 取第 n 位的值 |
| 判位 | `if (x & (1u << n))` | 第 n 位是否为 1 |

:::danger[**`1u` 里的 `u` 不能省**]
```c
x |= (1 << 31);        /* ❌ 1 是 int，左移 31 位是未定义行为 */
x |= (1u << 31);       /* ✅ 无符号左移有定义 */
```

**对 `int` 左移到符号位是 UB** —— 编译器可以做任何事（实际常常得到负数）。
:::

## 符号扩展：最常见的错误来源

```c
uint8_t b = 0xFF;
int x = b;             /* x = 255（uint8_t 是无符号，零扩展） */

int8_t sb = 0xFF;      /* 实际上是 -1 */
int y = sb;            /* y = -1（符号扩展） */
```

:::danger[有符号转宽类型会符号扩展]
```c
int8_t a = -1;              /* 0xFF */
uint32_t b = a;             /* 0xFFFFFFFF（不是 0x000000FF！） */

/* 想要 0xFF： */
uint32_t c = (uint8_t)a;    /* ✅ 先转无符号窄类型再扩宽 */
```

**这是"从传感器读到 -1 变成 4294967295"的根源。**
:::

## 无符号溢出的定义行为

```c
uint8_t x = 255;
x = x + 1;        /* x = 0（无符号溢出是良定义：模 2^n） */

int y = INT_MAX;
y = y + 1;        /* ❌ 有符号溢出是未定义行为 */
```

:::warning[有符号溢出是 UB，`-O2` 下会出人意料]
```c
int i = INT_MAX;
if (i + 1 < 0) {
    /* 编译器可能认为这个分支永远不成立，直接删掉 */
}
```

**做"允许溢出"的计算时用无符号类型**（或 `-fwrapv` 编译选项）。
:::

## 嵌入式五个典型用法

### ① 寄存器位域

```c
/* 设 USART 波特率寄存器的高 4 位 */
reg = (reg & ~(0xFu << 4)) | (value << 4);
```

**模式：清掉目标位 → 或上新值。** 顺序不能反。

### ② 位带（Cortex-M3/M4）

```c
/* 用位带别名让"单比特操作"变成原子 */
#define BITBAND(addr, bit)  (0x42000000 + (((uint32_t)(addr) - 0x40000000) * 32) + ((bit) * 4))
```

### ③ 循环队列的索引掩码

```c
#define QSZ 16               /* 必须是 2 的幂 */
idx = (idx + 1) & (QSZ - 1);    /* 比 % QSZ 快（且都是正数行为） */
```

:::danger[只有 2 的幂才能这么写]
`x & (N-1)` 等价于 `x % N` **只在 N 是 2 的幂时成立**。
:::

### ④ 位计数

```c
int popcount(uint32_t x) {
    int n = 0;
    while (x) { x &= x - 1; n++; }    /* Kernighan 算法，只循环到 1 的个数 */
    return n;
}
```

**Cortex-M 有 `__builtin_popcount()`（编译成高效指令或查表）。**

### ⑤ 找最高/最低位

```c
int lowest_set_bit(uint32_t x) {
    return __builtin_ctz(x);        /* count trailing zeros */
}
int highest_set_bit(uint32_t x) {
    return 31 - __builtin_clz(x);
}
```

:::warning[`ctz(0)` / `clz(0)` 是未定义行为]
**x 为 0 时结果未定义**（x86 上返回不确定值，ARM 上也是）。

```c
if (x == 0) return -1;          /* ✅ 先判空 */
```
:::

## 位域（bit-field）的坑

```c
struct Flags {
    unsigned a : 1;
    unsigned b : 3;
    unsigned c : 4;
};
```

:::danger[位域的内存布局是实现定义的]
- **不同编译器的位分配顺序不同**（LSB 优先 / MSB 优先）
- **跨字节的位域如何排列未规定**
- **`sizeof` 不确定**
- **不能取地址**

**所以位域不能用于"与硬件寄存器或网络协议对接"** —— 那些必须用显式的移位与掩码。
:::

:::tip[要按固定布局操作时用手动掩码]
```c
uint32_t v = 0;
v |= (a & 0x1u) << 0;
v |= (b & 0x7u) << 1;
v |= (c & 0xFu) << 4;
```

**虽然啰嗦，但布局完全可控。**
:::

## 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 设位不生效 | `1 << n` 的 `1` 是 int | 用 `1u` |
| 高字节变成 0xFF | 有符号符号扩展 | 先转 `uint8_t` |
| `-O2` 下分支消失 | 有符号溢出是 UB | 用无符号或 `-fwrapv` |
| 位域与协议对不上 | 位域布局实现定义 | 手写移位掩码 |
| `ctz(0)` 结果乱 | 未定义行为 | 先判 0 |
| `x & (N-1)` 算错 | N 不是 2 的幂 | 用 `%` 或改 N |
| 移位超过宽度 | `x << 32` 是 UB | 用 `x << 31` 分两次 |

:::danger[移位数 ≥ 类型宽度是 UB]
```c
uint32_t x = 1;
x << 32;          /* ❌ UB（不是 0） */
x << 31;          /* ✅ */
```

**在 x86 上实际会"取模 32"变成 `x << 0`** —— 更隐蔽。
:::
