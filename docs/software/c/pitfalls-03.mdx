# 03 防御性编程清单
| 做法 | 防什么 |
| --- | --- |
| 声明变量时立即初始化 | 未初始化读 |
| 指针声明时置 `NULL`，`free` 后立刻置 `NULL` | 悬垂、double free |
| 数组下标先检查范围 | 越界 |
| 用 `snprintf` 代替 `sprintf`/`strcpy` | 缓冲区溢出 |
| 用 `memmove` 处理可能重叠的拷贝 | `restrict` 违规 |
| 用 `memcpy` 做类型双关 | 严格别名违规 |
| 算术前检查溢出，或用 `__builtin_*_overflow` | 有符号溢出 |
| 定宽类型 + `u` 后缀 | 类型宽度、提升问题 |
| `_Static_assert` 钉住平台假设 | 移植时静默失效 |
| 不混用有符号和无符号 | 隐式转换 |
| `enum` 的 `switch` 都写 `default` | 未覆盖分支 |
| 开满警告 + `-Werror` | 一大批 |
| 头文件只放声明，源文件中定义 | 重复符号 |
| 文件作用域默认 `static` | 命名污染、意外修改 |
| 不在宏参数里用副作用表达式 | 序列点违规 |
| 常量放比较左边（或开 `-Wparentheses`） | `=` vs `==` |

## 常见坑

| 陷阱 | 分类 | 现象 | 正确做法 |
| --- | --- | --- | --- |
| 有符号溢出 | **UB** | "正常"但换编译器崩 | 用无符号或 `__builtin_add_overflow` |
| `INT_MIN / -1` | **UB** | x86 上 CPU 异常 | 特判 |
| `abs(INT_MIN)` | **UB** | 结果无法表示 | 特判 |
| 数组越界 | **UB** | 静默破坏相邻内存 | 检查下标，用 ASan |
| `memcpy(src, src+2, n)` | **UB** | 重叠区域 | 用 `memmove` |
| 返回局部变量地址 | **UB** | 值随机 | `static`/堆/调用方缓冲区 |
| use-after-free | **UB** | 偶发崩溃 | `free` 后置 NULL |
| double free | **UB** | 堆损坏，无关处崩 | 置 NULL，明确所有权 |
| `free` 非 malloc 指针 | **UB** | 崩溃 | 只 free 自己分配的 |
| 修改字符串字面量 | **UB** | 段错误 | 用 `const char *` |
| `i = i++` | **UB** | 值不确定 | 拆成多条语句 |
| `f(i++, i++)` | **UB** | 顺序不定 | 拆开 |
| `*(unsigned*)&float_var` | **UB** | `-O2` 下错 | `memcpy` 或 union |
| 读未初始化变量 | **UB** | 随机值 | 声明时初始化 |
| `printf("%d", 3.14)` | **UB** | 乱码/崩溃 | 匹配格式串，开 `-Wformat` |
| `-1 < 1u` | 合法但反直觉 | false | 不混用符号性 |
| `sizeof(x) > -1` | 合法但反直觉 | true（错！实测为 false） | 保证非负 |
| `size_t` 反向循环 `i>=0` | 合法但错 | 死循环 | 用 `i-- > 0` 惯用法 |
| `if (x = 5)` | 合法但错 | 恒真 | `==` 或开 `-Wparentheses` |
| 忘 `break` | 合法但错 | 多个 case 执行 | 每个 case 加 break |
| `strncpy` 不补 `\0` | 合法但有隐患 | 字符串没结尾 | 手动补或用 `snprintf` |
| 移位量 >= 位宽 | **UB** | UBSan 抓到 | 先判断 |
| 右移负数 | 实现定义 | 负值 | 转无符号 |
| `char` 符号性 | 实现定义 | 平台差异 | 用 `int8_t`/`uint8_t` |
| `sizeof(enum)` | 实现定义 | 平台差异 | 需要定宽就用 `uint32_t` |
