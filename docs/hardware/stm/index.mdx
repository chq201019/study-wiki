# STM 系列（STM32）

**一句话定位：** 如果你要做的东西需要**确定性**——确定的响应时间、确定的采样精度、十年不断供的芯片——那大概率是 STM32 的方向。

## STM32 和 ESP32 到底差在哪

很多人都问这个，直接给结论：

| 维度 | ESP32 系列 | STM32 系列 |
| --- | --- | --- |
| **无线** | 自带 WiFi + 蓝牙 | **没有**（要外挂模块） |
| **实时性** | 有 RTOS，但无线协议栈会抢占 | 中断响应可达纳秒级，确定性极强 |
| **外设精度** | ADC 一般（12 位，噪声较大） | ADC/DAC/定时器精度与稳定性明显更好 |
| **型号丰富度** | 十几种 | 几千种，从几分钱到几百块，引脚/外设可精准匹配 |
| **开发生态** | Arduino + IDF，上手快 | HAL/LL + CubeMX，规范但上手慢 |
| **供货周期** | 消费级，型号迭代快 | 工业级，长期供货承诺 |
| **典型场景** | 物联网、比赛、智能家居 | 电机控制、工业设备、医疗器械、汽车电子 |

:::tip[怎么选]
- 要**联网**、要**快出成果**、预算紧张 → ESP32
- 要**精密控制**（比如 FOC 电机控制、高精度采样）、要**过认证**、要**长期供货** → STM32
- 不确定 → 先用 ESP32 学通原理，再学 STM32 会快得多，因为底层概念是通的
:::

## 硬件建议

| 阶段 | 推荐板子 | 理由 |
| --- | --- | --- |
| 入门 | STM32F103C8T6 最小系统板（"蓝板"） | 十几块钱，资料最多，踩坑有人兜底 |
| 进阶 | STM32F407 / F411 开发板 | 带 FPU 和外设，能学 DSP 和浮点 |
| 需要调试 | **一定要买 ST-Link V2** | 没有调试器，STM32 学起来会痛苦十倍 |

:::danger[STM32 新手的第一个坑：没有调试器]
和 ESP32 直接 USB 烧录不同，STM32 通常需要 **ST-Link / J-Link** 这类调试器。没有它你只能"烧进去看现象"，出了问题完全不知道代码停在哪。

**调试器不是可选项。** 一块 ST-Link V2 二十块左右，能省掉你几十个小时。
:::

## 学 STM32 之前的前置知识

STM32 的门槛比 ESP32 高，主要高在两点：

1. **C 语言要过关**，尤其是指针、位运算、结构体。HAL 库满屏都是指针和寄存器结构体——如果这些看着眼晕，先去补 [C 语言主线](../../software/c/)
2. **要能看懂原理图和数据手册**，因为 STM32 没有 ESP32 那样"开箱即用"的封装，很多配置要照着手册来

:::tip[别跳过前置知识]
很多人直接上 STM32，卡在"这个寄存器什么意思"上就放弃了。这不是 STM32 难，是**前置知识缺口**。

补法：C 语言的[位运算专章](../../software/c/bitops) + [指针专章](../../software/c/pointers)，看完再回来。
:::
