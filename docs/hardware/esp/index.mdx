# ESP 系列（ESP32 / ESP32-S3）

**为什么建议从这里入门嵌入式：** ESP32 系列自带 WiFi 和蓝牙、价格便宜、社区资料多、烧录不需要额外的下载器（一根 USB 线就够）。同样的钱，你能买到比 STM32 更"好玩"的板子。

## 完整的 ESP 内容在哪

ESP 的内容已经写得很完整了，分在两处，按你现在想干什么选：

| 你现在想做什么 | 去哪 | 内容 |
| --- | --- | --- |
| **我只想三天内做出点东西** | [**快速上手**](../../quickstart/) | 全程米思齐拖积木，不讲原理，从装驱动到 MQTT 上云共 12 页 |
| **我想真正学会，搞懂原理** | [**完整教程 L0~L7**](../../course/) | 43 页，从 C 语言预备知识一直讲到工程化与量产 |
| **我需要查某个具体 API** | [**速查表**](../../reference/) | 引脚映射、Arduino↔IDF 对照、错误码 |

## 完整教程的纵深结构

```
L0 预备知识      ← 计算机怎么工作的、C 语言、嵌入式思维
L1 硬件与工程    ← 开发板、最小系统、工程搭建
L2 编程模型      ← FreeRTOS、组件与 CMake、分区与 OTA、日志与回溯
L3 Arduino 边界  ← Arduino 框架到底是什么，什么时候该脱离它
L4 外设深度      ← GPIO、ADC/DAC、PWM、I2C/SPI/UART、音频、触摸与摄像头
L5 无线与网络    ← WiFi、BLE、lwIP、OTA、ESP-MESH
L6 系统能力      ← 存储、电源、安全、USB、LVGL 图形、AI、语音
L7 工程化        ← 项目模板、测试、性能分析、综合项目
```

**全程 14~20 周**，串行推进。不要跳着看——每一层都是下一层的地基。

## 硬件基线

| 项 | 值 |
| --- | --- |
| 主推开发板 | ESP32-S3-WROOM-1（ESP32-S3-DevKitC-1） |
| Flash / PSRAM | 16MB / 8MB（N16R8） |
| 框架版本 | arduino-esp32 3.3.x（底层 ESP-IDF 5.5.x） |

:::warning[两个必须先知道的板子坑]
1. **板载 RGB 灯引脚分两批**：DevKitC-1 v1.0 在 GPIO48，v1.1 在 GPIO38。教程里两个都写，你的板子选一个不亮就换另一个
2. **GPIO35 / 36 / 37 绝对不能接东西**——被 Octal Flash/PSRAM 内部占用，接了大概率变砖

细节见 [QS-0 开始前必须知道的几件事](../../quickstart/board) 和 [引脚速查](../../reference/pinout)。
:::

## 如果没有板子

ESP32 系列里也有纯软件的仿真路径，但**强烈建议买一块真板子**。嵌入式最核心的能力是"从物理现象倒推代码问题"，仿真给不了你这个。

一块 ESP32-S3 开发板二三十块，比任何教程都值。

## 从 ESP 学完之后

ESP32 让你习惯了「有现成框架、有 WiFi、有大量库」的开发方式。如果你要做**硬实时、精密控制、或者工业产品**，那就该转向 [STM 系列](../stm/)——那里没有 WiFi，但外设精度和确定性完全不同。
