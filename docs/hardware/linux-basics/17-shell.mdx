# 17 Shell 脚本入门

**本课目标**：会写能实际使用的 bash 脚本，知道怎么避免最常见的坑。

## 第一个脚本

```bash
#!/bin/bash
echo "hello world"
```

保存为 `t.sh`，加执行权限，运行：

```bash
chmod +x t.sh
./t.sh
```

:::danger[脚本第一行的 `#!` 不能省]
```bash
#!/bin/bash
```

这叫 **shebang**，告诉系统用哪个解释器执行。

**没有它，系统可能用 `sh`（dash）执行**，而 dash 不支持 `[[ ]]`、数组等 bash 特性，脚本会出现莫名错误。

**规矩：bash 脚本第一行永远写 `#!/bin/bash`。**
:::

## 变量

```bash
name="world"                # 定义（等号两边不能有空格！）
echo "$name"                # 使用（加 $）
echo "${name}s"             # 用 {} 划清边界
```

:::danger[等号两边不能有空格]
```bash
name = "world"              # ❌ 报错：name: command not found
name="world"                # ✅
```

**`name = "world"` 会被当成"执行 name 命令，参数是 = 和 world"。**

（这是 bash 新手第一个坑。）
:::

### 单引号 vs 双引号

本机实测：

```bash
name="world"
echo "hello $name"          # hello world      ← 双引号：展开变量
echo 'single $name'         # single $name     ← 单引号：原样输出
echo "命令替换: $(date +%Y)" # 命令替换: 2026
```

| 引号 | 行为 |
| --- | --- |
| `"..."` | **展开**变量和命令替换 |
| `'...'` | **完全原样**，什么都不展开 |

:::tip[`$(...)` 优于反引号]
```bash
echo $(date)                # ✅ 现代写法，能嵌套
echo `date`                 # ⚠️ 老写法，嵌套麻烦
```
:::

## 参数

本机实测（`./t.sh x y`）：

```text
脚本名: ./t.sh  参数个数: 2
```

| 变量 | 含义 |
| --- | --- |
| `$0` | **脚本名** |
| `$1` `$2` ... | 第 1、2 个参数 |
| `$#` | **参数个数** |
| `$@` | 所有参数（每个独立） |
| `$*` | 所有参数（合成一个字符串） |
| `$?` | **上一条命令的退出码** |
| `$$` | 当前进程 PID |

:::warning[`$@` 和 `$*` 区别]
```bash
for arg in "$@"; do echo "[$arg]"; done    # 每个参数单独一项 ✅
for arg in "$*"; do echo "[$arg]"; done    # 全部合成一项
```

**遍历参数一律用 `"$@"`（带引号）。**
:::

## 条件判断

```bash
if [ "$count" -gt 2 ]; then
    echo "count>2"
else
    echo "count<=2"
fi
```

### 常用测试符

| 测试 | 含义 |
| --- | --- |
| `[ -f file ]` | 是文件 |
| `[ -d dir ]` | 是目录 |
| `[ -e path ]` | 存在 |
| `[ -r/-w/-x ]` | 可读/写/执行 |
| `[ -z "$s" ]` | 字符串为空 |
| `[ -n "$s" ]` | 字符串非空 |
| `[ "$a" = "$b" ]` | 字符串相等 |
| `[ "$a" -eq "$b" ]` | 数字相等 |
| `[ "$a" -ne/-lt/-gt/-le/-ge ]` | 数字比较 |

本机实测：

```bash
[ -f /etc/passwd ] && echo "passwd 是文件"    # 通过
[ -d /tmp ]        && echo "/tmp 是目录"      # 通过
[ -z "" ]          && echo "空字符串"          # 通过
[ -n "abc" ]       && echo "非空"              # 通过
```

:::danger[字符串比较用 `=`，数字用 `-eq`]
```bash
[ "$a" = "$b" ]         # 字符串相等
[ "$a" -eq "$b" ]       # 数字相等

[ "$a" == "$b" ]        # bash 扩展，能用
[ "$a" -eq "$b" ]       # 必须都是数字，否则报错
```

**用 `-eq` 比较非数字会报 `integer expression expected`。**
:::

:::danger[变量一定要加引号]
```bash
[ $VAR = "x" ]          # ❌ VAR 为空时变成 [ = "x" ] → 报错
[ "$VAR" = "x" ]        # ✅ 安全
```

**这是脚本最常见崩溃原因。**
:::

## 循环

```bash
# 遍历列表
for i in 1 2 3; do
    echo "loop $i"
done

# 遍历文件
for f in *.txt; do
    echo "处理 $f"
done

# C 风格
for ((i=0; i<5; i++)); do
    echo $i
done

# while
while [ "$count" -gt 0 ]; do
    echo "w$count"
    count=$((count-1))
done
```

本机实测输出：

```text
loop 1
loop 2
loop 3
w3
w2
w1
```

:::tip[算术用 `$(( ))`]
```bash
count=$((count - 1))        # ✅
count=$((count + 1))        # ✅
((count++))                 # ✅ 简写
```

**注意：`$(( ))` 里变量不用加 `$`。**
:::

## 函数

```bash
f() {
    echo "参数: $1 $#"
}
f a b c                      # 输出：参数: a 3
```

:::warning[bash 函数不能用 `return` 返回值]
```bash
f() { return 42; }          # return 只能返回 0-255 的退出码
x=$(f)                      # 用"输出"来返回值
```

**要"返回"数据，就让函数 `echo`，调用方用 `$(...)` 接。**
:::

## `set -euo pipefail`：脚本的保命设置

:::danger[默认情况下 bash 会"带病继续跑"]
```bash
rm /nonexistent             # 失败
echo "继续执行"              # ❌ 还是执行了
```

**这很危险**——比如前面 `cd` 失败，后面 `rm -rf *` 就删错目录了。
:::

```bash
#!/bin/bash
set -euo pipefail
```

| 选项 | 作用 |
| --- | --- |
| `-e` | **任何命令失败就退出** |
| `-u` | **用到未定义变量就退出** |
| `-o pipefail` | 管道中任一环失败就算失败 |

本机实测 `set -e`：

```text
before
退出码=1
```

（`false` 后面的 `echo "after"` **没有执行**。）

:::tip[为什么 `-u` 很重要]
```bash
set -u
rm -rf "$DIR"/*             # DIR 未定义 → 立刻报错退出
```

**没有 `-u` 的话，`$DIR` 是空字符串，变成 `rm -rf /*` —— 灾难。**
:::

## 退出码

```bash
exit 0                      # 成功
exit 1                      # 一般性错误
```

本机实测：

```bash
bash -c 'exit 3'; echo $?   # 3
```

**约定：`0` = 成功，非 0 = 失败。**

## 完整示例：一个备份脚本

```bash
#!/bin/bash
set -euo pipefail

# 配置
SRC="${1:?用法: $0 <源目录>}"
DEST="${2:-/backup}"
STAMP=$(date +%Y%m%d_%H%M%S)

# 检查
if [ ! -d "$SRC" ]; then
    echo "错误：$SRC 不是目录" >&2
    exit 1
fi

mkdir -p "$DEST"

# 打包
ARCHIVE="$DEST/backup_$STAMP.tar.gz"
tar -czf "$ARCHIVE" -C "$(dirname "$SRC")" "$(basename "$SRC")"

# 结果
SIZE=$(du -h "$ARCHIVE" | cut -f1)
echo "备份完成: $ARCHIVE ($SIZE)"

# 只保留最近 7 个
ls -1t "$DEST"/backup_*.tar.gz 2>/dev/null | tail -n +8 | xargs -r rm -f
echo "已清理旧备份"
```

:::tip[`${1:?消息}` 和 `${2:-默认值}`]
```bash
SRC="${1:?用法: $0 <源目录>}"      # 参数缺失 → 打印消息并退出
DEST="${2:-/backup}"               # 参数缺失 → 用默认值
```

**这两个语法能省掉大量 if 判断。**

（`${VAR:?}` 在 [第 5 课](./05-files) 讲 `rm` 安全时也提过。）
:::

## 常见错误

| 错误 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| 等号两边有空格 | `command not found` | bash 语法 | 去掉空格 |
| 变量不加引号 | 空格导致参数分裂 | 未引用展开 | `"$VAR"` |
| 没写 shebang | 用 dash 执行报错 | 解释器不对 | `#!/bin/bash` |
| 不用 `set -e` | 出错还继续跑 | 默认不退出 | 加 `set -euo pipefail` |
| 用 `-eq` 比字符串 | 报 integer expected | 把数字比较符用在字符串上 | 字符串用 `=` |
| 函数想 `return` 数据 | 只拿到 0-255 | return 是退出码 | 用 `echo` + `$()` |
| `[` 后没空格 | 语法错 | `[` 是命令 | `[ -f x ]` 有空格 |

:::danger[`[` 是一个命令，前后必须有空格]
```bash
[ -f file ]             # ✅
if [ -f file ]; then    # ✅
[-f file]               # ❌ 报错：command not found
```

**因为 `[` 实际是 `test` 命令的别名。**
:::
