# Linux 零基础完整教程

**这条线假设你从没接触过 Linux**，连"终端"都没开过也没关系。

如果你已经会 Linux 基本操作、想学嵌入式 Linux（交叉编译、内核驱动），请走 [Linux 进阶](../linux/)。

## 为什么学 Linux

| 理由 | 说明 |
| --- | --- |
| **服务器全是它** | 网站、数据库、云主机 90% 以上跑 Linux |
| **嵌入式离不开** | 树莓派、路由器、工业设备 |
| **开发必备** | 大部分编程工具链原生在 Linux 上 |
| **免费且可学** | 虚拟机里装一个，随便折腾 |

:::tip[一个现实的好处]
你在 Windows 上遇到的问题（环境配不上、工具装不了），**在 Linux 上往往一条命令解决**。

因为绝大多数开源工具**先支持 Linux**。
:::

## 学习建议

1. **必须动手**。Linux 是操作技能，看会了不等于会用
2. **别怕搞坏**。用虚拟机或云主机，搞坏了重装就行
3. **`man` 是你的朋友**。任何命令不懂就 `man 命令`
4. **`Tab` 键补全、`Ctrl+R` 搜历史**，能省一半打字
