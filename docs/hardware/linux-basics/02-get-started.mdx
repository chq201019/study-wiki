# 02 怎么开始用

**本课目标**：选一种方式，把 Linux 环境真正跑起来。

## 三种方式对比

| 方式 | 安装难度 | 资源占用 | 真实度 | 适合 |
| --- | --- | --- | --- | --- |
| **WSL**（Windows） | ⭐ 最简单 | 低 | 中 | Windows 用户日常学习 |
| **虚拟机** | ⭐⭐ 中等 | 高（2~4GB） | 高 | 想完整体验 |
| **云主机** | ⭐⭐ 中等 | 零 | **最高** | 学运维、要公网 |

:::tip[给你的建议]
- **Windows 用户**：先装 **WSL**，5 分钟就能用
- **想彻底学**：装 **虚拟机**
- **要练服务部署**：买个 **云主机**（新用户常有免费额度）
:::

## 方式一：WSL（推荐 Windows 用户）

### 安装（一条命令）

Windows 10（2004+）或 Windows 11 上，用**管理员身份**打开 PowerShell：

```powershell
wsl --install
```

然后**重启电脑**。重启后会自动要求你设置 Linux 用户名和密码。

:::warning[需要什么前提]
- Windows 10 版本 2004 及以上，或 Windows 11
- **在 BIOS 里开启了虚拟化**（大部分电脑默认开着）

如果报错说"虚拟化未启用"，进 BIOS 打开 `Intel VT-x` 或 `AMD-V`。
:::

### 验证

重启后打开"Ubuntu"（开始菜单里），或 PowerShell 里敲 `wsl`：

```bash
cat /etc/os-release
```

应该看到类似：

```text
PRETTY_NAME="Ubuntu 24.04 LTS"
```

### WSL 的特点

**优点**：

- 启动快（几秒）
- 能和 Windows 文件互通：Linux 里访问 Windows 的 `C:` 盘是 `/mnt/c/`
- 内存占用可控（用完自动释放）

**限制**：

- **没有 systemd**（默认情况下服务管理方式不同）
- 不是真正的完整系统（内核是微软编译的）
- 硬件相关操作受限

:::tip[WSL 里访问 Windows 文件]
```bash
cd /mnt/c/Users/你的用户名/Desktop
```

反过来，Windows 资源管理器里输入 `\\wsl$` 能访问 Linux 文件。
:::

## 方式二：虚拟机（最真实）

### 步骤概览

1. 装虚拟机软件（VirtualBox 免费 / VMware Workstation Player 免费）
2. 下载 Linux ISO 镜像
3. 新建虚拟机，分配内存和硬盘
4. 从 ISO 启动，安装系统

### 1. 装虚拟机软件

**VirtualBox**（免费开源，推荐入门）：到 virtualbox.org 下载安装。

### 2. 下载 ISO

到 [ubuntu.com/download](https://ubuntu.com/download/desktop) 或 [debian.org](https://www.debian.org/download) 下载 **Desktop 版**（有图形界面，好上手）。

文件大概 2~4 GB。

### 3. 新建虚拟机

关键参数建议：

| 配置项 | 建议值 |
| --- | --- |
| 内存 | **4 GB**（至少 2 GB） |
| CPU | 2 核 |
| 硬盘 | **25 GB**（动态分配） |
| 网络 | NAT（默认，能上网就够） |

:::danger[别把内存全部分给虚拟机]
主机 8 GB 内存的话，虚拟机给 4 GB 就够。

**给太多会让主机卡死**（主机自己还要用内存）。
:::

### 4. 安装

挂载 ISO → 启动 → 按向导走（选语言、分区用默认、设用户名密码）。

**装完记得移除 ISO**，否则会一直从光盘启动。

## 方式三：云主机

适合想学**真实服务器运维**的人。

### 常见选择

| 厂商 | 特点 |
| --- | --- |
| 阿里云 / 腾讯云 | 国内，新用户有优惠 |
| 国外厂商 | 常有免费试用 |

选最便宜的 **1 核 1G** 配置就够学习用。

### 连上去

云主机通常**没有图形界面**，只用 SSH 连：

```bash
ssh root@你的服务器IP
```

（下一课和[第 15 课](./15-ssh)详细讲 SSH。）

:::danger[云主机的安全提醒]
1. **改默认密码**（弱密码几小时内就会被扫到）
2. **别用 root 直接对外**（建议建普通用户 + sudo）
3. **开防火墙**，只放行需要的端口
4. **别在上面放敏感数据**
:::

## 本机验证：三件事

不管用哪种方式，跑完这三个命令确认环境正常：

```bash
# ① 看系统版本
cat /etc/os-release | head -3

# ② 看内核版本
uname -r

# ③ 看当前用户
whoami
```

已知环境示例（本站实测，Debian 13）：

```text
PRETTY_NAME="Debian GNU/Linux 13 (trixie)"
NAME="Debian GNU/Linux"
VERSION_ID="13"
```
```text
6.12.94+deb13-amd64
```

## 常用快捷键（先记住这几个）

| 快捷键 | 作用 |
| --- | --- |
| `Tab` | **补全命令/路径**（最有用） |
| `↑` / `↓` | 翻历史命令 |
| `Ctrl+R` | **搜索历史命令** |
| `Ctrl+C` | 中断当前命令 |
| `Ctrl+L` | 清屏（等价 `clear`） |
| `Ctrl+D` | 退出当前 shell |

:::tip[`Ctrl+R` 是效率神器]
敲 `Ctrl+R` 然后输入几个字母，会在历史命令里搜索。

**长命令不用重新敲**，找到直接回车。
:::

## 常见问题

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| WSL 安装报虚拟化未启用 | BIOS 没开 VT-x/AMD-V | 进 BIOS 开启 |
| WSL 启动报错 | Windows 版本太老 | 升级 Windows 或用虚拟机 |
| 虚拟机启动黑屏 | 内存给太少 / 显示设置 | 内存加到 4GB |
| 虚拟机卡顿 | 没装增强工具 | 装 Guest Additions |
| 云主机连不上 | 安全组没开 22 端口 | 控制台改安全组 |
| 中文乱码 | locale 没配 | `export LANG=C.UTF-8` |
