# 逻辑电平与供电预算速查

**接线前先解决两个问题**：这块板子能不能直接接那个模块（电平），以及电源撑不撑得住（电流）。
这两个问题判断错的后果不一样——电平错了当场烧，电流不够表现为"随机重启"，后者最难查。

> **一句话记法**：Arduino AVR 三兄弟是 5V 世界，其余全是 3.3V。
> 3.3V 主控接 5V 输出会烧；5V 主控接 3.3V 模块通常能跑（但模块输出只有 3.3V，
> 要确认 5V 板的高电平阈值够）。

## 常用电平转换

- **3.3V 主控 ← 5V 输出**（HC-SR04 的 ECHO、5V 继电器模块的 OUT）：
  电阻分压 `R1=1k`（串在信号线上）/ `R2=2k`（对地）→ 得 ≈3.3V。
  这是最便宜的方案（两个电阻两毛钱），比买电平转换模块更适合学生。
- **3.3V 输出 → 5V 输入**：多数 5V TTL 的高电平阈值是 2.0V，3.3V 能过，可以直连；
  但 5V CMOS 需要 0.7×VDD=3.5V，3.3V 不够，必须电平转换。
- **I2C 上拉**：3.3V 系统上拉到 3.3V；5V 模块与 3.3V 主控共 I2C 时，
  **上拉必须改到 3.3V**（拆掉模块上拉到 5V 的电阻），否则 SDA/SCL 会长期承受 5V。

## 供电预算（选电源时用）

| 负载 | 典型电流 | 注意 |
|---|---|---|
| ESP32 WiFi 发射峰值 | 250-500mA | USB 口只给 500mA，发射瞬间会掉压重启 |
| ESP8266 峰值 | 300mA | 同上 |
| SG90 舵机 | 空载 100mA，堵转 ~1A | 必须独立 5V |
| MG996R 舵机 | 空载 200mA，堵转 2.5A | 独立 5-6V，电源 ≥3A |
| 28BYJ-48 步进 | 240mA（每相 90mA） | 外部 5V |
| WS2812B | 每颗全亮 ~60mA | N 颗 ×60mA + 20% 余量 |
| MQ-2 加热丝 | ~150mA | 需要持续供电预热 |
| 继电器线圈 | 70-100mA | 与主控分开供电更稳 |
| SD 卡写入 | 100mA 瞬态 | 电源并 100µF |
| HuskyLens 1 代 | 峰值 ~300mA | 5V 独立供电 |
| HuskyLens 2 | 1.5-3W（峰值可达 800mA） | 5V 独立供电，别从主控取 |
| MaixCAM | 5V/1A 起 | 摄像头+屏幕全开更高 |
| MaixCAM2 | 5V/2A | 4K 编码时更高 |

**估算法**：把所有负载的峰值电流加起来 ×1.2，再选电源。
一个"ESP32 + OLED + DHT22"约 600mA（WiFi 峰值占大头），5V/1A 够；
一旦加了舵机或电机，就必须单独的 5V/2A 以上电源。

## 共地与隔离

- 所有"独立供电"的负载（电机、舵机、继电器、灯带）**必须与主控共地**，
  否则信号没有参考电平，表现为"代码没错但完全没反应"。
- 电机、继电器等感性负载：驱动输出要并续流二极管（L298N 内置），
  电机端子并 0.1µF 电容吸收火花。
- 强电（220V）侧与低压侧保持 ≥6mm 爬电距离；调试时断电操作。

## 上电顺序（能救板子）

1. 断电状态下接好所有线
2. 先接所有 GND
3. 再接电源
4. 最后接信号线
5. 执行器（舵机/电机）的独立电源**最后上电**，让主控先跑起来

顺序反了会怎样：先接电源再插信号线，等于带电操作，手一抖碰到相邻引脚就短路。
