# 13 SPI 与总线概念

**本课目标**：理解 SPI，能对比三种总线并选对。

## SPI 是什么

**SPI = Serial Peripheral Interface**，四根线，**全双工、高速**。

| 线 | 全名 | 方向 | 作用 |
| --- | --- | --- | --- |
| **SCLK** | Serial Clock | 主机→从机 | 时钟 |
| **MOSI** | Master Out Slave In | 主机→从机 | 主机发数据 |
| **MISO** | Master In Slave Out | 从机→主机 | 从机发数据 |
| **CS** | Chip Select | 主机→从机 | **片选**（选中哪个从机） |

:::tip[和 I2C 的核心差异]
| | I2C | SPI |
| --- | --- | --- |
| 线数 | **2** | **4**（每多一个从机多一根 CS） |
| 速度 | 100k~400k（标准）/ 1M+ | **几 MHz ~ 几十 MHz** |
| 多设备 | 靠地址 | **靠 CS 片选** |
| 全双工 | ❌ 半双工 | ✅ **全双工** |
| 上拉电阻 | 必须 | 不需要 |

**要快就用 SPI，要省引脚就用 I2C。**
:::

## CS 片选怎么工作

```text
ESP32                    设备A          设备B
 SCLK ────────┬────────────┬──────────────┬────
 MOSI ────────┼────────────┼──────────────┼────
 MISO ────────┼────────────┼──────────────┼────
 CS_A ────────┴── 接设备A的CS（低=选中）
 CS_B ─────────────────────┴── 接设备B的CS
```

:::info[片选是"低电平有效"]
```c
/* 选中设备A：把 CS_A 拉低 */
gpio_set_level(CS_A, 0);
/* 通信 ... */
gpio_set_level(CS_A, 1);      /* 释放 */
```

**为什么是低有效**：这样"没有选中任何设备"就是所有 CS 都高电平，抗干扰更好。

**同一时刻只能有一个 CS 为低**——否则两个设备会同时往 MISO 上说话，数据冲突。
:::

:::warning[多设备时引脚数会涨]
**每多一个 SPI 从机，就多一根 CS 线。**

3 个 SPI 设备 = SCLK + MOSI + MISO + 3×CS = **6 根线**。

（有些设计用译码器/移位寄存器扩展 CS，但会增加复杂度。）
:::

## ESP-IDF 的 SPI 用法

本机 ESP-IDF v5.3.5 的 `peripherals` 示例里有 `spi_master`、`spi_slave`、`spi_slave_hd`。

核心概念：

| 概念 | 说明 |
| --- | --- |
| **SPI 主机（master）** | ESP32 通常是主机 |
| **SPI 总线（bus）** | 共享的 SCLK/MOSI/MISO |
| **SPI 设备（device）** | 挂在总线上的一个从机（有自己的 CS 和参数） |

```c
/* ① 初始化总线（SCLK/MOSI/MISO） */
spi_bus_config_t buscfg = {
    .mosi_io_num = 11,
    .miso_io_num = 13,
    .sclk_io_num = 12,
    .quadwp_io_num = -1,
    .quadhd_io_num = -1,
    .max_transfer_sz = 4096,
};
spi_bus_initialize(SPI2_HOST, &buscfg, SPI_DMA_CH_AUTO);

/* ② 挂一个设备（指定 CS 和时钟参数） */
spi_device_interface_config_t devcfg = {
    .clock_speed_hz = 10 * 1000 * 1000,   /* 10 MHz */
    .mode           = 0,                   /* SPI 模式 0~3 */
    .spics_io_num   = 10,                  /* 这根 CS 归它 */
    .queue_size     = 7,
};
spi_device_handle_t dev;
spi_bus_add_device(SPI2_HOST, &devcfg, &dev);

/* ③ 收发 */
spi_transaction_t t = {
    .length = 8 * 4,          /* 位长度！4 字节 = 32 位 */
    .tx_buffer = send_buf,
    .rx_buffer = recv_buf,
};
spi_device_transmit(dev, &t);
```

:::danger[SPI 的 `length` 单位是"位"不是"字节"]
```c
spi_transaction_t t = {
    .length = 4,              /* ❌ 这是 4 位，不是 4 字节 */
};
spi_transaction_t t2 = {
    .length = 8 * 4,          /* ✅ 4 字节 = 32 位 */
};
```

**这是 ESP-IDF SPI 最常见的错**——传太小会导致只发了几位，设备完全没反应。
:::

## SPI 模式（Mode 0~3）

SPI 有 4 种模式，由两个参数组合：

| 参数 | 含义 |
| --- | --- |
| **CPOL** | 时钟空闲时是高还是低 |
| **CPHA** | 在第一个还是第二个边沿采样 |

| Mode | CPOL | CPHA |
| --- | --- | --- |
| **0** | 0（空闲低） | 0（第一个边沿采样） |
| 1 | 0 | 1 |
| 2 | 1（空闲高） | 0 |
| 3 | 1 | 1 |

:::warning[模式不匹配 = 收到全 0 或全 1]
**大多数设备用 Mode 0**（这也是 ESP-IDF 的默认）。

**如果通信失败，第一个要试的就是换模式。**

设备手册里一般写"SPI Mode 0 (CPOL=0, CPHA=0)"或分开写 CPOL/CPHA。
:::

## 三种总线怎么选

| | **UART** | **I2C** | **SPI** |
| --- | --- | --- | --- |
| 线数 | 2（TX/RX） | 2 | 4 + N×CS |
| 速度 | 通常 ≤ 1 Mbps | 100k~1M | **1~80 MHz** |
| 距离 | 较长（几米） | **短（30cm 以内）** | 短（板内） |
| 多设备 | 一对一 | 地址寻址 | CS 片选 |
| 典型用途 | 调试口、GPS、蓝牙模块 | 传感器、OLED | **屏幕、SD 卡、Flash** |

:::tip[实用选择]
- **调试/打印** → UART
- **接多个低速传感器** → I2C（省引脚）
- **要带宽**（刷屏、读 SD 卡）→ SPI
- **长距离**（几米）→ UART 或 RS485（不是 I2C/SPI）
:::

## 常见 SPI 设备

| 设备 | 典型速率 | 说明 |
| --- | --- | --- |
| ST7735/ST7789 TFT 屏 | 20~40 MHz | 彩色屏，刷一张图几十 ms |
| SD 卡 | 10~25 MHz | 文件系统存储 |
| W25Q Flash | 40~80 MHz | 外部存储 |
| nRF24L01 | 4~8 MHz | 2.4G 无线 |
| MAX6675 | 4 MHz | 热电偶 |

:::warning[屏幕刷新率取决于 SPI 速度]
一块 240×320 的 16 位色屏，一帧是：

```text
240 × 320 × 2 字节 = 153600 字节 ≈ 150 KB
```

在 **10 MHz SPI** 下，传完要：

```text
153600 × 8 / 10e6 ≈ 123 ms   →  约 8 帧/秒
```

在 **40 MHz** 下约 31 ms → 约 32 帧/秒。

**所以刷屏慢往往是 SPI 频率不够，不是 CPU 慢。**
:::

## 常见错误

| 错误 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| `length` 传字节数 | 设备无反应 | 单位是位 | `8 * 字节数` |
| SPI 模式不对 | 收到 0x00/0xFF | CPOL/CPHA 错 | 试 Mode 0/3 |
| CS 没拉低/没接 | 通信失败 | 设备没被选中 | 检查 CS 接线 |
| 两个 CS 同时为低 | 数据冲突 | 逻辑错误 | 保证互斥 |
| 频率设太高 | 偶发错误 | 超过设备上限 | 降到手册值 |
| 线太长 | 通信不稳 | SPI 是板内总线 | 缩短线 |

:::danger[SPI 频率先低后高]
新接一个设备，**先用 1 MHz 调通，再往上加**。

直接用 40 MHz 失败的话，你分不清是"接线错"还是"频率太高"。
:::

## 第二阶段小结

你现在会用的外设：

| 外设 | 能做什么 |
| --- | --- |
| GPIO 输出 | 点灯、驱动继电器 |
| PWM（LEDC） | 调亮度、调电机 |
| GPIO 输入 | 按键、开关 |
| ADC | 电位器、光敏、电池电压 |
| 中断 / 定时器 | 精确响应、周期任务 |
| I2C | 屏幕、传感器 |
| SPI | 彩屏、SD 卡 |

**这些构成了"单片机的基本盘"**——不联网的项目也只用到这些。
