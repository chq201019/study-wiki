# ESP32 零基础完整教程

**这条线假设你没碰过单片机**，连"引脚""烧录"是什么都不知道也没关系。

如果你已经会 ESP32、想深入原理，请走 [ESP 系列教程 L0~L7](../../course/)。

## 为什么选 ESP32 入门

| 优势 | 说明 |
| --- | --- |
| **自带 WiFi + 蓝牙** | 不用外挂模块，直接联网 |
| **一根 USB 线就能开发** | 不需要额外调试器 |
| **生态极好** | 例程多、社区活跃、中文资料丰富 |
| **便宜** | 一块开发板二三十元 |
| **官方框架成熟** | ESP-IDF 自带 20 类官方示例 |

:::tip[和 STM32 的区别]
| | ESP32 | STM32 |
| --- | --- | --- |
| 强项 | **联网**（WiFi/BLE） | **硬实时**（ADC/定时器精度高） |
| 入门难度 | **低**（一根 USB 线） | 中（需要 ST-Link） |
| 典型用途 | 智能家居、传感器上云 | 电机控制、工业设备 |

**想快速做出能联网的东西 → ESP32。想做精密控制 → STM32。**
:::

## ESP32 芯片家族（实测本地 ESP-IDF v5.3.5 支持的目标）

```text
esp32  esp32s2  esp32s3  esp32c2  esp32c3
esp32c5  esp32c6  esp32c61  esp32h2  esp32p4
```

**入门推荐 ESP32-S3**（性能好、生态全、有 USB）。

## 学习建议

1. **必须买板子**。单片机是动手学科，看不会
2. **先跑通再理解**。第一天就点个灯，建立信心
3. **改一处、烧一次、看现象**。一次改五处，出问题不知道是哪处
4. **加打印是最强调试手段**。板子不会说话，全靠串口
