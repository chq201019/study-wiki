# 02 型号怎么选

**本课目标**：看完就知道该买哪块板子，不再纠结。

## 先说结论

:::tip[买这个就够了]
**ESP32-S3 开发板，Flash 16MB + PSRAM 8MB**（常写成 N16R8）。

价格约 25~40 元。

**理由**：

- S3 是当前主力型号，生态最全
- 有**原生 USB**（一根线就能烧录+串口）
- 双核 240MHz，性能充足
- 16MB Flash + 8MB PSRAM 足够做大项目
- 教程、例程都是围绕它写的
:::

## 本地 ESP-IDF v5.3.5 支持的十个目标

```text
esp32    esp32s2   esp32s3
esp32c2  esp32c3   esp32c5   esp32c6  esp32c61
esp32h2  esp32p4
```

| 系列 | 定位 | 说明 |
| --- | --- | --- |
| **ESP32**（经典） | 第一代 | 双核，最老的型号，资料最多 |
| **ESP32-S2** | 单核 + USB | 无蓝牙，过渡产品，不推荐 |
| **ESP32-S3** | **主力** | 双核 + USB + AI 指令，**推荐** |
| **ESP32-C3** | 低成本 | RISC-V 单核，便宜（十几元） |
| **ESP32-C6** | 新一代 | 支持 WiFi 6 + 802.15.4（Zigbee/Thread） |
| **ESP32-H2** | 无 WiFi | 只有 802.15.4 + BLE |
| **ESP32-P4** | 高性能 | 无 WiFi，主打多媒体 |

:::warning[别买太偏的型号]
**ESP32-C2 / C5 / C61 / H2 / P4 这些偏门型号**：

- 中文教程少
- 例程不全
- 遇到问题不好搜

**新手只考虑 ESP32-S3 或 ESP32-C3。**
:::

## S3 vs C3 vs 经典 ESP32

| | 经典 ESP32 | **ESP32-S3** | ESP32-C3 |
| --- | --- | --- | --- |
| 架构 | Xtensa 双核 | Xtensa 双核 | **RISC-V 单核** |
| 主频 | 240 MHz | 240 MHz | 160 MHz |
| 蓝牙 | 经典 + BLE | BLE 5.0 | BLE 5.0 |
| 原生 USB | ❌ | ✅ | ❌（部分型号有） |
| 价格 | 20~30 元 | 25~40 元 | **12~20 元** |
| 教程丰富度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ |

:::tip[怎么选]
- **预算够、想长期玩** → **ESP32-S3（N16R8）**
- **只要便宜、简单联网** → **ESP32-C3**
- **跟着老教程学** → 经典 ESP32（但注意它没有原生 USB）

**如果只能买一块，买 S3。**
:::

## Flash 和 PSRAM 要多大

型号命名里的 `N16R8` 是什么意思：

```text
N16 R8
 │   └─ 8 MB PSRAM
 └───── 16 MB Flash
```

| 配置 | 够用吗 |
| --- | --- |
| N4（4MB Flash，无 PSRAM） | 基础够用，做不了大项目 |
| N8R2（8MB + 2MB PSRAM） | 够用 |
| **N16R8（16MB + 8MB PSRAM）** | **推荐，一步到位** |

:::info[PSRAM 是什么]
**PSRAM = 外挂的"假内存"**，通过 SPI 访问，速度比 SRAM 慢但容量大（2~8 MB）。

**用途**：

- 存图片/字库
- 音频缓冲
- 大缓冲区（摄像头帧）

**做点灯、传感器不需要 PSRAM。** 但差价不大，买了不亏。
:::

## 买板子要注意的几个点

:::danger[这些细节会影响你第一天能不能跑通]
| 要注意 | 原因 |
| --- | --- |
| **有 USB 转串口芯片**（CH340/CP2102） | 否则电脑识别不到 |
| **有 BOOT 和 RESET 按键** | 烧不进去时手动进下载模式 |
| **引脚排针已焊好** | 否则你要自己焊 |
| **明确标了型号**（别买"ESP32 兼容"） | 避免踩坑 |
| **USB 口是 Type-C** | 更耐用，别买 Micro-USB 老化款 |
:::

:::warning[两种"ESP32-S3 开发板"的区别]
| 类型 | USB 口 | 说明 |
| --- | --- | --- |
| **带 USB 转串口芯片** | 1 个（COM 口） | 最常见，兼容性好 |
| **原生 USB（USB-OTG）** | 1~2 个 | S3 原生支持，可模拟键盘等 |

**新手买"带串口芯片"的那种最稳**——插上就是一个 COM 口，不用管驱动细节。
:::

## 一起要买的东西

| 东西 | 价格 | 为什么需要 |
| --- | --- | --- |
| **面包板** | 8~15 元 | 免焊接线 |
| **杜邦线**（公对公/公对母） | 5~10 元 | 连接 |
| **LED + 电阻套装** | 8~10 元 | 点灯实验 |
| **按键** | 3~5 元 | 输入实验 |
| **电位器**（10k） | 2 元 | ADC 实验 |
| **万用表** | 30 元 | **排查供电必备** |

**总计约 80~120 元，能走完前 12 课。**

:::tip[万用表别省]
"板子莫名其妙重启"里至少一半是供电问题。

**量一下电压**比换十根线都快。
:::

## 不建议买的东西（新手阶段）

| 东西 | 为什么不建议 |
| --- | --- |
| 贵的传感器套件（几百元） | 大部分用不上，先学好基础 |
| 摄像头模块 | 新手难度高 |
| 电机驱动 + 电机 | 涉及供电隔离，容易烧板 |
| 一块以上的板子 | 先玩透一块 |
