# 04 装驱动与串口识别

**本课目标**：让电脑正确识别开发板，并知道认不到时怎么一步步查。

:::tip[先别急着装驱动]
**Windows 10/11 自带一部分驱动**，很多板子插上就能用。

**正确顺序**：

1. **先插上看看**（设备管理器里有没有多出 COM 口）
2. 有 → 不用装，直接往下学
3. 没有/有黄色感叹号 → 再装驱动

**盲目装驱动反而可能搞乱系统。**
:::

## 为什么需要"驱动"

开发板通过 USB 连着电脑，但 **USB 和 串口 是两种不同的协议**。

开发板上有一颗**USB 转串口芯片**负责翻译：

```text
电脑 USB  ──→ [USB转串口芯片] ──→ ESP32 的串口
              CH340 / CP2102 …
```

**没有这颗芯片的驱动，电脑就不知道该怎么跟它说话。**

## 三种常见的串口芯片

| 芯片 | 厂商 | 常见于 | 驱动包名 |
| --- | --- | --- | --- |
| **CH340 / CH341** | 南京沁恒 WCH | 最便宜的大量开发板 | `CH341SER` |
| **CH343** | 沁恒（新款） | 部分新板（支持更高速率） | `CH343SER` |
| **CP2102 / CP210x** | Silicon Labs | 官方板、较贵的板 | `slabvcp` |
| **FT232** | FTDI | 老款/工业板 | `ftdibus` / `ftdiport` |

:::info[怎么知道自己板子上是哪颗]
三种办法：

1. **看板子背面芯片丝印**（最准）——用放大镜看那颗靠近 USB 的小芯片
2. **看商品详情页**——卖家一般会写"CH340 串口"
3. **看设备管理器里的硬件 ID**（见下）

**ESP32-S3 有原生 USB 的板子可能不需要转换芯片**，直接就是一个"USB JTAG/serial debug unit"设备。
:::

## 第一步：看电脑认出了什么（Windows）

**右键「开始」→ 设备管理器**，展开 **「端口 (COM 和 LPT)」**。

| 你看到的 | 含义 | 下一步 |
| --- | --- | --- |
| `USB-SERIAL CH340 (COM3)` | ✅ 认出来了 | 记下 **COM3**，不用装驱动 |
| `Silicon Labs CP210x (COM5)` | ✅ 认出来了 | 记下 COM5 |
| `USB 串行设备 (COM4)` | ✅ 认出来了 | 记下 COM4 |
| **「其他设备」里有带黄色感叹号的项** | ❌ 缺驱动 | 装驱动 |
| 什么新设备都没有 | ❌ 更基础的问题 | 换线/换口（见排查表） |

:::danger[一定要区分"没驱动"和"线是充电线"]
**很多 USB 线只有电源线，没有数据线**（充电宝送的那种）。

插上后设备管理器**完全没反应** → 先换一根**确认能传数据**的线（比如手机数据线）。

**这是"认不到板子"最常见的原因，比缺驱动还常见。**
:::

## 第二步：装驱动

### 方法一：用 Mind+ 自带的一键安装（最省事）

Mind+ 安装目录下有现成的驱动包和安装器：

```text
C:\Mind+\drivers\
├── driverInstall.bat        ← 双击运行，自动按 32/64 位装
├── zadig-2.9.exe            ← 用于替换驱动（一般用不到）
├── drivers\
│   ├── dpinst-amd64.exe     ← 64 位驱动安装器
│   ├── dpinst-x86.exe       ← 32 位驱动安装器
│   ├── CH341SER.INF         ← CH340/CH341 驱动
│   ├── CH343SER.INF         ← CH343 驱动
│   ├── slabvcp.inf          ← CP210x 驱动
│   ├── ftdibus.inf / ftdiport.inf   ← FTDI 驱动
│   └── mbedSerial.inf
├── ia64\  x86\              ← USB 串口系统文件（usbser.sys 等）
```

:::tip[怎么装]
**右键 `driverInstall.bat` → 以管理员身份运行**。

它会：

1. 判断你的系统是 32 位还是 64 位
2. 把 `usbser.sys` 等系统文件复制到 `C:\Windows\System32\`
3. 调用 `dpinst-amd64.exe` 批量安装 inf 驱动
4. 一路点「下一步 / 同意」直到完成
5. **重启电脑**

**装完再插板子，设备管理器里应该出现 COM 口。**
:::

### 方法二：只装需要的那一个

不想批量装的话，可以只装对应芯片的驱动：

**右键那个 `xxx.inf` → 安装**。

或者用设备管理器手动指定：

1. 右键带感叹号的设备 → **更新驱动程序**
2. **浏览我的电脑以查找驱动程序**
3. 指向 `C:\Mind+\drivers\drivers` 目录
4. 下一步，等它装完

### 方法三：从厂商官网下载

| 芯片 | 官方下载页 |
| --- | --- |
| CH340/CH343 | 沁恒官网（wch.cn）→ 产品 → 驱动下载 |
| CP210x | Silicon Labs 官网 → CP210x USB to UART Bridge VCP Drivers |
| FTDI | ftdichip.com → VCP Drivers |

:::warning[别从"驱动大全"网站下]
第三方驱动站经常捆绑软件、版本陈旧、甚至有恶意程序。

**只用官方或板子厂家提供的。**
:::

## 第三步：验证

装完驱动（必要时重启）后：

1. 插上板子
2. 设备管理器 → 「端口 (COM 和 LPT)」→ **应该出现新的 COM 口**
3. **拔掉再插上**，看这个 COM 口是否消失又出现（确认就是它）

记下这个 COM 号，后面烧录要选它。

:::tip[用命令行验证更快]
PowerShell 里：

```powershell
# 列出所有串口
Get-CimInstance Win32_SerialPort | Select-Object DeviceID, Description

# 或者看 PnP 设备
Get-PnpDevice -Class Ports | Select-Object Status, FriendlyName
```

输出示例：

```text
DeviceID Description
-------- -----------
COM3     USB-SERIAL CH340 (COM3)
```
:::

## 认不到 / 装了也不行：排查表

| 现象 | 最可能原因 | 怎么查/解决 |
| --- | --- | --- |
| 设备管理器毫无反应 | **USB 线是充电线** | 换确认能传数据的线 |
| 同上 | USB 口坏了/供电不足 | 换口，**别用前面板 USB / 别经 Hub** |
| 同上 | 板子没供电 | 看板上电源 LED 亮不亮 |
| 显示「未知设备」黄叹号 | 缺驱动 | 按上节装对应 inf |
| 装完还是黄叹号 | 驱动装错型号 | 看硬件 ID 确认芯片，重装对应驱动 |
| 两个驱动冲突 | 装过多个版本 | 卸载旧驱动后重装 |
| COM 口出现但打不开 | 被别的软件占用 | 关掉串口助手/Mind+/Arduino IDE |
| 有时能认有时不能 | 接触不良 | 换线、换口、别拉拽 |
| 一插就蓝屏/重启 | 供电短路 | **立刻断电**，检查接线 |

### 看硬件 ID 确认芯片型号

1. 设备管理器 → 右键那个设备 → **属性**
2. **详细信息** 选项卡 → 属性选 **硬件 ID**
3. 看到类似：

```text
USB\VID_1A86&PID_7523     ← 1A86 = 沁恒，7523 = CH340
USB\VID_1A86&PID_55D3     ← CH343
USB\VID_10C4&PID_EA60     ← 10C4 = Silicon Labs，CP2102
USB\VID_0403&PID_6001     ← 0403 = FTDI
```

:::tip[记住这几个 VID]
| VID | 厂商 |
| --- | --- |
| `1A86` | 沁恒（CH340/CH343） |
| `10C4` | Silicon Labs（CP210x） |
| `0403` | FTDI |
| `303A` | **Espressif（乐鑫）** — S3/原生 USB 会出现这个 |

**看到 `303A` 说明是乐鑫原生 USB 设备**，可能不需要装串口驱动。
:::

### 药不能乱吃：什么时候用 Zadig

`zadig-2.9.exe` 在这些情况才用：

- 需要把设备驱动**替换成 WinUSB / libusb**（比如某些网页版工具、特殊烧录工具）
- 设备被 Windows 装成了错误驱动

:::danger[Zadig 用错会导致板子更认不到]
它会把驱动**替换**掉，而不是安装。

**日常开发（Mind+ / Arduino IDE / ESP-IDF）不需要 Zadig。**

用错了可以在设备管理器里"卸载设备 → 删除驱动程序 → 重新插拔"来恢复。
:::

## macOS / Linux 呢

:::tip[这两个系统通常免驱]
**macOS**：CH340 从 10.14 之后部分需要装官方驱动，CP210x 免驱。

**Linux**：内核自带 `ch341`、`cp210x`、`ftdi_sio` 驱动，**插上就用**。

```bash
# Linux 下确认
ls /dev/ttyUSB*          # CH340/CP2102 一般是 ttyUSB0
ls /dev/ttyACM*          # 原生 USB CDC 是 ttyACM0
dmesg | tail -5          # 插上后看内核日志
```

**Linux 上更常见的坑是权限**：

```bash
sudo usermod -aG dialout $USER    # 把自己加入 dialout 组
# 重新登录后生效
```

（[Linux 零基础第 12 课](../../hardware/linux-basics/12-users)讲过 `usermod -aG`。）
:::

## 完整检查清单

:::tip[插板子后的五步确认]
- [ ] **电源 LED 亮了**（有供电）
- [ ] **设备管理器出现新 COM 口**（或 macOS/Linux 出现 `/dev/ttyUSB*`）
- [ ] **拔插一次，COM 号跟着消失/出现**（确认就是这块板）
- [ ] **没有黄色感叹号**
- [ ] **COM 口没有被其他软件占用**（串口助手、Arduino IDE 都关掉）
:::

## 常见错误

| 错误 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| 用充电线 | 完全没反应 | 无线芯 | 换数据线 |
| 盲目装一堆驱动 | 系统混乱 | 没先看现象 | 先插上试 |
| 用 Zadig 替换驱动 | 更认不到 | Zadig 是替换不是安装 | 卸载后重装正确驱动 |
| 不看硬件 ID | 装错型号驱动 | 猜芯片 | 查 VID/PID |
| 开着串口助手就烧录 | 端口被占用 | 独占访问 | 关掉其他软件 |
| 走 USB Hub | 时认时不认 | 供电/信号衰减 | 直插主板后置口 |
