# 07 串口：板子的嘴和耳朵

**本课目标**：把串口用成你最常用的调试工具。

:::tip[为什么这一课最重要]
板子不会说话——**没有屏幕、没有键盘**。

它告诉你的**唯一通道就是串口**。所有问题排查都从这里开始。

**加打印是嵌入式里效率最高的调试手段**，比单步调试还常用。
:::

## 三种打印方式

```c
/* ① 最简单的 C 标准库 */
printf("值 = %d\n", value);

/* ② ESP-IDF 日志（推荐） */
ESP_LOGI(TAG, "值 = %d", value);

/* ③ 直接写串口（底层，一般不用） */
uart_write_bytes(UART_NUM_0, buf, len);
```

`TAG` 要先定义：

```c
static const char *TAG = "myapp";
```

:::tip[`printf` 和 `ESP_LOGI` 怎么选]
| | `printf` | `ESP_LOGI` |
| --- | --- | --- |
| 有无级别 | ❌ | ✅ E/W/I/D/V |
| 有无模块标识 | ❌ | ✅ 靠 TAG |
| 能否按级别过滤 | ❌ | ✅ |
| 是否自动加时间戳 | ❌ | ✅ |

**正式代码用 `ESP_LOGI`**，临时快速验证 `printf` 也行。

（`printf` 在 ESP-IDF 里**默认就输出到串口**，不用额外初始化。）
:::

## 日志级别

```c
ESP_LOGE(TAG, "错误：读传感器失败");       /* E，红色 */
ESP_LOGW(TAG, "警告：电压偏低");           /* W，黄色 */
ESP_LOGI(TAG, "信息：已连接 WiFi");        /* I，绿色 */
ESP_LOGD(TAG, "调试：原始值 = %d", raw);   /* D，默认不显示 */
ESP_LOGV(TAG, "详细：寄存器 = 0x%02X", r); /* V，默认不显示 */
```

:::danger[`ESP_LOGD` 默认不输出，别以为代码没执行]
```c
ESP_LOGD(TAG, "到这里了");    /* 默认看不到！ */
```

**默认级别是 `INFO`**，`D` 和 `V` 被编译/运行期过滤掉了。

打开方式：

```bash
idf.py menuconfig
# → Component config → Log output → Default log verbosity
```

选择 `Debug` 或 `Verbose`。

**Debug 和 Verbose 输出量极大，会明显拖慢程序**——排查完记得改回去。
:::

## 波特率：为什么是 115200

| 波特率 | 说明 |
| --- | --- |
| 9600 | 很慢，老设备常见 |
| **115200** | **ESP-IDF 默认，通用选择** |
| 921600 | 快，烧录时常用 |
| 1500000 | 更快，但容易出错 |

:::danger[波特率不匹配 = 满屏乱码]
```text
���j�a�H�\H�        ← 典型的波特率不对
```

**看到乱码第一反应就是波特率错了。**

ESP-IDF 默认的串口监视器波特率是 **115200**：

```bash
idf.py monitor -b 115200
```

**烧录和监视是两回事**：烧录可以高速（921600），监视必须和固件里配的一致。
:::

## 串口为什么会"丢数据"

:::warning[在中断或高频循环里 printf 会出问题]
```c
void IRAM_ATTR my_isr(void *arg) {
    printf("中断来了\n");       /* ❌ 危险！ */
}
```

**原因**：

1. `printf` 内部可能要加锁、分配内存
2. 串口输出是**阻塞的**（115200 波特率下，一行 40 字符约 3.5 ms）
3. 中断里不允许长时间阻塞

**结果**：中断超时、看门狗复位、数据丢失。

**规矩：中断里只置标志位，把打印放到任务里做。**
:::

### 高频打印会拖慢程序

```c
while (1) {
    ESP_LOGI(TAG, "循环 %d", i++);   /* 每圈都打 → 严重拖慢 */
}
```

**:warning: 115200 波特率下每秒只能传约 11 KB 字符。**

如果每圈打 30 字节，理论上限约 380 圈/秒——**你的循环被串口卡住了**。

**排查性能问题时，先把打印去掉再测。**

## 最实用的调试套路

:::tip[四种打印模式]
**① 标记"到这里了"**

```c
ESP_LOGI(TAG, "① 开始初始化");
init_wifi();
ESP_LOGI(TAG, "② WiFi 完成");
```

**程序卡住时，看最后打印到第几步就知道卡在哪。**

**② 打印关键值**

```c
ESP_LOGI(TAG, "读到 = %d, 期望 = %d", got, expected);
```

**③ 打印地址和指针**（排查崩溃）

```c
ESP_LOGI(TAG, "ptr = %p, size = %d", (void*)buf, len);
```

**④ 十六进制看二进制数据**

```c
ESP_LOG_BUFFER_HEX(TAG, buf, len);      /* 一次性打印整个缓冲区 */
```
:::

## 完整示例

```c
#include <stdio.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "esp_log.h"

static const char *TAG = "serial_demo";

void app_main(void)
{
    /* ① 基本信息 */
    ESP_LOGI(TAG, "=== 启动 ===");

    /* ② 各种格式 */
    int    i = 42;
    float  f = 3.14159f;
    char   s[] = "hello";

    ESP_LOGI(TAG, "整数 %d, 浮点 %.2f, 字符串 %s", i, f, s);
    ESP_LOGI(TAG, "十六进制 0x%04X, 八进制 %o", 255, 8);
    ESP_LOGI(TAG, "指针 %p", (void *)&i);

    /* ③ 缓冲区十六进制转储 */
    uint8_t data[] = {0x01, 0x02, 0xAB, 0xFF};
    ESP_LOG_BUFFER_HEX(TAG, data, sizeof(data));

    /* ④ 每秒打印一次（注意延时别为 0） */
    int count = 0;
    while (1) {
        ESP_LOGI(TAG, "心跳 %d", ++count);
        vTaskDelay(pdMS_TO_TICKS(1000));
    }
}
```

串口输出大概长这样（时间戳格式依配置而定）：

```text
I (312) serial_demo: === 启动 ===
I (322) serial_demo: 整数 42, 浮点 3.14, 字符串 hello
I (332) serial_demo: 十六进制 0x00FF, 八进制 10
I (342) serial_demo: 指针 0x3fc9a1b4
I (352) serial_demo: 01 02 ab ff
I (1362) serial_demo: 心跳 1
I (2362) serial_demo: 心跳 2
```

:::info[`I (312)` 里的 312 是什么]
**开机以来的毫秒数**（系统 tick）。

**排查时序问题特别有用**：

```text
I (100) app: 开始连接
I (3210) app: 连接完成
```

一眼看出连接花了 3.1 秒——如果预期是 1 秒，就有问题。
:::

## 格式符速查

| 类型 | 格式符 | 例子 |
| --- | --- | --- |
| `int` | `%d` | `42` |
| `unsigned` | `%u` | `42` |
| `long long` | `%lld` | —— |
| `float`/`double` | `%f` / `%.2f` | `3.14` |
| `char` | `%c` | `a` |
| 字符串 | `%s` | `hello` |
| 十六进制 | `%X` / `%04X` | `00FF` |
| 指针 | `%p` | `0x3fc9...` |
| `size_t` | `%zu` | —— |
| `uint32_t` | `%"PRIu32"` | 需要 `<inttypes.h>` |

:::danger[`uint32_t` 别直接用 `%d`]
```c
uint32_t x = 4000000000;      /* 超过 int 范围 */
printf("%d", x);              /* ❌ 输出负数/错乱 */
printf("%" PRIu32, x);        /* ✅ 需要 #include <inttypes.h> */
```

**ESP-IDF 自己的示例就是这么写的**（`PRIu32` 宏）。
:::

## 常见错误

| 错误 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| 波特率不对 | 满屏乱码 | 监视器与固件不一致 | 统一 115200 |
| 中断里 `printf` | 崩溃/看门狗 | 阻塞操作 | 只置标志位 |
| 高频循环打印 | 程序变慢 | 串口带宽有限 | 降频或去掉 |
| `ESP_LOGD` 看不到 | 以为没执行 | 默认级别是 INFO | menuconfig 调级别 |
| 打印没有换行 | 输出粘在一起 | 缺 `\n` | 加上 |
| 用 `%d` 打 `uint32_t` | 数字错乱 | 类型不匹配 | 用 `PRIu32` |
| 循环里 `vTaskDelay(0)` | 看门狗复位 | 不让出 CPU | 至少 1 tick |
