# 四路编码器电机驱动模块开发指南

> 资料依据：杭州松甲科技《四路编码器电机驱动模块使用手册 V1.2》（12 页）+ 官方
> `esp32uart.ino` 示例代码 + B 站教程视频
> https://www.bilibili.com/video/BV13rgS6REYJ/

## 一、它和 L298N 的本质区别

L298N 是"给电平就转"的功率放大器。这块板**自带 MCU**，你发的是**结构化指令**：

| | L298N / TB6612 | 这块板 |
|---|---|---|
| 控制方式 | 主控直接输出 PWM + 方向电平 | 发串口/IIC 指令 |
| 占用主控资源 | 每路 3 个 IO（EN+IN1+IN2） | 1 个串口（TX/RX）或 1 条 I2C |
| 编码器反馈 | ❌ 没有 | ✅ 每路 AB 相霍尔 |
| 闭环定速 | ❌ 要自己写 PID | ✅ 驱动板内部做 |
| 测速/定位 | ❌ | ✅ 读脉冲即可 |
| 价格 | ¥12 | ¥128 |

**该选哪个**：只是让轮子转 → L298N 够了。要走直线、要测速、要定距离（循迹、麦轮、竞赛车）→
用这块，因为它把 PID 和编码器采集都做在板子上了，主控不用管。

## 二、接线

### 2.1 电源（最容易接错的地方）

```
外部电源 6~12V ──→ [KF126-5.0-2P 电源端子]
                    ↑ 旁边有拨动开关，不打开板子完全不工作
```

| 电机类型 | 供电电压 |
|---|---|
| 520 编码器电机 | **12V** |
| 310 编码器电机 | 7.4V |
| TT 马达 | **6~8V** |

电压给错轻则没力，重则烧电机。板子正常工作是指示灯**闪烁**。

### 2.2 电机接口（PH2.0-6P）

引脚顺序是固定的：

```
M-  |  5V  |  A  |  B  |  GND  |  M+
```

- `M+` / `M-` 是**电机电源**（大电流）
- `5V` / `GND` 是**霍尔编码器电源**（小电流）
- `A` / `B` 是编码器脉冲输出

**接反会烧编码器**。插之前对照丝印看一眼。

### 2.3 串口接 ESP32（推荐方式）

```
驱动板 TX  →  ESP32 GPIO41 (RX)
驱动板 RX  →  ESP32 GPIO42 (TX)
驱动板 GND →  ESP32 GND          ← 必须接，不共地会收到乱码
```

```cpp
// ESP32 上开第二路串口
Serial1.begin(115200, SERIAL_8N1, 41, 42);   // 参数顺序：RX, TX
```

> 注意 `begin()` 第三个参数是 **RX**、第四个是 **TX**，和直觉相反。
> 写成 TX,RX 的话完全没反应，而且不报错。

### 2.4 IIC 接法（备选）

只用接 SCL / SDA / GND 三根（NC 脚空置），地址 **0x51**。

IIC 是开漏输出，**主控侧必须有上拉电阻**（ESP32 内部上拉较弱，长线要外部 4.7k）。

> 注意 0x51 与部分 EEPROM 地址冲突。同一条总线上有 24C 系列 EEPROM 时改用串口模式。

### 2.5 总线舵机接口（松甲独有）

3Pin 的 `S / + / -`。**它不会主动发指令**，只有在主控向驱动板发串口指令时
顺带转发一次。所以不能把它当独立舵机控制器用，但电机+舵机混合项目能省一个控制器。

## 三、串口指令表（实战核心）

所有指令以 **`!` 结尾**。少了这个感叹号，驱动板**不响应也不报错**——
这是最常见的"发了指令电机不动"的原因。

### 3.1 初始化（必须做）

```cpp
// 1. 设置电机类型：0=520  1=TT  2=310
Serial1.print("$MOTOR_4CH_SET:2!");

// 2. 设置轮径/线数/减速比（做速度换算用，不发的话闭环速度没有物理意义）
//    轮径 cm / 编码器线数 / 减速比
Serial1.print("$MOTOR_PARAM:6,13,30!");

// 3. 可选：编码器方向取反（装车后发现方向反了才用）
Serial1.print("$MOTOR_4CH_SET_ENCPDER_POLARITY:1!");
```

> `ENCPDER` 是手册里的原始拼写（少了 O），照抄即可，改成 `ENCODER` 反而不认。

### 3.2 控制电机

```cpp
// 开环 PWM：-1.0 ~ 1.0
Serial1.print("$Car_Pwm:0.5,0.5,0.5,0.5!");

// 闭环定速：-1.0 ~ 1.0（驱动板内部 PID，四路给同样值能走直线）
Serial1.print("$Car:0.3,0.3,0.3,0.3!");
```

**两套量纲别混**：串口模式是 `-1.0~1.0`，IIC 模式的 0x05/0x06 寄存器是 `-100~100`。

### 3.3 读取反馈

| 指令 | 回包格式 | 用途 |
|---|---|---|
| `$MOTOR_4CH_READ:battery!` | `$MOTOR_4CH_Battery:%d!` | 电源电压 mV |
| `$MOTOR_4CH_READ:encoder_20ms!` | `$MOTOR_4CH_Encoder_20ms:%hd,%hd,%hd,%hd!` | 20ms 内脉冲增量（算速度） |
| `$MOTOR_4CH_READ:encoder_total!` | `$MOTOR_4CH_Encoder_Total:%d,%d,%d,%d!` | 累计脉冲（算距离） |

### 3.4 脉冲数与速度换算

```
电机转一圈脉冲数 = 编码器线数 × 减速比 × 程序倍频数

例：13 线霍尔 × 30 减速比 × 4 倍频 = 1560 脉冲/圈
```

三款官方电机都是 **13 线**。减速比：520 是 1:30、310 是 1:20、TT 是 1:48 或 1:90。

由 20ms 增量算转速：

```
轮速(cm/s) = 20ms脉冲数 × 4倍频修正 ÷ 每圈脉冲数 × 轮周长 ÷ 0.02
```

## 四、ESP32 完整示例（官方代码精简版）

```cpp
#define MOTOR_TYPE 2        // 0=520 1=TT 2=310
#define PIN_RX 41
#define PIN_TX 42

void sendCmd(const char* c) { Serial1.print(c); }

// 读 20ms 编码器增量
bool readEncoder20ms(int16_t out[4]) {
  Serial1.print("$MOTOR_4CH_READ:encoder_20ms!");
  unsigned long t = millis() + 100;
  while (millis() < t) {
    if (Serial1.available()) {
      String r = Serial1.readStringUntil('!');
      if (r.startsWith("$MOTOR_4CH_Encoder_20ms:")) {
        String d = r.substring(24);
        int i1 = d.indexOf(',');
        int i2 = d.indexOf(',', i1 + 1);
        int i3 = d.indexOf(',', i2 + 1);
        out[0] = d.substring(0, i1).toInt();
        out[1] = d.substring(i1 + 1, i2).toInt();
        out[2] = d.substring(i2 + 1, i3).toInt();
        out[3] = d.substring(i3 + 1).toInt();
        return true;
      }
    }
  }
  return false;
}

void setup() {
  Serial.begin(115200);                                   // USB 调试
  Serial1.begin(115200, SERIAL_8N1, PIN_RX, PIN_TX);      // 驱动板
  delay(100);

  sendCmd("$MOTOR_4CH_SET:2!");        // 电机类型
  delay(100);
  sendCmd("$MOTOR_PARAM:6,13,30!");    // 轮径/线数/减速比
  delay(100);
  Serial.println("电机驱动初始化完成");
}

void loop() {
  int16_t enc[4];
  if (readEncoder20ms(enc)) {
    Serial.printf("脉冲: %d %d %d %d\n", enc[0], enc[1], enc[2], enc[3]);
  }
  delay(200);
}
```

> 官方代码里调试输出用 `Serial`、指令用 `Serial1`，两路分开。
> 网上有版本把调试也打在 `Serial1` 上，那样调试文字会混进驱动板的指令流，
> 驱动板可能误解析——**不要那样改**。

## 五、AB/CD 方向默认相反（装车必读）

手册明确写着：**电机接口 AB 与 CD 的控制方向默认是反向的**。

四路同时给正速度时：**A/C 逆时针转，B/D 顺时针转**。

这是为四驱小车设计的——按「左前 A、右前 B、左后 C、右后 D」装，
四路给正速度小车就直线前进。

如果装成别的方式（比如两驱、或者左右装反了），会表现为"给正速度原地打转"。
两种解法：

1. 代码里给 B/D 取负值
2. 用 `$MOTOR_4CH_SET_ENCPDER_POLARITY:1!` 反转编码器极性
   （注意这只改**编码器**方向，不改电机方向，闭环时才有影响）

## 六、常见故障对照

| 现象 | 原因 |
|---|---|
| 发指令完全没反应，指示灯也不亮 | 电源端子旁的**拨动开关没打开** |
| 发指令没反应，指示灯在闪 | 指令**少了结尾的 `!`**，或波特率不是 115200 |
| 收到乱码 | 没共地（GND 没接） |
| 电机转但方向反 | AB/CD 默认反向；或接线接反 |
| 闭环速度不准 | 没发 `$MOTOR_PARAM`，或 `$MOTOR_4CH_SET:` 电机类型选错 |
| 编码器读数为 0 | 霍尔 5V/GND 没接，或 A/B 相接错 |
| 电机弱 | 电压不够（520 要 12V） |
| I2C 扫不到 0x51 | 没上拉电阻；或与 EEPROM 地址冲突，改用串口 |

## 七、教学定位

| 场景 | 是否合适 |
|---|---|
| 四驱竞赛车 / 循迹车 | ✅ 编码器 + 闭环是这类项目的刚需 |
| 需要定距行驶（走 1 米停） | ✅ 读累计脉冲即可，不用自己算 |
| 麦轮车 / 全向底盘 | ✅ 四路独立控制 |
| 电机 + 舵机混合项目 | ✅ 顺带转发总线舵机指令 |
| 只是让轮子转起来 | ⚠️ 用 L298N 更便宜，这块板大材小用 |
| 初学者第一个项目 | ⚠️ 指令格式要求精确，比给电平难 |
