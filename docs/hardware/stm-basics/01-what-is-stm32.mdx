# 01 STM32 是什么

**本课目标**：搞清 STM32 到底指什么，别被型号名和一堆术语搞晕。不用动手。

## 一句话

**STM32 = ST 公司做的 32 位单片机。**

| 部分 | 含义 |
| --- | --- |
| **ST** | 意法半导体（STMicroelectronics） |
| **M** | Microcontroller（单片机） |
| **32** | 32 位架构 |

**它是"什么外设都有、但默认不联网"的通用芯片。**

## 拆解一个型号：STM32F103C8T6

这个型号就是著名的**「蓝板 Blue Pill」**上的芯片。

```text
STM32 F 103 C 8 T 6
 │    │  │   │ │ │ └─ 温度范围：6 = 工业级 -40~85℃
 │    │  │   │ │ └─── 封装：T = LQFP（四面扁平脚）
 │    │  │   │ └───── Flash 容量：8 = 64 KB
 │    │  │   └─────── 引脚数：C = 48 脚
 │    │  └─────────── 系列：103 = 基础型
 │    └────────────── 家族：F1 = Cortex-M3 主流档
 └─────────────────── ST 家 32 位 MCU
```

:::tip[记住这张表，所有 STM32 型号都能读]
规律全家族一致。**新手只需要会读这四段**：家族、系列、引脚数、Flash。

| 位 | 含义 | 常见值 |
| --- | --- | --- |
| 家族 | 内核代次 | F1(M3) / F4(M4) / H7(M7) / G4 / L4(低功耗) |
| 系列 | 外设组合 | 103 基础 / 411 高性能 / 431 带 DAC |
| 引脚 | 封装引脚数 | T=36 / C=48 / R=64 / V=100 / Z=144 |
| Flash | 存储大小 | 6=32K / 8=64K / B=128K / E=512K |
:::

## Cortex-M 是什么

:::info[内核和外设是两回事]
**Cortex-M 是 ARM 公司设计的 CPU 内核**，ST 买了授权，加上自己的外设做成 STM32。

```text
ARM 设计内核（Cortex-M3/M4/M7）
        ↓ 授权
ST 用内核 + 自家外设 = STM32
NXP 用内核 + 自家外设 = LPC
Nordic 用内核 + 自家外设 = nRF
```

**所以不同厂家的 M3 芯片，CPU 指令集是一样的**——但外设寄存器完全不同（不能直接移植）。

| 内核 | 特点 | 典型型号 |
| --- | --- | --- |
| Cortex-M0/M0+ | 最小最省电 | STM32F0 |
| **Cortex-M3** | **经典主流** | **STM32F1** |
| Cortex-M4 | **带 FPU（硬件浮点）** | STM32F4 / G4 / L4 |
| Cortex-M7 | 高性能（400+ MHz） | STM32H7 |
:::

## STM32F103C8T6 有什么

| 资源 | 规格 | 对比 ESP32 |
| --- | --- | --- |
| 内核 | Cortex-M3 @ **72 MHz** | 双核 240 MHz |
| Flash | **64 KB** | 4~16 MB |
| SRAM | **20 KB** | 512 KB |
| 定时器 | 4 个（含 PWM） | 多个 |
| ADC | **12 位，2 个单元** | 12 位（非线性） |
| 通信 | 3×USART、2×I2C、2×SPI、1×CAN | 类似 |
| 无线 | **完全没有** | WiFi + BLE |
| 调试 | **SWD（需要 ST-Link）** | USB 直连 |

:::danger[20 KB SRAM 是什么意思]
**在电脑上随手开个 1 MB 数组，在这里直接编译不过/运行崩溃。**

| 内存类型 | 大小 |
| --- | --- |
| Flash（存代码） | 64 KB |
| **SRAM（运行时变量）** | **20 KB** |

**所以 STM32 的程序普遍"抠门"**：不用 `printf` 全套、不用动态分配、不用大缓冲。

（HAL 库本身就要吃掉几 KB RAM，剩下的才是你的。）
:::

## 和电脑、Arduino 的对比

| | 电脑 | Arduino Uno | **STM32F103** |
| --- | --- | --- | --- |
| CPU | 3~5 GHz | 16 MHz（8 位） | **72 MHz（32 位）** |
| 内存 | 8~32 GB | 2 KB | **20 KB** |
| 存储 | TB 级 | 32 KB | 64 KB |
| 操作系统 | 完整 OS | 裸机 | **裸机 / FreeRTOS** |
| 调试 | 随便 | 串口打日志 | **SWD 单步调试** |
| 价格 | 几千 | 几十 | **十几元** |

:::tip[STM32 相比 Arduino 的最大优势：真正的调试器]
Arduino 只能靠串口打日志猜。

**STM32 用 ST-Link 可以**：

- **单步执行**，看每一行的变量变化
- **打断点**停住程序
- **实时看变量**，不用加打印
- **看寄存器**和外设状态

**这是"能查问题"和"只能猜"的区别。**

（代价：需要多买一个 ST-Link，二十元左右。）
:::

## 它能做什么

| 领域 | 典型应用 |
| --- | --- |
| **电机控制** | 无人机电调、云台、步进电机 |
| **工业控制** | PLC、变频器、传感器采集 |
| **仪表** | 万用表、血压计、电子秤 |
| **汽车电子** | 车身控制、CAN 节点 |
| **消费电子** | 电动牙刷、扫地机 |
| **竞赛/教学** | 电子设计竞赛、课程设计 |

:::warning[它不适合什么]
| 不适合 | 原因 |
| --- | --- |
| 需要 WiFi/蓝牙 | 没有，要外挂模块 |
| 要跑 Linux/带屏幕的复杂 UI | RAM 太小 |
| 需要大容量存储 | Flash 只有几十~几百 KB |
| 快速做原型演示 | 配置比 Arduino 麻烦 |

**这些场景用 ESP32 或嵌入式 Linux 更合适。**
:::

## 学 STM32 最难的地方

:::danger[三个真实的坎]
**① 工具链比 ESP32 复杂**

要装 CubeMX + CubeIDE（或 Keil），配置 SWD 调试器，理解工程结构。

**② 生成的代码很长**

CubeMX 生成的 `main.c` 有几百行初始化，**一开始完全看不懂是正常的**。

**③ 配置错误不报错，只是"不工作"**

时钟没开、引脚没配、中断没使能——代码能编译、能烧进去，就是没反应。

**所以这条线会花很多篇幅讲"为什么"，而不只是"怎么做"。**
:::
