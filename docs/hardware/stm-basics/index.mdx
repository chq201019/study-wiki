# STM32 零基础完整教程

**这条线假设你没碰过单片机**。如果你已经会 ESP32，前 5 课可以快读，但**第 2 课（和 ESP32 的区别）一定要看**——两者的开发方式差别很大。

想系统了解 STM32 家族和生态，请看 [STM32 进阶](../../chips/stm32/)。

## 为什么学 STM32

| 理由 | 说明 |
| --- | --- |
| **工业界用量最大** | 嵌入式岗位 JD 出现率最高 |
| **外设精度高** | ADC、定时器比 ESP32 好得多 |
| **硬实时** | 中断响应确定性高，适合电机控制 |
| **型号极多** | 从几分钱到几百元，按需选 |
| **生态成熟** | HAL 库、CubeMX、CubeIDE 全套免费 |

:::tip[和 ESP32 的定位区别]
| | ESP32 | **STM32** |
| --- | --- | --- |
| 无线 | **自带 WiFi + BLE** | ❌ 默认没有 |
| 强项 | 联网、IoT | **精确控制、实时性** |
| 开发方式 | 一根 USB 线 | **需要 ST-Link 调试器** |
| 库 | ESP-IDF | **HAL / LL / 寄存器** |
| 入门门槛 | 低 | 中 |

**想做能联网的东西 → ESP32。想做电机、仪表、工业设备 → STM32。**

**两个都学最好**——它们的原理相通，只是 API 不同。
:::

## 学习建议

1. **必须买板子和 ST-Link**。没有调试器很多问题无法排查
2. **一定用 CubeMX 起步**。手写初始化寄存器对新手太残酷
3. **先让代码跑起来，再回头理解**。HAL 库有大量初始化代码，一开始看不懂是正常的
4. **每改一处就烧一次**。STM32 的坑大多在配置上，不是语法上
