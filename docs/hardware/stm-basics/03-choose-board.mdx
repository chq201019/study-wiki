# 03 型号怎么选

**本课目标**：看完就知道买哪块板、哪种下载器，不再纠结。

## 先说结论

:::tip[买这个就够了]
| 东西 | 具体型号 | 价格 |
| --- | --- | --- |
| **开发板** | STM32F103C8T6 最小系统板（蓝板） | 12~20 元 |
| **下载器** | **ST-Link V2**（带 SWD 排线） | 15~25 元 |
| **USB-TTL 模块** | CH340 或 CP2102 | 5~10 元 |
| **面包板 + 杜邦线** | —— | 15 元 |

**总计约 50~70 元，能走完前 17 课。**
:::

:::warning[为什么要买 USB-TTL]
**蓝板没有 USB 转串口芯片。**

要 `printf` 输出（[第 9 课](./09-uart)）就必须外接一个 USB-TTL 模块。

**不买的话你只能靠调试器看变量，学起来很别扭。**
:::

## 五个主流家族怎么选

| 家族 | 内核 | 主频 | 特点 | 适合 |
| --- | --- | --- | --- | --- |
| **F1** | Cortex-M3 | 72 MHz | **最经典、资料最多、最便宜** | **入门（推荐）** |
| F4 | Cortex-M4F | 168 MHz | 带硬件浮点、性能强 | 需要算力/DSP |
| G4 | Cortex-M4F | 170 MHz | 模拟外设强（高精度 ADC/DAC） | 电机控制、电源 |
| L4 | Cortex-M4F | 80 MHz | **超低功耗** | 电池设备 |
| H7 | Cortex-M7 | 480 MHz | 性能最强、带大 RAM | 图形/复杂算法 |

:::tip[新手就买 F1]
**理由**：

1. **资料最多**（中文教程、视频、开源项目遍地）
2. **最便宜**（十几元）
3. **够学所有基础概念**（GPIO/串口/定时器/ADC/I2C/SPI/DMA/中断）
4. **出了问题好搜**

**等 F1 玩熟了，再上 F4/G4/L4 都是几小时的事**——HAL 库和 CubeMX 的用法完全一样。
:::

## 蓝板（Blue Pill）要注意什么

:::danger[蓝板有三个要留意的点]
**① 有假货（用 CH32 或翻新芯片冒充）**

表现：CubeMX 生成的代码烧进去不跑、或者调试连不上。

**规避**：买评价好的店，或者直接买 **STM32F103C8T6 官方 Nucleo 板**（贵一些但稳）。

**② 板载 LED 在 PC13，是低电平点亮**

```c
HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_RESET);   /* 亮 */
```

**写 `SET` 反而是灭**——很多人卡在这。

**③ 有些蓝板需要在 ST-Link 的 SWD 上额外接 RST**

连不上时，把 ST-Link 的 RST 接到板子的 NRST 引脚再试。
:::

## 更省心的选择：Nucleo 板

如果预算允许（约 80~150 元），买 **ST 官方 Nucleo 开发板**：

| 优点 | 说明 |
| --- | --- |
| **自带 ST-Link** | 不用另买下载器 |
| **自带 USB 转串口** | 插 USB 就能 printf |
| **板载按键和 LED** | 不用外接元件 |
| **Arduino 兼容排针** | 能插现成模块 |
| **绝对不会是假货** | 官方正品 |

**推荐型号**：`NUCLEO-F103RB`（F1 家族）或 `NUCLEO-F411RE`（F4 家族）。

:::tip[贵在哪里]
多花 60~100 元，换来：

- **省掉买 ST-Link 和 USB-TTL 的麻烦**
- 少踩"假货"和"接线"两个坑
- 第一天就能专心学代码

**如果你预算不紧，Nucleo 是更划算的选择。**
:::

## ST-Link 怎么选

| 类型 | 价格 | 说明 |
| --- | --- | --- |
| **ST-Link V2（山寨版，USB 棒状）** | **15~25 元** | 最常见，够用 |
| ST-Link V2 克隆（带外壳） | 25~40 元 | 稍好一点 |
| ST-Link V3（官方） | 150+ 元 | 支持更多协议，学习不必买 |

:::danger[山寨 ST-Link 的常见问题]
1. **固件太老** → 新版 CubeIDE 可能提示要升级
2. **个别芯片连不上** → 提高 SWD 速度或降速重试
3. **标着 V2 实际是 V2-1 克隆** → 功能差不多，能用

**解决"固件太老"**：用 ST 官方的 **STM32CubeProgrammer** 里的固件升级功能。

**大多数情况下 15 元的就能用。**
:::

## 蓝板接线：SWD 四根线

```text
ST-Link          STM32 蓝板
───────          ──────────
3.3V    ────────  3V3
GND     ────────  GND
SWDIO   ────────  DIO（SWDIO）
SWCLK   ────────  CLK（SWCLK）
（可选）RST ────  NRST（连不上时接上）
```

:::warning[不要接 5V]
```text
ST-Link 的 5V  →  ❌ 别接（蓝板有 3.3V 稳压，接 5V 到 3V3 脚会烧）
```

**只用 ST-Link 的 `3.3V` 引脚供电，或者板子自己用 USB 供电、ST-Link 只接 GND/SWDIO/SWCLK 三根。**

**两种供电方式只能选一种**，别同时供电。
:::

## 完整采购清单

| 东西 | 价格 | 必需 |
| --- | --- | --- |
| STM32F103C8T6 蓝板 | 12~20 元 | ✅ |
| ST-Link V2 | 15~25 元 | ✅ |
| USB-TTL（CH340） | 5~10 元 | ✅ **printf 用** |
| 面包板 | 8~15 元 | ✅ |
| 杜邦线（公对公 + 公对母） | 8 元 | ✅ |
| LED + 电阻套装 | 8 元 | ✅ |
| 按键 | 3 元 | ✅ |
| 电位器 10k | 2 元 | ADC 用 |
| OLED（SSD1306，I2C） | 15 元 | 第 15 课用 |

**合计约 80~110 元。**

:::tip[别买的东西（新手阶段）]
| 东西 | 原因 |
| --- | --- |
| 贵的开发板（H7 等） | 学基础用不上 |
| 电机驱动 + 电机 | 涉及供电隔离，容易烧板 |
| 一堆传感器 | 先学好基础外设 |
| J-Link | 比 ST-Link 贵很多，学习不必 |
:::
