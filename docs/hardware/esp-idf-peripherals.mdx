# ESP-IDF 常用外设代码手册

这份手册补的是「知道 API 名字但不确定正确用法」的空档。每节给可直接编译的最小片段，
以及踩过的坑。全部基于 ESP-IDF v5.5 / v6.1，两个版本 API 兼容。

## 为什么和 Arduino 不一样

| 事情 | Arduino | ESP-IDF |
|---|---|---|
| 入口 | `setup()` / `loop()` | `app_main()`，跑完就返回，必须自己维持 |
| 延时 | `delay(ms)` 阻塞 | `vTaskDelay(pdMS_TO_TICKS(ms))` 让出 CPU |
| 引脚 | `pinMode/digitalWrite` | `gpio_config()` 一次配好，再 `gpio_set_level()` |
| 串口 | `Serial.print` | `ESP_LOGI` 宏 或 `uart_write_bytes()` |
| 错误 | 返回值少查 | 几乎每个 API 返回 `esp_err_t`，**必须查** |

最常见的错误：在 `app_main` 里写个死循环不 `vTaskDelay`，看门狗会在 5 秒后重启板子。

## GPIO

```c
#include "driver/gpio.h"

// 输出：一次配置，之后随时改电平
gpio_config_t io = {
    .pin_bit_mask = (1ULL << GPIO_NUM_4),
    .mode = GPIO_MODE_OUTPUT,
    .pull_up_en = GPIO_PULLUP_DISABLE,
    .pull_down_en = GPIO_PULLDOWN_DISABLE,
    .intr_type = GPIO_INTR_DISABLE,
};
gpio_config(&io);
gpio_set_level(GPIO_NUM_4, 1);

// 输入带内部上拉（按键接地那种）
gpio_config_t in = {
    .pin_bit_mask = (1ULL << GPIO_NUM_5),
    .mode = GPIO_MODE_INPUT,
    .pull_up_en = GPIO_PULLUP_ENABLE,
    .intr_type = GPIO_INTR_NEGEDGE,   // 下降沿中断
};
gpio_config(&in);
```

**坑**：
- `pin_bit_mask` 是 64 位整数，写 `1 << 4` 会因整型提升出问题，必须 `1ULL << 4`。
- GPIO0 / 3 / 45 / 46 是 strapping pin，上电瞬间的电平决定启动模式，别接会在上电时拉高/拉低的东西。
- GPIO19 / 20 是原生 USB，占了就没法用 USB 下载。
- 带 Octal PSRAM 的模组上 GPIO35/36/37 不可用，排针印着也接不通。

## I2C

```c
#include "driver/i2c_master.h"   // v5.x 新驱动，旧的 driver/i2c.h 已废弃

i2c_master_bus_config_t bus_cfg = {
    .i2c_port = I2C_NUM_0,
    .sda_io_num = GPIO_NUM_8,
    .scl_io_num = GPIO_NUM_9,
    .clk_source = I2C_CLK_SRC_DEFAULT,
    .glitch_ignore_cnt = 7,
    .flags.enable_internal_pullup = true,
};
i2c_master_bus_handle_t bus;
ESP_ERROR_CHECK(i2c_new_master_bus(&bus_cfg, &bus));

// 挂一个设备（SSD1306 OLED，地址 0x3C）
i2c_device_config_t dev_cfg = {
    .dev_addr_length = I2C_ADDR_BIT_LEN_7,
    .device_address = 0x3C,
    .scl_speed_hz = 400000,
};
i2c_master_dev_handle_t oled;
ESP_ERROR_CHECK(i2c_master_bus_add_device(bus, &dev_cfg, &oled));

// 写一个字节
uint8_t cmd[2] = { 0x00, 0xAE };
ESP_ERROR_CHECK(i2c_master_transmit(oled, cmd, sizeof(cmd), 100));
```

**坑**：
- v5.0 起 `driver/i2c.h` 的旧 API 仍可用但有弃用警告，新项目用 `i2c_master.h`。
- 内部上拉通常只有几十 kΩ，长导线或高速率时不可靠，**面包板上建议外挂 4.7k**。
- I2C 地址冲突是最常见的接线错误：SSD1306 是 0x3C 或 0x3D，BMP280 是 0x76 或 0x77。
- 挂多个设备时每个设备单独 `i2c_master_bus_add_device`，共用一条 bus。

## SPI

```c
#include "driver/spi_master.h"

spi_bus_config_t buscfg = {
    .mosi_io_num = GPIO_NUM_11,
    .miso_io_num = GPIO_NUM_13,
    .sclk_io_num = GPIO_NUM_12,
    .quadwp_io_num = -1,
    .quadhd_io_num = -1,
    .max_transfer_sz = 4096,
};
ESP_ERROR_CHECK(spi_bus_initialize(SPI2_HOST, &buscfg, SPI_DMA_CH_AUTO));

spi_device_interface_config_t devcfg = {
    .clock_speed_hz = 4 * 1000 * 1000,
    .mode = 0,                    // CPOL=0 CPHA=0，多数模块用 mode 0
    .spics_io_num = GPIO_NUM_10,
    .queue_size = 1,
};
spi_device_handle_t dev;
ESP_ERROR_CHECK(spi_bus_add_device(SPI2_HOST, &devcfg, &dev));
```

**坑**：
- `spi_bus_initialize` 只能对同一个 host 调一次，第二次会报错。
- mode 选错的表现是「读出来全是 0xFF 或 0x00」，不是崩溃。
- SD 卡高速时需要 DMA，`max_transfer_sz` 要给够。

## UART

```c
#include "driver/uart.h"

uart_config_t cfg = {
    .baud_rate = 9600,
    .data_bits = UART_DATA_8_BITS,
    .parity = UART_PARITY_DISABLE,
    .stop_bits = UART_STOP_BITS_1,
    .flow_ctrl = UART_HW_FLOWCTRL_DISABLE,
    .source_clk = UART_SCLK_DEFAULT,
};
uart_driver_install(UART_NUM_2, 1024, 0, 0, NULL, 0);
uart_param_config(UART_NUM_2, &cfg);
uart_set_pin(UART_NUM_2, GPIO_NUM_17, GPIO_NUM_18, UART_PIN_NO_CHANGE, UART_PIN_NO_CHANGE);

// 发
uart_write_bytes(UART_NUM_2, "AT\r\n", 4);

// 收（非阻塞）
uint8_t buf[128];
int n = uart_read_bytes(UART_NUM_2, buf, sizeof(buf), pdMS_TO_TICKS(100));
```

**坑**：
- `uart_driver_install` 必须在 `param_config` 之前。
- UART0 被 `ESP_LOGI` 占用，接了 GPS 或 HC-05 就看不到日志了。**用 UART1/UART2**。
- 波特率不匹配读出来是乱码而不是没数据。

## ADC

```c
#include "esp_adc/adc_oneshot.h"

adc_oneshot_unit_handle_t adc;
adc_oneshot_unit_init_cfg_t init = { .unit_id = ADC_UNIT_1 };
ESP_ERROR_CHECK(adc_oneshot_new_unit(&init, &adc));

adc_oneshot_chan_cfg_t ch = {
    .atten = ADC_ATTEN_DB_12,        // 量程 0~3.1V 左右
    .bitwidth = ADC_BITWIDTH_12,
};
ESP_ERROR_CHECK(adc_oneshot_config_channel(adc, ADC_CHANNEL_0, &ch));

int raw;
adc_oneshot_read(adc, ADC_CHANNEL_0, &raw);
```

**坑（这是 ESP32 最经典的两个）**：
- **ADC2 在 WiFi 开启时完全不可用**。做联网项目只能用 ADC1。
- ADC 非线性严重，默认配置误差可达 ±10%。要准就得用 `adc_cali` 做校准，或外挂 ADS1115。
- 输入不能超过 `atten` 对应的量程，超了会烧引脚。

## PWM（LEDC）

```c
#include "driver/ledc.h"

ledc_timer_config_t t = {
    .speed_mode = LEDC_LOW_SPEED_MODE,
    .duty_resolution = LEDC_TIMER_10_BIT,   // 0~1023
    .timer_num = LEDC_TIMER_0,
    .freq_hz = 5000,
    .clk_cfg = LEDC_AUTO_CLK,
};
ledc_timer_config(&t);

ledc_channel_config_t c = {
    .gpio_num = GPIO_NUM_6,
    .speed_mode = LEDC_LOW_SPEED_MODE,
    .channel = LEDC_CHANNEL_0,
    .timer_sel = LEDC_TIMER_0,
    .duty = 0,
    .hpoint = 0,
};
ledc_channel_config(&c);

ledc_set_duty(LEDC_LOW_SPEED_MODE, LEDC_CHANNEL_0, 512);   // 50%
ledc_update_duty(LEDC_LOW_SPEED_MODE, LEDC_CHANNEL_0);     // 必须调这个才生效
```

**坑**：
- `ledc_set_duty` 之后必须 `ledc_update_duty`，忘了就没反应——这是最常见的「PWM 没用」原因。
- 舵机要 50Hz（周期 20ms），分辨率别设太高，否则频率算不出来。
  50Hz + 14 位在 80MHz 时钟下超出范围，用 10 位。

## NVS（存配置）

```c
#include "nvs_flash.h"
#include "nvs.h"

nvs_flash_init();   // app_main 里调一次

nvs_handle_t h;
nvs_open("cfg", NVS_READWRITE, &h);

int32_t threshold = 40;
nvs_set_i32(h, "thr", threshold);
nvs_commit(h);

int32_t got = 0;
if (nvs_get_i32(h, "thr", &got) == ESP_OK) {
    // 读到了
}
nvs_close(h);
```

**坑**：
- 不 `nvs_commit` 掉电就丢。
- 键名最长 15 字符。
- 擦写寿命约 10 万次，别在循环里写。

## 错误处理约定

ESP-IDF 的 API 几乎都返回 `esp_err_t`。两种处理方式：

```c
// 关键路径：失败就停，ESP_ERROR_CHECK 会打印文件名行号并 abort
ESP_ERROR_CHECK(i2c_new_master_bus(&cfg, &bus));

// 可恢复的：自己判断
esp_err_t err = nvs_get_i32(h, "thr", &got);
if (err == ESP_ERR_NVS_NOT_FOUND) {
    ESP_LOGW(TAG, "还没存过，用默认值");
} else if (err != ESP_OK) {
    ESP_LOGE(TAG, "读取失败: %s", esp_err_to_name(err));
}
```

**坑**：不检查返回值是最常见的隐形 bug。I2C 设备没接上时 `transmit` 返回错误，
不查就会以为「程序跑了但屏幕不亮」，然后去怀疑屏幕坏了。

## 看门狗

```c
// 长任务里定期喂狗，或干脆用循环 + vTaskDelay 让出 CPU
while (1) {
    do_work();
    vTaskDelay(pdMS_TO_TICKS(10));   // 这一行能避免 90% 的看门狗重启
}
```

任务看门狗默认 5 秒。任何长时间不让出 CPU 的循环都会触发重启。
