# Vim 实用指南

**本课目标**：掌握能覆盖日常 90% 编辑工作的命令集，不再被"退出 Vim"困住。

## 先说最要紧的

```text
Esc         回到普通模式（不知道在哪就先按它）
:w          保存
:q          退出
:wq 或 :x   保存并退出
:q!         不保存强制退出
```

:::danger[卡住时的通用解法]
1. **按 `Esc`**（可能按两下）
2. 输入 `:q!` 回车（丢弃修改退出）
3. 如果提示 `E37: No write since last change`，那就是要靠 `!` 强制

**`Ctrl+C` 在 Vim 里不是"取消"，它只是中断当前命令。**
:::

## 四个模式

| 模式 | 进入 | 用途 |
| --- | --- | --- |
| **普通（Normal）** | `Esc` | **移动、删除、复制（主战场）** |
| 插入（Insert） | `i a o` 等 | 打字 |
| 可视（Visual） | `v` / `V` / `Ctrl+v` | 选中 |
| 命令行（Cmdline） | `:` | 保存、替换、设置 |

:::tip[核心心智模型：动词 + 对象]
```text
d  +  w       删除到下一个词
c  +  i"      修改引号内的内容
y  +  a{      复制整个花括号块（含括号）
```

**学会这个组合逻辑，命令就不用背了** —— 你能自己推导出几百种组合。
:::

## 移动（普通模式）

```text
h j k l           左 下 上 右
w / b             下一个词 / 上一个词
0 / ^ / $         行首 / 第一个非空 / 行尾
gg / G            文件开头 / 结尾
:42               跳到第 42 行
Ctrl+d / Ctrl+u   下半页 / 上半页
%                 跳到匹配的括号
```

:::tip[数字前缀能重复任何动作]
```text
5j        下移 5 行
3w        前进 3 个词
d2w       删除 2 个词
```
:::

## 编辑

```text
i      光标前插入
a      光标后插入
o      下方新开一行插入
O      上方新开一行插入
A      行尾插入

x      删一个字符
dd     删整行
dw     删到下一个词
D      删到行尾

yy     复制整行
p      粘贴到下方
P      粘贴到上方

u      撤销
Ctrl+r 重做
.      重复上一次修改   ← 最有用的一条
```

:::danger[`.` 的威力被严重低估]
```text
想删除 10 行里的某个词：
  1. 找到第一处，删掉（比如 ciw）
  2. 按 n 跳到下一处
  3. 按 . 重复删除
```

**"改一次 + 点号重复"是 Vim 最高效的工作方式。**
:::

## 文本对象（i / a）

| 对象 | 含义 |
| --- | --- |
| `iw` / `aw` | 词 / 词含空格 |
| `i"` / `a"` | 引号内 / 含引号 |
| `i(` / `a(` | 括号内 / 含括号 |
| `i{` / `a{` | 花括号内 / 含括号 |
| `it` / `at` | 标签内 / 含标签（HTML） |
| `ip` / `ap` | 段落 |

```text
ci"       修改引号内的内容（删完内容后直接进入插入模式）
di{       删除花括号内所有内容
ya<       复制整个尖括号块
```

:::tip[`i` 与 `a` 的区别]
- **`i`（inner）** —— 只要"里面"，不含边界
- **`a`（around）** —— 含边界字符

```text
文本： foo("bar")
ci"  →  foo("")          （只改引号内）
ca"  →  foo()            （连引号一起改）
```
:::

## 搜索与替换

```text
/pattern       向下搜索
?pattern       向上搜索
n / N          下一个 / 上一个
*              搜索光标下的词（超好用）
:noh           取消高亮
```

```text
:s/old/new/        当前行第一个
:s/old/new/g       当前行全部
:%s/old/new/g      整个文件
:%s/old/new/gc     整个文件，每个都确认
:10,20s/a/b/g      指定行范围
```

:::warning[替换内容里的特殊字符]
```text
替换路径时 / 要转义：:%s/\/usr/\/opt/g
或者换分隔符：      :%s#/usr#/opt#g
```
:::

## 可视模式

```text
v        字符选择
V        行选择
Ctrl+v   块选择（列编辑）
```

:::tip[块选择是改对齐/加注释的利器]
```text
Ctrl+v  →  选中几行的第一列  →  I  →  输入 //  →  Esc
（给多行同时加行注释）
```
:::

## 分屏与标签

```text
:sp file        水平分屏
:vsp file       垂直分屏
Ctrl+w 加方向键  切换窗口
:tabnew file    新标签
gt / gT         下一个 / 上一个标签
```

## 宏

```text
qa          开始录制到寄存器 a
（做一系列操作）
q           结束录制
@a          执行一次
@@          重复上一次宏
10@a        执行 10 次
```

:::tip[宏 + 数字前缀 = 批量处理]
**典型用法**：给 100 行批量加引号

```text
qa  →  I"  →  Esc  →  A"  →  Esc  →  j  →  q
100@a
```
:::

## 十个最提效的操作

| 操作 | 效果 |
| --- | --- |
| **`.`** | 重复上次修改 |
| **`*`** | 搜索光标下的词 |
| **`ci"`** | 改引号内内容 |
| **`gg=G`** | 全文自动缩进 |
| **`Ctrl+v` + `I`** | 多行同时插入 |
| **`:%s///gc`** | 全文替换并逐个确认 |
| **`:e!`** | 丢弃修改重新加载 |
| **`gd`** | 跳到局部定义 |
| **`q:`** | 打开命令历史（可编辑后执行） |
| **`:set paste`** | 粘贴时不自动缩进 |

:::danger[粘贴时缩进乱套]
**终端里直接粘贴会被当成输入，自动缩进会叠加。**

```text
:set paste     粘贴前开
:set nopaste   粘贴后关
```

**Vim 还可以 `:set pastetoggle=<F2>` 一键切换；或者直接用 `"+p`（系统剪贴板寄存器）粘贴。Neovim 0.10 起移除了 `pastetoggle`，它默认开启括号粘贴（bracketed paste），自动缩进不会再叠加。**
:::

## 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 打字变成命令 | 在普通模式 | 按 `i` 进插入模式 |
| 退不出去 | 有未保存修改 | `:q!` 或 `:wq` |
| 方向键输出 ABCD | vi 兼容模式 / 终端类型识别不对 | 用 `hjkl` 或设 `:set nocompatible` |
| 粘贴缩进错乱 | 自动缩进叠加 | `:set paste` |
| 中文显示乱码 | 编码设置 | `:set encoding=utf-8` |
| 搜索时大小写必须完全对上才找得到 | 默认区分大小写 | `:set ignorecase smartcase` |
| 撤销只能撤一次 | 老版本 | 现代 Vim 有撤销树，`g-` / `g+` 走时间线 |

:::tip[新手最小可用集]
**先只用这 12 个：**

```text
Esc  i  :w  :q  :wq  :q!
h j k l  dd  yy  p  u  /
```

**够用了再扩展。一次学太多会全都记不住。**
:::
