# 驱动时序与寄存器速查

这份文档只收**最容易写错、错了最难查**的那部分：寄存器地址、时序参数、两代芯片的差异。
写驱动前先看这里，比翻数据手册快。

## MAX7219 / MAX7221

- SPI **Mode0**，16bit 帧：高 8 位 = 寄存器地址，低 8 位 = 数据；**LOAD/CS 上升沿锁存**。
- 寄存器：
  - `0x01-0x08` = DIG0-DIG7（8 行数据）
  - `0x09` = 译码模式（`0x00` 不译码/点阵用，`0xFF` 全 BCD 译码）
  - `0x0A` = 亮度（`0x00-0x0F`）
  - `0x0B` = 扫描界限（`0x00-0x07`，表示显示几位）
  - `0x0C` = 关机（`0x00` 正常，`0x01` 关屏）
  - `0x0F` = 显示测试（`0x01` 全亮）
- **初始化顺序**：关机 → 扫描界限 → 译码模式 → 亮度 → 关显示测试 → 清屏 → 开机。
  顺序反了会出现"花了半天点不亮"或"点阵乱码"。
- 级联：DOUT → 下一片 DIN，共用 CLK/LOAD；**发送时先写最远的那一片**。
- 5V 供电，单颗最大段电流约 100mA；8×8 点阵全亮需 5V/1A 以上，
  **不要从 3.3V 板取电**。

## MFRC522（RC522）寄存器

- **3.3V 供电**（5V 会烧），SPI Mode0，SCK ≤10MHz。
- 关键寄存器：
  - `0x00` CommandReg（`0x0F` softReset / `0x0C` transceive）
  - `0x01` ComIEnReg、`0x04` ComIrqReg、`0x05` DivIrqReg、`0x06` ErrorReg
  - `0x09` FIFODataReg、`0x0A` FIFOLevelReg
  - `0x0C` ControlReg、`0x0E` BitFramingReg
  - `0x14` TxControlReg（`0x03` 打开天线）
  - `0x24` ModWidthReg、`0x26` RFCfgReg（接收增益）
  - `0x2A-0x2D` CRC 结果
- 常用流程：softReset → 设置定时器 → 天线开 → REQA(`0x26`) →
  anticoll(`0x93 0x20`) → select → 读写块。
- 读卡距离 3-5cm；**天线周围 2cm 内不要有金属**（金属会吃掉磁场）。
- 与主控共用 SPI 时，注意其它设备的 CS 不要同时拉低。

## SH1106 与 SSD1306 的差异（最坑的一对）

这两个屏长得一样、接口一样、价格一样，但**显存布局不同**：

| | SSD1306 | SH1106 |
|---|---|---|
| 显存 | 128×64 | **132×64** |
| 可见区起点 | 列 0 | **列 2** |
| 寻址模式命令 | 有 `0x20` | **无**，只能页地址模式 |

**用 SSD1306 的库去驱动 SH1106，画面会整体右移 2 列**，右边缘内容跑到左边，
学生以为是屏坏了。反过来用 SH1106 库驱动 SSD1306 则左边缺 2 列。

正确做法：
- SH1106 用 U8g2 的 `U8G2_SH1106_128X64_NONAME_F_HW_I2C`，或 Adafruit_SH110X 库
- 确认屏幕型号的方法：看模块背面的丝印，或查卖家页面（0.96" 多为 SSD1306，1.3" 多为 SH1106）

## DHT11 / DHT22 单总线时序

- 时序：主机拉低 ≥1ms 起始 → 释放 → 传感器响应（低 80µs + 高 80µs）→ 40bit 数据。
- **每位以 50µs 低电平开始**，高电平 26-28µs = `0`，70µs = `1`。
- 采样间隔：**DHT11 ≥1s，DHT22 ≥2s**；读太快会返回 NaN。
- 上拉 4.7k-10k；线长 >1m 时降低上拉阻值或并 100nF 滤波。
- DHT11 与 DHT22 时序不同，**必须用对应的驱动类型**，写错会解析出完全错误的数据。

## HC-05 蓝牙模块 AT 模式

- 进入 AT 模式：**KEY/EN 接高电平后再上电**（或上电后拉高），LED 慢闪（2s 一次）。
- AT 串口 **38400 8N1**（部分批次 9600），命令需以 `\r\n` 结尾。
- 常用命令：
  - `AT`（测试）、`AT+VERSION`（版本）
  - `AT+NAME=xxx`（改名字）、`AT+PSWD=1234`（改配对码）
  - `AT+ROLE=1`（主）/ `0`（从）
  - `AT+UART=9600,0,0`（改通信波特率）、`AT+RESET`（重启生效）
- 通信模式默认 9600；模块 IO 是 3.3V，与 3.3V 主控可直连，
  与 5V 主控（Arduino）连接时模块 RX 建议分压。

## 28BYJ-48 步进电机 + ULN2003

- 四相八拍励磁顺序：`A→AB→B→BC→C→CD→D→DA`（正转），反序反转。
- 减速比 1/64，步距角 5.625°/64；**输出轴转一圈需 64×32 = 2048 个八拍**。
- 每相 90mA，**必须外部 5V**；ULN2003 是灌电流驱动，IN 高电平导通。
- 常见"丢步"原因：供电不足、共地不良、节拍间隔 <1ms。

## L298N 与 TB6612FNG 对比（选型用）

| 项 | L298N | TB6612FNG |
|---|---|---|
| 电机电压 | 5-35V | 2.5-13.5V |
| 连续电流 | 2A/路 | 1.2A/路（峰值 3.2A） |
| 压降/发热 | **高**（达林顿，需散热片） | **低**（MOSFET） |
| 控制 | IN1/IN2 + ENA PWM | IN1/IN2 + PWM + **STBY** |
| 逻辑电平 | 5V | 3.3V/5V 兼容 |
| 适用 | 大电压、低成本 | 电池供电、高效率小车 |

**给学生的建议**：做电池供电的小车优先 TB6612——压降小意味着同样的电池跑得久，
而且不用散热片。L298N 适合"手上有现成的 12V 电源"的场景。
注意 TB6612 的 **STBY 脚必须拉高**才工作，忘了这个会出现"代码全对但电机不转"。

## WS2812B 时序与供电

- 800kHz，`T0H` 0.4µs / `T0L` 0.85µs，`T1H` 0.8µs / `T1L` 0.45µs，
  容差 ±150ns；**中断会破坏时序**（所以关闭中断或用硬件外设驱动）。
- 5V 供电。DIN 高电平阈值 `0.7×VDD = 3.5V`，
  **3.3V 主控直连可能不亮** → 电平转换，或把灯带供电降到 4.5V（串一个二极管）。
- 首颗前串 330Ω 限流，电源并 1000µF 电容；长灯带每 5m 补一次电。

## 串口协议的常见错误

- **TX/RX 必须交叉**：设备 TX → 主控 RX，设备 RX → 主控 TX。
  接成 TX-TX 的现象是"完全没数据"，而且学生常以为是模块坏了。
- **波特率必须两边一致**，且要用标准值（9600/19200/38400/57600/115200）。
- **共地**：只接 TX/RX 不接 GND 时，双方没有共同参考电平，数据会乱码。
- 与 3.3V 设备通信时，5V 主控的 TX 要分压到 3.3V 再进设备 RX。
