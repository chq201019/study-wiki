# 17 硬件设计要点

**本课目标**：能看懂并检查一块 STM32 最小系统板，知道哪些地方容易画错。

## 最小系统必须有六样

```text
① 电源      3.3V（含 VDDA 模拟电源）
② 去耦电容  每个电源引脚一个 100nF
③ 晶振      8MHz + 两个负载电容（HSE）
④ 复位电路  NRST 上拉 10k + 100nF 到地
⑤ BOOT0     下拉到地（从 Flash 启动）
⑥ 调试口    SWDIO / SWCLK / GND（+ 可选 SWO）
```

:::danger[少一样会怎样]
| 缺什么 | 现象 |
| --- | --- |
| 去耦电容 | 能跑，但随机死机、ADC 乱跳 |
| **BOOT0 悬空** | **随机进不了程序**（可能进系统存储器） |
| 复位电容 | 上电复位不可靠，偶发不启动 |
| VDDA 没接 | ADC 完全不能用 |
| 负载电容 | 晶振不起振或频率偏 |
:::

## 去耦电容：位置比数量重要

:::danger[100nF 必须紧贴引脚，不是"板上有就行"]
```text
❌ 错误：电容放在板子另一头，靠走线连过来
    → 走线的电感让高频去耦失效

✅ 正确：电容和引脚在同一面，走线 < 2mm
```

**每个 VDD 引脚配一个 100nF**（F103C8T6 有 3 个 VDD + 1 个 VDDA）。

**另外整板再放 1~2 个 10µF** 做低频储能。
:::

**布局要点**：

- 电容的地端**直接打过孔到地平面**（不要走长线到地）
- 电源先进电容再进芯片（不是先芯片再电容）
- 晶振靠近芯片，下面是**完整地平面，不走任何信号线**

:::tip[怎么判断去耦够不够]
**用示波器看 VDD 上的纹波**：

- 正常应该在几十 mV 以内
- 如果看到几百 mV 的尖峰，去耦不足或地平面被割裂

**另外一个实用技巧**：把 ADC 采自己的 VDDA/2，看读数跳动量——**跳得厉害就是电源不干净**。
:::

## 晶振与负载电容

:::info[8MHz 晶振 + 两个电容到地]
```text
         ┌── OSC_IN ────┬─── 8MHz ────┬── OSC_OUT ──┐
         │              │             │             │
        CL1           晶振           CL2           芯片
         │              │             │
        GND            GND           GND
```

**CL1 = CL2 ≈ 2 × (CL - Cstray)**

- `CL` 是晶振规格书里的负载电容（常见 8pF、10pF、12pF、20pF）
- `Cstray` 是杂散电容（PCB 布线带来，约 3~5pF）
:::

:::warning[算一个实际的例子]
晶振 CL = 10pF，杂散按 4pF：

```text
CL1 = CL2 = 2 × (10 - 4) = 12pF
```

**选 12pF 或 15pF 的标准值**。

**配错会怎样**：

- 电容太大 → 起振慢、频率偏低、极端情况下不起振
- 电容太小 → 频率偏高、容易受干扰停振

**很多开发板用的是 20pF，但那只是"能用"，不代表最优。**
:::

:::danger[晶振下面不能走线]
**晶振是敏感的高阻节点**，下面走任何信号线都会耦合干扰。

**规矩**：

- 晶振下方铺地，**不走任何走线**（包括地线也只走整片地平面）
- 晶振外壳接地（四脚晶振有两脚是外壳）
- 走线尽量短粗
:::

## 复位电路

```text
        3.3V
          │
         10kΩ
          │
NRST ─────┼──── 100nF ──── GND
          │
        按钮 ──── GND
```

:::tip[为什么是 10k + 100nF]
- **10k 上拉**：保证常态高电平（不复位）
- **100nF 到地**：上电时产生一个低电平脉冲，让芯片可靠复位
- **时间常数 = 10k × 100nF = 1ms**，足够覆盖电源上升时间

**按钮并联在电容上**（按下时直接拉低）。
:::

:::warning[ST 的 NRST 内部已经有上拉]
F103 的 NRST 内部有约 40kΩ 上拉，**理论上外部可以省掉**。

**但仍然建议外接**：

- 内部上拉较弱，长走线时抗干扰差
- 加 100nF 才能保证上电复位时序

**注意**：外部 10k 和内部 40k 并联后约 8k，不影响功能。
:::

## BOOT0：最常见的"程序烧了但不跑"

:::danger[BOOT0 悬空 = 行为不可预测]
| BOOT0 | BOOT1 | 启动位置 |
| --- | --- | --- |
| **0** | x | **主 Flash（正常运行）** |
| 1 | 0 | 系统存储器（串口下载） |
| 1 | 1 | SRAM（调试用） |

**BOOT0 必须通过 10kΩ 下拉到地**（不要悬空！）。

**悬空时它可能被干扰拉高**，于是芯片进了系统存储器，你的程序当然不跑。
:::

:::tip[产品上怎么做 BOOT0]
**量产板**：直接 10k 下拉到地，不引出（正常永远从 Flash 启动）。

**开发板**：用一个跳线帽选择（下拉电阻保留，跳线短接到 3.3V 时进下载模式）。
:::

## SWD 调试口

:::info[最少三根线]
```text
SWDIO   ── 数据（双向）
SWCLK   ── 时钟
GND     ── 地

（可选）
SWO     ── 单线输出，用于 printf 调试
NRST    ── 复位（可选，但强烈建议接）
3.3V    ── 给调试器检测目标电压（不要用它供电给板子）
```
:::

:::warning[SWD 也怕干扰]
- SWDIO/SWCLK 走线尽量短（< 10cm）
- 调试口旁边加 100nF 去耦
- **不要把 SWD 引脚复用成 GPIO 后忘了恢复**——会连不上调试器

**救命办法**：把 BOOT0 拉高进系统存储器，用串口擦掉 Flash，再恢复。
:::

## ADC 供电的特殊要求

:::danger[VDDA 和 VSSA 必须单独处理]
```text
VDD  ──┬── 100nF ──┬── VDD 引脚
       │           │
     10µF         GND

VDDA ──┬── 100nF ──┬── VDDA 引脚
       │           │
      1µF          VSSA（单独接地）
```

**要点**：

- VDDA 前面串一个**磁珠或 10Ω 电阻**（和数字电源隔离）
- 磁珠后再加 1µF + 100nF
- VSSA 单独走线到地，不和其他地混在一起
:::

:::tip[ADC 精度差，先查电源]
**检查顺序**：

1. VDDA 上的纹波（示波器 AC 耦合，应该 < 10mV）
2. VDDA 滤波电容是否紧贴引脚
3. 数字信号线是否从模拟区穿过
4. ADC 输入源阻抗是否过大（见 [第 06 课](./adc-deep)）
:::

## 打板前自查清单

:::tip[这 20 项检查能省一次打板]
**电源**

- [ ] 每个 VDD 引脚都配了 100nF，且紧贴
- [ ] VDDA 有独立滤波（磁珠 + 1µF + 100nF）
- [ ] VSSA 单独接地
- [ ] 板上有 10µF 以上储能电容

**启动**

- [ ] **BOOT0 有 10k 下拉**
- [ ] NRST 有 10k 上拉 + 100nF 到地
- [ ] NRST 有按钮

**时钟**

- [ ] 晶振走线短且下方不走线
- [ ] 负载电容按晶振 CL 算过
- [ ] 晶振外壳接地

**调试**

- [ ] SWDIO / SWCLK / GND 都引出
- [ ] NRST 引出（强烈建议）
- [ ] 调试口没被复用成其他功能

**其他**

- [ ] 所有未用引脚有明确处理（模拟输入或输出固定电平）
- [ ] 电源指示灯（能直观判断是否上电）
- [ ] USB 的 D+ 有 1.5k 上拉（如果做 USB）
- [ ] CAN 两端有 120Ω（如果做 CAN）
- [ ] 有测试点（3.3V / GND / 关键信号）
:::

## 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 程序烧了但不跑 | **BOOT0 悬空** | 加 10k 下拉 |
| 偶发不启动 | 复位电容缺失 | 加 100nF |
| 拔插电源随机死机 | 去耦不足 | 每引脚 100nF |
| ADC 乱跳 | VDDA 没滤波 | 磁珠 + 电容 |
| 晶振不起振 | 负载电容错 / 虚焊 | 按 CL 算，重新焊 |
| 跑一会儿发热 | 供电电压过高或引脚短路 | 量电压，查短路 |
| 调试器连不上 | SWD 引脚被复用 / 固件卡死 | BOOT0 拉高救砖 |
| USB 识别不到 | D+ 缺 1.5k 上拉 | 加上拉 |
| 长时间运行后死机 | 电源纹波 / 温度 | 量纹波，加散热 |

:::danger[一定要留测试点]
**至少留**：

- 3.3V
- GND
- 每个关键信号（串口 TX/RX、SWD、复位）

**没有测试点，调试时只能拿探针去碰引脚——既容易短路，也容易滑到手。**

**测试点的成本是零，收益是几十小时的调试时间。**
:::
