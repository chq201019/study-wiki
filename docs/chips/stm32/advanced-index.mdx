# STM32 进阶：从会用到懂原理

**这条线假设你已经能用 CubeMX + HAL 跑通项目**（点灯、串口、定时器、I2C 都会）。

如果你还没到这一步，先走 [STM32 零基础](../../hardware/stm-basics/)。

## 零基础线没讲的东西

| 零基础教了「怎么做」 | 进阶要讲「为什么」 |
| --- | --- |
| `HAL_GPIO_WritePin` 怎么调 | 三种抽象层（HAL/LL/寄存器）性能差多少、怎么选 |
| 时钟填 72MHz 自动求解 | PLL 的分频器怎么算、时钟门控省多少电 |
| NVIC 优先级勾选 | 优先级分组、抢占与尾链、临界区该怎么写 |
| DMA 加个通道 | 通道映射表、双缓冲、Cache 一致性 |
| `HAL_TIM_PWM_Start` | 输入捕获、编码器模式、互补输出与死区 |
| `HAL_ADC_Start` | 注入通道、多重采样、精度提升手段 |
| 能烧进去跑起来 | 启动文件做了什么、链接脚本怎么改 |
| `systemctl`/OTA 概念 | **自己写 Bootloader 做 IAP 升级** |

## 怎么用这条线

:::tip[建议顺序]
**先读 01-04**（抽象层、时钟、中断、DMA）——这四块是后面所有内容的地基。

**再按你项目需要选读** 05-08（外设）和 13-16（通信与 RTOS）。

**09-12 是工程能力**，做产品绕不开，建议早点看。

**17-18 在出问题时最值钱**。
:::

:::warning[本线的验证程度说明]
- **标注「本机实测」的**：在本地工具链或服务器上真实验证过
- **标注「📋 示例」的**：代码结构标准但未在硬件上跑过（本站没有对应开发板）
- **纯原理图**：来自 ST 官方参考手册（RM0008 等）的寄存器说明

**遇到不一致时以你的芯片手册为准。**
:::
