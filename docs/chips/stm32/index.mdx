# STM32 导读与家族地图

**STM32 是 ST（意法半导体）推出的 32 位 Arm Cortex-M 内核单片机家族**，2010 年前后开始铺货，如今是通用 MCU 的事实标准：国内嵌入式岗位 JD 出现率最高，高校电子类课程、电赛、工业控制、汽车电子里遍地都是。

它和本站主线 ESP32 的关系可以这样理解：**ESP32 是"自带无线的联网芯片"，STM32 是"什么外设都有但默认不联网的通用芯片"**。ESP32 适合 IoT 出活，STM32 适合把单片机功底打扎实——工业界大量项目（电机驱动、仪表、汽车节点）不需要 WiFi 但需要稳定、便宜、低功耗的 32 位 MCU，这就是 STM32 的主场。

:::tip[学过本站 ESP32 教程再来，事半功倍]
STM32 六页教程大量引用完整教程的原理页：GPIO 矩阵对照[复用选择器](./from-esp32)、PWM 平均效应、I2C 字节级时序、FreeRTOS 任务模型……原理不变，变的只是 API 名字和配置工具。
:::

## 1. 一分钟建立框架：三层套娃

第一次看 STM32 型号名会懵（STM32F103C8T6？），其实就三层：

```text
家族（决定内核和资源档位）
  └── 系列（决定外设组合和功耗定位）
        └── 型号后缀（决定引脚数 / Flash 大小 / 封装温度）
```

以 **STM32F103C8T6** 为例逐段拆（这就是著名的"蓝板 Blue Pill"上的芯片）：

| 段 | 值 | 含义 |
| --- | --- | --- |
| STM32 | — | ST 家 32 位 MCU |
| F1 | 家族 | Cortex-M3 主流档 |
| 103 | 系列 | 基础型（101 精简 / 102 USB / **103 基础** / 105/107 互联型） |
| C | 引脚 | 48 脚 |
| 8 | Flash | 64KB |
| T | 封装 | LQFP（四面扁平脚） |
| 6 | 温度 | 工业级 -40~85℃ |

**读任何 STM32 型号都用这张表**，规律全家族一致。查具体资源用 ST 官方选型器或者 CubeMX 直接选。

## 2. 家族地图：每个家族一句话

| 家族 | 内核 | 主频 | 一句话定位 | 新手碰它吗 |
| --- | --- | --- | --- | --- |
| **F1** | Cortex-M3 | 72MHz | 经典老将，教程/电赛/蓝板所在地，资料最多 | ✅ **首选入门** |
| F0 / C0 | Cortex-M0 | 48MHz | 便宜精简，替代 8 位机的入门款 | 可以，资料略少 |
| **F4** | Cortex-M4F | 168~180MHz | 带 FPU/DSP 指令的主流主力，Discovery 板多 | ✅ 第二块板推荐 |
| F7 / H7 | Cortex-M7 | 216~550MHz | 高性能档，跑 LVGL/音频/视觉 | 学完外设再说 |
| G0 / G4 | M0+ / M4F | 64~170MHz | 新一代主流，混合信号外设强（G4 有运放/比较器） | 新项目替代 F1/F4 |
| L0/L4/L5 | M0+/M4/M33 | 32~110MHz | 低功耗家族（电池仪表、传感器节点） | 涉及超低功耗再看 |
| U5 | M33 | 160MHz | 更强低功耗 + 安全特性 | 同上 |
| WB / WL | M4+M0+ 双核 | 64~110MHz | **自带 BLE（WB）或 LoRa（WL）**——STM32 里最接近 ESP32 定位的 | 做无线再碰 |
| H5 / N6 | M33 / +NPU | 250MHz~ | 新一代带 AI 加速/安全启动 | 关注即可 |

记忆锚点：**F=通用主流，G=新一代主流，L=低功耗，H=高性能，WB/WL=带无线**。

## 3. 和 ESP32 的定位对照

| | ESP32-S3（本站主线） | STM32F103/F4（本专栏主角） |
| --- | --- | --- |
| 无线 | WiFi+BLE 芯片自带 | **没有**（要联网得外挂模块） |
| 片内 Flash/RAM | 无大 Flash（外挂 16MB）+ 512KB RAM | F103C8：**片内** 64KB Flash + 20KB RAM |
| 程序执行 | 从外挂 QSPI Flash 缓存执行 | 直接在片内 Flash **零等待**执行 |
| 主频 | 240MHz 双核 | 72~180MHz 单核 |
| 每片价格（散新） | 10~20 元 | F103 蓝板 10~15 元，芯片 3~8 元 |
| 生态入口 | 米思齐 / Arduino / IDF | Arduino（STM32duino）/ **CubeMX+HAL** / 寄存器 |
| 典型项目 | 联网音箱、摄像头、网关 | 电机控制、仪表、电池设备、工业节点 |

一个直观结论：**"要不要联网"基本决定选谁**。两边都会的人，项目里常见组合是"STM32 干实时控制 + ESP32 干联网"，各干擅长的事。

## 4. 买哪块板子入门

| 板子 | 芯片 | 价格 | 推荐度 | 理由 |
| --- | --- | --- | --- | --- |
| **蓝板 Blue Pill**（STM32F103C8T6） | F103C8 | 10~15 元 | ✅ 入门首选 | 教程全网最多；注意两件事：板上芯片常见 CS32/CKS32 兼容片（学习无碍），PCB 天线区电阻 R10 别乱动 |
| STM32F411 BlackPill | F411CE | 15~25 元 | ✅ 进阶替代 | M4F + 100MHz + 512KB Flash，蓝板同款小板型，性能强一截 |
| NUCLEO-F103RB | F103RB | 60~90 元 | 稳妥之选 | 官方板，板载 ST-Link 调试器（**省掉买烧录器**），资源正式 |
| STM32F407 探索者/战舰等 | F407ZG | 100~300 元 | 备选 | 国内教学板，外设全（屏/网口/音频），资料中文齐全但体积大 |

:::caution[独立蓝板必须配一个烧录调试器]
蓝板本身**没有烧录器**，要么买一个 ST-Link V2 克隆版（10~20 元，SWD 烧录+调试），要么用 USB 转串口模块走串口 ISP 烧录（只能烧录不能打断点调试）。**强烈建议 ST-Link**——能打断点看变量，学起来完全是两个世界。详见[第一个工程](./first-project)。
:::
