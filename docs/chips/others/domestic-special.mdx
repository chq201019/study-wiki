# 国产平替与特色选手

[地图页](./)把各家定位过了一遍，这一页挑四个"当代最值得认真考虑的候选"细讲：**GD32/CH32**（降本主力）、**RP2040**（异构想象力）、**nRF52**（BLE 王者）、**MSP430/MSPM0**（功耗标杆）。每家按同一个模板讲：是什么 → 生态怎么入 → 和你已会的体系差在哪 → 什么时候选它。

## 1. GD32：把"兼容"做成一门生意

### 是什么

兆易创新（GigaDevice）的 Cortex-M 系列，设计目标就是**替换 STM32**：引脚定义一致、寄存器布局一致、HAL/标准库代码基本能直接编译（把头文件 `stm32f10x.h` 换成 `gd32f10x.h` 或用其兼容包）。**但内核跑得更快**——GD32F103 主频 108MHz（ST 是 72MHz），Flash 是自家零等待工艺。

### "兼容但不等同"的 1%

| 差异点 | 表现 |
| --- | --- |
| 主频与等待周期 | 主频高、Flash 零等待，**含空循环的时序代码会变快**——靠循环数数的软件延时全要重标定 |
| 外设行为细节 | 个别外设（如 USB、部分定时器位）与 ST 有勘误级差异，看 GD 的勘误表 |
| 型号命名 | F103/G030/G430/A7 系列，规律与 STM32 相似但资源表不同 |

实战经验：**GPIO/UART/I2C/SPI/TIM 这类"教科书外设"兼容度接近 100%，直接换**；USB/以太网/CAN 等复杂外设要按 GD 的官方库重新集成。

### 什么时候选

- STM32 芯片缺货/涨价/停产（这是 GD 存在的原始理由）
- 量产降本：同封装直接换片，PCB 不用改
- 学习期**不特别推荐**作为第一颗 32 位机——资料量小于 STM32，遇到问题搜索命中率低

## 2. CH32：RISC-V 把 32 位打到 8 位的价格

### 是什么

南京沁恒（WCH，就是做 CH340 串口芯片的那家）的 MCU 线，分两支：

- **兼容线**：CH32F103 等对齐 STM32，体验同 GD32
- **RISC-V 线**：自研青稞 V4 内核（CH32V 系列）——**这条线才是看点**。代表作 **CH32V003**：RISC-V 32 位、48MHz、2KB RAM、16KB Flash、**单价一两元**，把"32 位单片机"的价格打到 8051 区间

### 生态怎么入

RISC-V 线不走 Keil，官方工具链是 **MounRiver Studio**（基于 GCC + OpenOCD，免费）+ **WCH-Link** 烧录器（十几元）。也有开源社区维护的 Arduino 核心与 PlatformIO 支持。C 语言层面和你会的完全一致，**工具链是唯一新事物**——恰好是[学习模板](../stm32/from-esp32)第 3 步的又一次重复。

### 什么时候选

- **极限成本**：能接受 2KB RAM 的场景（点灯、按键、继电器、简单传感采集），V003 是性价比天花板
- 想低成本接触 **RISC-V 生态**（指令集层面感受与 Arm 的差异）
- 注意：RAM/Flash 极小，跑不了 RTOS 和复杂协议栈，定位是"高级 8051"

## 3. RP2040：PIO——"自己造外设"的芯片

### 是什么

树莓派基金会出品：**双核 Cortex-M0+ @133MHz、264KB RAM、外挂 QSPI Flash**，芯片 5~10 元，开发板（Raspberry Pi Pico）约 15 元。性能中规中矩，但有一个独门武器改变玩法：**PIO（Programmable I/O）**。

### PIO 是什么概念

PIO 是 **8 个独立的小型状态机**，每个都能以确定时序收发引脚信号，程序用几条类汇编指令写。它的意义：**芯片没有的外设协议，你可以用 PIO"造"出来**——

- WS2812 灯带：常规 MCU 要关中断掐纳秒级时序，PIO 里 9 条指令稳定出 800kHz 波形
- VGA 视频输出、DVI、PS/2 键盘、SD 卡高速模式……社区把各种"不可能"用 PIO 实现了一遍

对照你已知的体系：ESP32 用 **RMT 外设**干类似的事（生成任意波形），STM32 没有等价物（只能靠定时器+DMA 拼接）。**RP2040 的 PIO 是"外设可编程"的激进版本**——理解它，你对"外设"的定义会宽一圈。

### 生态怎么入

官方 **C/C++ SDK**（CMake 工程，IDF 用户秒懂）或 **MicroPython**（官方分支，玩法类似 ESP32 的 MicroPython）。资料以英文官方 datasheet + 社区为主。

### 什么时候选

- 驱动怪异协议/高时序精度外设（PIO 无可替代）
- 双核便宜玩并发、创客项目
- 不适合：要无线（没有！需外挂模块）、要工业级供货保障

## 4. nRF52：BLE 产品的默认答案

### 是什么

Nordic 半导体，Cortex-M4 内核 + 射频前端的 BLE SoC，nRF52832/52840 是主力（52840 带 USB 和大 RAM）。**卖点不是性能是射频**：链路预算、功耗曲线、协议栈成熟度，做了十年 BLE 的厂家，无线耳机/手环/传感标签的主力供应商。

### 生态怎么入（这是它最特别的部分）

Nordic 现行体系是 **nRF Connect SDK（NCS）**，基于 **Zephyr RTOS**：

- 配置体系是 **devicetree**（`.dts` 描述硬件，编译期生成配置）+ **Kconfig**（软件特性裁剪）——Kconfig 你在 [L2](../../course/l2-programming-model/component-cmake) 见过，devicetree 是新概念，值得学（它正在成为嵌入式配置的事实标准，Linux 内核同款）
- BLE 用法是声明式 API：注册服务/特征值结构体，协议栈回调驱动——比 ESP32 的 Bluedroid/NimBLE 层次更规整
- 入门工具：nRF Connect for Desktop（图形化烧录/日志）+ VSCode 插件

学习成本明显比 HAL 高（Zephyr 的抽象层次深），**但 BLE 应用开发的工业标准就在这**。

### 什么时候选

- 电池供电 BLE 产品要量产（功耗和稳定性有保障）
- 想学 Zephyr/devicetree 这套"下一代"开发范式
- 只是想"做个 BLE 玩具"→ 留在 ESP32-C 系更省力

## 5. TI MSP430 / MSPM0：功耗的度量衡

MSP430 是 16 位老架构、MSPM0 是 TI 2022 年起的 Cortex-M0+ 新线。卖点一句话：**睡眠电流和工作功耗的极限控制**，多级低功耗模式（LPM0~LPM4）能到 μA 级待机。万用表、热量表、烟雾报警器里的常青树。

- 工具：Code Composer Studio（免费）或 Energia（Arduino 式）
- **什么时候选**：纽扣电池十年寿命的仪表类产品、低功耗系统设计学习（它的电源管理教材级）；一般项目不必首选，但**"低功耗设计方法论"值得读它的文档**——和 [L6 功耗一节](../../course/l6-system/power)的思路互为印证

## 6. 收束：第二颗芯片决策表

| 你的情况 | 推荐 | 理由 |
| --- | --- | --- |
| 求职嵌入式/进工业 | **STM32**（[专栏](../stm32/)） | 岗位覆盖面最大 |
| 量产降本/国产替代 | **GD32 / AT32** | STM32 代码直接迁移 |
| 极限成本小控制 | **CH32V003** | 一两元的 32 位 RISC-V |
| 协议实验/创客玩法 | **RP2040** | PIO 独一份 |
| BLE 电池产品 | **nRF52** | 射频与协议栈标杆 |
| 十年纽扣电池 | **MSPM0 / STM32L** | 功耗设计典范 |
| 想吃透裸机原理 | STC 8051（[详讲](./classic-mcu)） | 寄存器直写显微镜 |

**最后提醒**：无论选谁，[学习模板七步](../stm32/from-esp32)通用——背资源、懂时钟、查引脚、走启动、配外设、上 RTOS/DMA、吃透调试。芯片是方言，嵌入式是语言。
