# 其他主流芯片地图

STM32（[上一专栏](../stm32/)）和 ESP32（[本站主线](../../course/)）覆盖了大部分场景，但嵌入式版图上还有几块重要大陆：教科书级的 8051、创客鼻祖 AVR、异构玩家 RP2040、价格屠夫国产系、BLE 王者 Nordic、功耗标杆 MSP430。这一页每家给一段话定位 + 选型判断，细讲放在后面两页。

## 2. 每家一段话

### 8051 系（STC 等）——"理解裸机的最佳教材"

1980 年 Intel 设计的 8 位架构，四十多年了还在中国电子专业课堂上。它的价值**不在性能而在透明**：没有 HAL、没有 RTOS、没有矩阵，`P1 = 0xFE;` 一行就是寄存器操作，每个机器周期都在你眼皮底下。STC（宏晶）把它做成了国产入门标准：几块钱一片、串口 ISP 烧录、中文资料铺天盖地。**适合作为"第二视角"学习**——你在 ESP32/STM32 上被库包起来的东西（位操作、中断现场、机器周期），在 8051 上全是裸的。→ [经典入门款详讲](./classic-mcu)

### AVR（ATmega328P / Arduino UNO）——创客生态的活化石

Arduino UNO 板上的芯片。8 位、16MHz、2KB RAM，性能早被吊打，但 **Arduino 这个"库+IDE+社区"的范式就是从它发扬光大的**——你每天用的 `digitalWrite` 语言体系是它定下来的。今天的实际意义：读老项目、玩极简 Arduino 生态、理解"Arduino API 只是抽象层"的最佳标本。→ [经典入门款详讲](./classic-mcu)

### RP2040 / RP2350——异构外设的想象力

树莓派基金会 2021 年推出的双核 Cortex-M0+（RP2350 升级 M33），几块钱、264KB RAM。两样独门绝技：**PIO（可编程 I/O）**——8 个小型状态机让你用几行汇编实现任意协议时序（WS2812、DVI 甚至 VGA），硬件直接"长出"新外设；**双核 + 极简 C SDK**——没有 RTOS 也能优雅并发。创客圈新宠，Audio/复古计算机/创意硬件的乐园。→ [国产与特色选手详讲](./domestic-special)

### GD32 / CH32 / AT32——国产平替军团

- **GD32（兆易创新）**：Cortex-M 内核、**引脚级兼容 STM32**，主频反而更高（GD32F103 跑 108MHz），散货市场和量产替代的常客
- **CH32（南京沁恒）**：一半产品兼容 STM32（CH32F103），一半走 RISC-V 路线——**CH32V003 单价一两元**，把 32 位 RISC-V 打进 8 位机的价格区间
- **AT32（雅特力）**：STM32 高兼容 + 大 Flash，性价比路线

选型逻辑很简单：**拿 STM32 的资料、按 STM32 的教程学、用更少的钱买货**——同时接受"兼容但不完全等同"的细节差异。→ [国产与特色选手详讲](./domestic-special)

### Nordic nRF52 / nRF54——低功耗蓝牙的隐形冠军

你手上的无线耳机、手环、电子价签、传感器标签，拆开很大概率是 nRF52。Cortex-M4 内核 + **业界功耗/射频口碑最好的 BLE 协议栈**，纽扣电池能跑一年。开发走 nRF Connect SDK（基于 **Zephyr RTOS**）——学习曲线比 HAL 陡（Zephyr 的 devicetree 概念要先啃），但换来工业级无线产品力。**做"带 BLE 的电池设备"，它基本是默认答案**。→ [国产与特色选手详讲](./domestic-special)

### TI MSP430 / MSPM0——超低功耗的老标杆

16 位老架构（MSP430）+ 新 M0+ 线（MSPM0）。卖点是**睡眠电流和工作功耗的极限控制**，万用表、水气表、仪表仪器里活了二十年的常青树。生态偏 TI 自家工具（Code Composer Studio），国内社区热度一般，但在"电池要活十年"的仪表行业无可替代。

## 3. 场景 → 选型速查

| 你要做的东西 | 首选 | 备选 |
| --- | --- | --- |
| 联网设备（WiFi/MQTT/语音） | **ESP32** | W801 |
| 电机控制/工业节点/仪表 | **STM32**（F4/G4） | GD32/AT32（降本） |
| BLE 手环/标签/传感器 | **nRF52** | ESP32-C6、STM32WB |
| 十年纽扣电池设备 | **MSP430/MSPM0** | STM32L 系列、nRF52 |
| 极限成本（单片两元以下） | **CH32V003** | 8051 系 |
| 教学理解裸机 | **STC 8051** 或 STM32 寄存器版 | —— |
| 创意硬件/协议实验 | **RP2040**（PIO） | ESP32 |
| 比赛一周出活 | **ESP32**（无线自带方案最短） | STM32 + 无线模块 |

:::tip[一个通用的降本/降险原则]
原型期选**生态最省事的**（ESP32/STM32 生态最厚），量产后为降本换**兼容平替**（GD32/CH32/AT32）——前提是读完兼容芯片的勘误表并全量回归测试。"兼容"的意思是 99% 一样，**剩下 1% 就是量产事故的来源**。
:::
