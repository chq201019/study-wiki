# 经典入门款：8051 与 AVR

这两位是"爷爷辈"：8051 是 1980 年的架构（中国课堂上仍是标配），AVR 是 Arduino UNO 的心脏。**性能上它们已被 32 位机全面碾压，但学习价值依然存在**——因为"什么都没有"：没有 HAL、没有设备树、没有外设矩阵、没有 RTOS，每个寄存器每个机器周期都摊在你面前。

如果你在本站 ESP32 教程里对"为什么 `gpio_set_level` 能让引脚变电平""中断现场发生了什么"仍有隔膜，拿一块 10 元的 8051 板写两页代码，隔膜就没了。这就是本页的存在意义：**它们是理解抽象层底下的显微镜**。

## 1. STC 8051：一行代码看穿裸机

### 最小系统与烧录

STC89C52RC（经典款）：8 位 8051 内核、12MHz 级主频、**512 字节 RAM、8KB Flash**。最小系统五件套：晶振（11.0592MHz——串口整除的经典频率）+ 复位电路 + EA 拉高 + 电源。烧录用 **stc-isp 软件 + USB 转串口**：点下载 → 给芯片断电再上电 → 上电瞬间 bootloader 抓住串口开始收程序（STC 的 boot 是上电窗口触发，和 STM32 的 BOOT0 机制不同）。

### 点灯：寄存器直写的全部真相

```c
#include <reg52.h>          // 定义 SFR（特殊功能寄存器）地址

sbit LED = P1^0;            // LED 在 P1.0——sbit 把"字节地址+位"命名成变量

void main(void)
{
    while (1) {
        LED = 0;            // 灌电流接法：写 0 亮。这一句编译后就是一条 SETB/CLR 位操作指令
        delay();
        LED = 1;
        delay();
    }
}
```

注意这里**没有任何初始化函数**：没有 `gpio_config`、没有时钟使能、没有 HAL_Init。上电 → 复位向量 → main，寄存器复位默认值就是可用状态。**"库替你省掉的那些步骤在硬件层面是什么"——8051 用不存在告诉你答案**：库的本质是把"配置模式寄存器、开时钟、设复用"打包成函数。

### 中断现场：到机器周期为止

```c
void Timer0_ISR(void) interrupt 1      // 定时器0中断，向量号1——关键字直接对应硬件向量表
{
    TH0 = 0xFC; TL0 = 0x66;            // 12MHz 下 1ms 的重装值，手工算的
    ms++;
}
```

8051 的中断没有优先级组、没有 NVIC、没有 FromISR API——**进中断就是保存 PC、压栈、跳向量表**，全由硬件自动做，你能做的只有"写短一点"。在 STM32 上被 `HAL_GPIO_EXTI_Callback` 包起来的机制，这里裸到只剩语义。

### 8051 值得学的三件事（和不必学的部分）

值得带走：

1. **机器周期思维**：12MHz 晶振 ÷12 分频 = 1MHz 机器周期，`delay()` 就是数循环圈数——从此你理解"阻塞延时在烧什么"
2. **位操作肌肉记忆**：`sbit`、`&=`、`|=` 掩码操作，这是所有嵌入式寄存器操作的通用语法
3. **资源饥饿下的编程**：512B RAM 里写程序，全局变量都要数着用——这是最好的"内存预算训练"

不必较真：总线扩展方式（P0 复用）、汇编指令集本身——它们属于历史，思路已在 32 位机进化。

## 2. AVR / Arduino UNO：抽象层的诞生地

### 两个身份，一次讲清

ATmega328P 同时是两样东西：**一块 8 位 AVR 内核芯片**（16MHz、2KB RAM、32KB Flash）和 **Arduino UNO 生态的载体**。想理解 Arduino 是什么，就在这颗芯片上把两层各玩一遍：

```c
// ① Arduino 层：你熟悉的语言（快速上手的对照模式）
digitalWrite(13, HIGH);
delay(500);

// ② AVR 寄存器层：digitalWrite 展开后的真身
DDRB |= (1 << DDB5);        // Data Direction：B 口第 5 位设为输出
PORTB |= (1 << PORTB5);     // 输出高
PORTB &= ~(1 << PORTB5);    // 输出低
```

对比一下：`digitalWrite(13, HIGH)` 在 Arduino 框架里要经历"13 号→查表换端口位→判断 PWM 附加功能→再写寄存器"四步，耗时几十微秒；寄存器直写**一条指令一个周期**。这个 100 倍的差距就是[完整教程 L3](../../course/l3-arduino/)讨论的"框架代价"的最极端标本——**在 8 位机上，抽象层的开销大到能改变项目可行性**（所以老创客的关键路径都写寄存器）。

### setup/loop 的本质

```c
int main(void) {
    init();                 // Arduino 运行时：配定时器0给 millis()、ADC 预分频等
    setup();                // 你的 setup
    for (;;) {
        loop();             // 你的 loop——所以 loop 里可以死循环（有看门狗兜底除外）
        // 串口事件钩子等
    }
}
```

`setup()/loop()` 不是硬件机制，是 **Arduino 运行时给你的一副骨架**——main 在框架里写好了。这纠正一个常见误解：很多人以为 Arduino 是另一种体系，其实它是"一套约定 + 一层库"，底下还是那颗裸芯片。你以后看任何框架（米思齐、Arduino-esp32、STM32duino）都能用这双眼睛拆解。

### 串口、ADC 的方言味道

AVR 的 UART 用 `UDR0` 寄存器一字节一字节收发、ADC 用 `ADMUX/ADCSRA` 寄存器序列启动——比 STM32 HAL 更原始。**不建议深学每个寄存器**，建议只做一件事：把"点灯+串口+ADC"三个东西用寄存器写一遍，体会"所有外设=一组状态寄存器+一个数据寄存器+若干开关位"这个不变式。这个不变式在 8051、AVR、STM32、ESP32 上永远成立。

## 3. 三代芯片同题对比：点灯背后

同一个"点灯+500ms 翻转"，三代硬件的实现深度：

| | STC89C52 (8051) | ATmega328P (AVR) | STM32F103 | ESP32-S3 |
| --- | --- | --- | --- | --- |
| 代码形态 | 寄存器直写 | Arduino 或寄存器 | HAL（CubeMX 生成） | IDF / Arduino |
| 引脚配置 | 无需配置 | DDR 方向寄存器 | 开时钟+模式寄存器 | gpio_config 结构体 |
| 延时 | 手写循环数圈 | `_delay_ms`（定时器）或 delay 库 | HAL_Delay(SysTick) | vTaskDelay(RTOS) |
| 中断 | 向量号+短函数 | ISR 宏 | NVIC+HAL 回调 | INTC+ISR 入队 |
| RAM 预算 | 512B | 2KB | 20KB | 512KB+8MB |
| 你学到什么 | 裸机的最小真相 | 抽象层的诞生 | 生成器+库的工业范式 | 全栈与无线 |

**读法**：从左往右是"抽象逐层加厚"的历史。每一层都没有白给——厚一层，生产率高一分，离硬件真相远一寸。**完整工程师应该两头都摸过**：知道最底下的真相，也懂得最上面的取舍。

## 常见坑

| 症状 | 病根 |
| --- | --- |
| STC 烧录一直"正在检测目标单片机" | 没做"断电→点下载→再上电"动作；或 USB 转串口的 RX/TX 接反 |
| 8051 串口乱码 | 晶振不是 11.0592MHz（常见 12MHz），波特率算不整——按实际晶振重算 TH1 |
| Arduino `digitalWrite` 太慢跟不上时序 | 换寄存器直写（PORTx）；或换 32 位机 |
| UNO 的 analogRead(A5) 报错 | A6/A7 是纯模拟脚不能 `digitalRead`（每块板差异，查引脚图） |
| 8051 程序莫名重启 | RAM 爆了/栈溢出——512 字节时代，查全局变量和局部大数组 |
