## 芯片选型对照

虽然本教程固定用 ESP32-S3，但工程中选型是基本功：

| 型号 | 内核 | 特点 | 典型场景 |
| --- | --- | --- | --- |
| ESP32-S3 | 双核 Xtensa LX7 @240MHz | **向量指令**、原生 USB、LCD CAM、8MB PSRAM | 图像/音频/AI、机器视觉 |
| ESP32-C3 | 单核 RISC-V @160MHz | 便宜、面积小、无 PSRAM | 成本敏感的简单 IoT |
| ESP32-C6 | 单核 RISC-V @160MHz | WiFi 6 + BLE + 802.15.4 | 新一代低功耗 IoT |
| ESP32-H2 | 单核 RISC-V @96MHz | **只有 802.15.4，没有 WiFi** | Zigbee / Thread 网关 |
| ESP32-P4 | 双核 RISC-V @400MHz | 外设极多、带 MIPI/ISP | 边缘 AI、带屏终端 |

选型时看五件事：算力需求（要不要向量指令）、内存（图像/音频需要 PSRAM）、无线制式（WiFi / BLE / Zigbee 要哪个）、功耗（电池项目优先 C 系列）、成本与供货。

选定之后，型号之间的差异对照见[跨型号移植指南](../../reference/porting)。
