## 判断标准

一个项目做到什么程度算"产品化"？对照这张表自查：

| 维度 | 原型 | 产品 |
| --- | --- | --- |
| 断电恢复 | 重新配网 | 自动恢复，配置持久化 |
| 升级 | 手动烧录 | OTA + 回滚保护 |
| 固件安全 | 无 | Secure Boot + 加密 |
| 功耗 | 一直开着 | 深睡眠，电池能用几个月 |
| 数据 | 存内存 | 掉电不丢 |
| 界面 | 串口打印 | 本地显示 + 远程配置 |
| 日志 | 到处 printf | 分级可关闭 |
