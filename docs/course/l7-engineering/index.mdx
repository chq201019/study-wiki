## 为什么工程化很重要

一个人写的项目，能跑就行。要交付的项目，必须让别人能接手：

- 结构统一 → 新人 1 天能看懂
- 错误处理统一 → 出问题时知道去哪找
- 有测试 → 改代码不会破坏已有功能
- 有文档 → 半年后自己也能看懂
