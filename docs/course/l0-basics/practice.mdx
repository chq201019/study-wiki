## 题 1：倒计时器（热身）

**要求**：用循环打印 `10 9 8 ... 2 1`，最后打印 `发射！`。

:::tip[提示一]
倒着数：计数器从 10 开始，每圈减 1。
:::

:::tip[提示二]
`for (int i = 10; i > 0; i--)`——条件是"还没数到 0"，每圈 i 减 1。
:::

:::tip[参考答案]
```c
#include <stdio.h>

int main(void) {
    for (int i = 10; i > 0; i--) {
        printf("%d\n", i);
    }
    printf("发射！\n");
    return 0;
}
```
注意 `i > 0`：i 减到 0 时条件不成立退出，正好不打印 0。
:::

## 题 2：温度换算函数

**要求**：写函数 `float c_to_f(float c)`，把摄氏度换算成华氏度（公式：F = C × 9/5 + 32）。在 main 里换算 25 度和 0 度，分别打印。

:::tip[提示一]
返回类型 `float`，参数一个 `float c`，函数体一行 return。
:::

:::tip[提示二]
小心整数除法：`9 / 5` 是 1！要写 `9.0 / 5.0` 或 `1.8`。
:::

:::tip[参考答案]
```c
#include <stdio.h>

float c_to_f(float c) {
    return c * 9.0f / 5.0f + 32.0f;
}

int main(void) {
    printf("25 摄氏 = %.1f 华氏\n", c_to_f(25.0f));
    printf(" 0 摄氏 = %.1f 华氏\n", c_to_f(0.0f));
    return 0;
}
```
输出：
```text
25 摄氏 = 77.0 华氏
 0 摄氏 = 32.0 华氏
```
如果写成 `c * 9 / 5`，`9/5` 先算出 1，25 度会算成 57——**整数除法坑的现场教学**。
:::

## 题 3：传感器读数统计

**要求**：数组 `{12, 15, 11, 18, 14}` 是 5 次温度读数。用循环求**最大值**和**平均值**（平均值保留 1 位小数）。

:::tip[提示一（最大值）]
先假设第一个数最大（`int max = readings[0];`），循环里遇到更大的就换。
:::

:::tip[提示二（平均值）]
循环里累加（`sum += readings[i];`），循环外除以 5.0——**除以 5.0 不是 5**。
:::

:::tip[参考答案]
```c
#include <stdio.h>

int main(void) {
    int readings[5] = {12, 15, 11, 18, 14};
    int max = readings[0];
    int sum = 0;

    for (int i = 0; i < 5; i++) {
        if (readings[i] > max) {
            max = readings[i];
        }
        sum = sum + readings[i];
    }

    float average = sum / 5.0f;      // 5.0f 保住小数！
    printf("最大 %d 平均 %.1f\n", max, average);
    return 0;
}
```
输出：
```text
最大 18 平均 14.0
```
"打擂台求最大值"是嵌入式最常用的套路之一——传感器每来一个新值，跟当前最大值比一下。
:::

## 题 4：交换两个变量（指针关）

**要求**：main 里有两个变量 `a = 3, b = 8`。写函数 `void swap(int *x, int *y)`，调用后 a 和 b 的值**真的互换**。

:::tip[提示一]
函数参数是复印件，直接换复印件没用。要收**房间号**（指针），顺着房间号改原件。
:::

:::tip[提示二]
三个盒子互换需要一个临时盒子：`int t = *x; *x = *y; *y = t;`。
:::

:::tip[参考答案]
```c
#include <stdio.h>

void swap(int *x, int *y) {
    int t = *x;      // 先把 x 房间里的值抄到临时盒
    *x = *y;         // 把 y 房间的值搬进 x 房间
    *y = t;          // 把临时盒的值搬进 y 房间
}

int main(void) {
    int a = 3, b = 8;
    printf("交换前 a=%d b=%d\n", a, b);
    swap(&a, &b);            // 递房间号！
    printf("交换后 a=%d b=%d\n", a, b);
    return 0;
}
```
输出：
```text
交换前 a=3 b=8
交换后 a=8 b=3
```
调用时必须写 `&a, &b`——不写 `&` 递过去的是复印件，函数照样白忙。
:::

## 题 5：位运算：高低 4 位互换

**要求**：把一个字节的低 4 位和高 4 位交换。例如 `0xAB`（二进制 `1010 1011`）变成 `0xBA`（二进制 `1011 1010`）。

:::tip[提示一]
三步：把低 4 位搬到高 4 位（左移 4）；把高 4 位搬到低 4 位（右移 4）；两部分相加（用 `|`）。
:::

:::tip[提示二]
`0xAB` 低 4 位是 `0x0B`（`0xAB & 0x0F` 掩掉高位），左移 4 变 `0xB0`；高 4 位是 `0x0A`（`0xAB >> 4`）；`0xB0 | 0x0A = 0xBA`。
:::

:::tip[参考答案]
```c
#include <stdio.h>

unsigned char swap_nibbles(unsigned char b) {
    unsigned char low  = b & 0x0F;      // 掩码 0x0F = 0000 1111：留下低 4 位
    unsigned char high = b >> 4;        // 右移 4 位：高 4 位落到低 4 位
    return (low << 4) | high;           // 低 4 位升到高位，和高位拼起来
}

int main(void) {
    unsigned char x = 0xAB;
    printf("0x%X -> 0x%X\n", x, swap_nibbles(x));
    return 0;
}
```
输出：
```text
0xAB -> 0xBA
```
这题是寄存器操作的基本功——手册里说"寄存器低 4 位是配置、高 4 位是模式"，用的就是"掩码提取 + 移位拼装"这两下。
:::

## 题 6：综合小项目——成绩单（把全部知识串起来）

**要求**：定义一个结构体存"学生姓名（char 数组）和分数（int）"；写函数 `void print_report(student_t *s, int count)`，接收结构体**数组**和人数，打印每个学生的名字和分数，以及最高分和平均分（保留 1 位小数）。

这道题综合了：结构体（第 9 节）、结构体指针与箭头（第 9 节）、结构体数组（第 6、9 节）、函数传指针（第 8 节）、循环与最大值套路（第 4、6 节）、整数除法坑（第 3 节）。**做得出这题，L0 语言关就真的过了**。

:::tip[提示一]
```c
typedef struct {
    char name[20];
    int  score;
} student_t;
```
:::

:::tip[提示二]
结构体数组就是"一排包裹"：`student_t list[3] = {...}`；传给函数写 `print_report(list, 3)`——数组名自动变成指针。
:::

:::tip[参考答案]
```c
#include <stdio.h>

typedef struct {
    char name[20];
    int  score;
} student_t;

void print_report(student_t *s, int count) {
    int max = s[0].score;
    int sum = 0;

    for (int i = 0; i < count; i++) {
        printf("%s\t%d\n", s[i].name, s[i].score);
        if (s[i].score > max) {
            max = s[i].score;
        }
        sum += s[i].score;
    }
    printf("最高分 %d，平均分 %.1f\n", max, sum / (float)count);
}

int main(void) {
    student_t list[3] = {
        {"小明", 85},
        {"小红", 92},
        {"小刚", 78},
    };
    print_report(list, 3);
    return 0;
}
```
输出：
```text
小明    85
小红    92
小刚    78
最高分 92，平均分 85.0
```
注意三处指针相关的细节：函数参数是 `student_t *s`（收房间号不复印）；函数里用 `s[i].score`（`s[i]` 先顺指针找到第 i 个包裹，`.` 再取字段）；`sum / (float)count` 强转成小数再除。
:::
