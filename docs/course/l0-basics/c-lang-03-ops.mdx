# 03 嵌入式类型与运算

## 2.2 嵌入式专属写法：uint8_t 家族

以后读 ESP32 代码，最常见的是 `uint8_t`、`uint16_t`、`uint32_t` 这种"奇怪"类型。拆开读就不奇怪了：

- `u` = unsigned（无符号，只装 0 和正数）
- `int8` / `int16` / `int32` = 精确地 8 / 16 / 32 个**比特**宽（1 字节 = 8 比特，所以 `uint8_t` 正好 1 字节）
- `_t` = type 的惯例后缀

| 写法 | 比特 | 能装的范围 | 典型用途 |
| --- | --- | --- | --- |
| `uint8_t` | 8 | 0～255 | 一个字节的数据、原始读数 |
| `uint16_t` | 16 | 0～65535 | ADC 读数（12 位结果装得下） |
| `uint32_t` | 32 | 0～约 42.9 亿 | 时间戳、地址 |
| `int8_t` / `int16_t` | 同宽 | 带符号版本 | 可正可负的量（如温度偏移） |

为什么不用 `int`？因为 `int` 在不同平台上大小可能不一样（老单片机上 int 可以只有 2 字节），而 `uint32_t` 把"占 4 个字节"写得明明白白。**嵌入式代码讲究精确到字节，所以全员用这套**。它们藏在 `<stdint.h>` 里，用时 `#include <stdint.h>`。

### signed 和 unsigned：一个比特的去向

一个字节有 8 个比特，能表示 256 种组合（0～255）。**如果要表示负数，最高那个比特就被征用当"正负号"**，剩下 7 个比特表示大小——范围变成 -128～127。这就是 signed（带符号）和 unsigned（无符号）的全部区别：

| | 8 个比特怎么用 | 1 字节范围 |
| --- | --- | --- |
| `unsigned` | 全部 8 比特表示大小 | 0～255 |
| `signed` | 最高位当符号，7 比特表示大小 | -128～127 |

### 溢出实验：盒子满了会怎样

跑这个，盯着看：

```c
#include <stdio.h>

int main(void) {
    unsigned char tiny = 250;       // unsigned char = 1 字节无符号，范围 0～255
    for (int i = 0; i < 8; i++) {
        printf("%d\n", tiny);
        tiny = tiny + 1;            // 超过 255 会怎样？
    }
    return 0;
}
```

输出：

```text
250
251
252
253
254
255
0        ← 256 装不下，绕回 0！
1
```

**盒子满了不报错，而是像里程表一样绕回去**。为什么？回忆二进制：255 是 `1111 1111`，加 1 变成 `1 0000 0000`——9 个比特，但盒子只有 8 个，**最高位那个 1 被扔掉了**，剩下 `0000 0000` 就是 0。

这就是"溢出（Overflow）"。两种形态都要认识：

- **无符号溢出**：绕回 0（255 + 1 → 0）
- **有符号溢出**：最坏的绕回——`127 + 1` 变成 **-128**（最高位从 0 变 1，被解读成负号了）

:::caution[溢出不报错，嵌入式事故重灾区]
把毫秒时间戳存进 `uint16_t`：65536 毫秒 = 65.5 秒，**一分钟后数值绕回 0**，所有依赖时间的逻辑错乱。在电脑上你可能永远遇不到（int 太大），换到板子上小类型满天飞——**规矩：时间戳、计数器一律 `uint32_t` 起步；拿不准就用大类型**。
:::

### 试着改一改

1. 把 `unsigned char tiny = 250;` 改成 `char tiny = 250;`（带符号）再跑——250 打出来是 -6！（250 的比特被解读成负数了）。这就是 signed/unsigned 解读方式的差别
2. 写一个 `uint8_t` 变量从 0 一直加到 300 的循环，观察它永远到不了 300

## 3. 运算：对盒子里的数做手脚

```c
#include <stdio.h>

int main(void) {
    int a = 10, b = 3;        // 一行声明两个变量

    printf("加 %d\n", a + b);        // 13
    printf("减 %d\n", a - b);        // 7
    printf("乘 %d\n", a * b);        // 30
    printf("除 %d\n", a / b);        // 3   ⚠️ 见下面的坑
    printf("余 %d\n", a % b);        // 1   10 除以 3 余 1

    printf("小数除 %f\n", 10.0 / 3.0);   // 3.333333  想要小数，至少一边带小数点

    a++;                             // 等于 a = a + 1，现在 a 是 11
    b--;                             // 等于 b = b - 1，现在 b 是 2
    printf("自增自减后 %d %d\n", a, b);

    a += 5;                          // 等于 a = a + 5
    printf("复合赋值后 %d\n", a);     // 16
    return 0;
}
```

输出：

```text
加 13
减 7
乘 30
除 3
余 1
小数除 3.333333
自增自减后 11 2
复合赋值后 16
```

### 先乘除后加减：优先级

和数学一致：

```c
1 + 2 * 3        // 7   先乘后加
(1 + 2) * 3      // 9   括号最优先
10 - 4 - 3       // 3   同级从左到右算
```

:::tip[拿不准就加括号]
C 的完整优先级表有十几级（位运算、逻辑运算都参战），背下来不现实也没必要。**写复合表达式时，宁可多加两对括号**——括号不要钱，bug 要钱。
:::

:::danger[整数除法的坑（新手必踩第一名）]
`10 / 3` 在 C 里是 **3，不是 3.33**——两个整数相除，小数部分直接扔掉（不四舍五入，是直接砍）。更狠的：`9 / 10` 是 **0**。想要小数结果，除数或被除数至少一个带小数点：`10.0 / 3`。

实际事故：ADC 读数换电压，`float v = raw / 4095;`——raw 是 int，`raw / 4095` 先算出整数（大部分时候是 0），**再**装进 float。正确写法 `raw / 4095.0f`。**写换算公式时检查除号两边有没有小数点。**
:::

`a % b`（取余数）的妙用远不止数学题：**判断奇偶**（`x % 2 == 0` 是偶数）、**周期性报数**（`i % 10` 让数在 0～9 打转）、**把秒换成分秒**（`s / 60` 分、`s % 60` 秒）。

### 自增自减与复合赋值

```c
a++;        // a = a + 1
a--;        // a = a - 1
a += 5;     // a = a + 5      同族还有 -= *= /= %=
```

这些缩写没有新功能，但代码里铺天盖地，必须认得。

### 比较运算与逻辑运算

比较运算的结果是 `1`（真）或 `0`（假）：

```c
a > b     // 大于        a >= b   大于等于
a < b     // 小于        a <= b   小于等于
a == b    // 等于        ⚠️ 两个等号！
a != b    // 不等于
```

逻辑运算把多个条件拧起来：

| 符号 | 名字 | 何时成立 |
| --- | --- | --- |
| `&&` | 与（AND） | **两边都**真才真 |
| `\|\|` | 或（OR） | **任一边**真就真 |
| `!` | 非（NOT） | 真变假、假变真 |

```c
int temp = 28, humidity = 65;
(temp > 25) && (humidity > 60)     // 1：又热又闷
(temp > 30) || (humidity > 90)     // 0：两个都不满足
!(temp > 30)                       // 1：不算热
```

一个顺带的语法现象：`||` 两边的竖线在有些编辑器里会被转义成 `\|\|`（本页表格里就是这样），那是排版转义，**实际代码里就是两个竖线字符**。

:::danger[新手第一大坑：`=` 和 `==`]
`=` 是**装进盒子**（赋值），`==` 是**判断两边相不相等**。写 `if (x = 5)` 意思是"把 5 装进 x，然后判断 5（永远为真）"——程序不报错但逻辑全错。以后看到条件里出现单个 `=`，第一反应就是查这里。
:::
