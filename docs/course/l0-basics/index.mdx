## 为什么必须先过语言关

ESP32 的官方主力框架 ESP-IDF 是 **C 语言**写的（C++ 只是可选）。你要读的代码长这样：

```c
esp_err_t err = esp_wifi_set_config(WIFI_IF_STA, &wifi_config);
if (err != ESP_OK) {
    ESP_LOGE(TAG, "配置失败: %s", esp_err_to_name(err));
}
```

这一小段里藏着 C 的一半核心概念：类型（`esp_err_t`）、函数调用与返回值（`err`）、结构体和取地址（`&wifi_config`）、条件判断（`if`）、指针与字符串（`TAG`、`%s`）。看不懂这些，后面每一章都只能靠背；看得懂，每一章都是在给已知的积木换新玩法。

## 学到什么程度算够

不需要精通，需要达到：

- [ ] 能解释"变量、类型、函数、指针"四个词，并举出自己的比喻
- [ ] 能看懂一个带指针参数的函数在干什么（比如 `read(&buf, &len)`）
- [ ] 知道 `const`、`volatile`、`static`、`extern` 各自的实际作用
- [ ] 会用"置位 `|=`、清位 `&=~`"两个模板解读寄存器手册里的 `BIT(3)`
- [ ] 理解函数指针（回调的基础），能解释"系统怎么知道按键了要调谁"
- [ ] 知道程序在 Flash、数据在内存，以及栈和堆的区别
- [ ] 看过一遍编译输出，能找到 `build/*.map` 文件
- [ ] 建立了自己的错误笔记文件

:::tip[学习建议]
每学完一节，**合上教程，用自己的话给一个假想的新手讲一遍**。讲不顺的地方就是你没真懂的地方——这是效率最高的自测方法。另外读一读[怎么学](./how-to-learn)那页的方法论，它比多学十页技术内容更保值。
:::
