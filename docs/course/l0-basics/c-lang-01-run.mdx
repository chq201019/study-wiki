# 01 跑起来并看懂第一段代码

## 0. 先学会"跑代码"：三分钟搞定

学语言必须动手，光看永远学不会——这是本页最重要的方法要求。不用装任何软件，用**在线编译器**（网页里直接写代码、点运行）：

1. 浏览器打开任意一个"C 语言在线编译"网站（搜这个词，菜鸟教程、W3School 都自带）
2. 把网页里默认的示例代码**全部删掉**
3. 粘贴下面这段，点"运行"：

```c
#include <stdio.h>

int main(void) {
    printf("Hello!\n");
    return 0;
}
```

屏幕上应该出现：

```text
Hello!
```

**恭喜，你已经运行了第一个程序。** 从现在起到本页结束，你手上要一直开着这个网页。本页后面所有例子都这样跑：粘贴 → 运行 → 对照输出。**先在脑子里预测输出，再运行验证**——预测对了说明你真懂了，预测错了就是最宝贵的学习时刻。

### 什么叫"编译"，亲眼看看

在线编译器把"编译"这一步藏起来了，值得花一分钟理解它干了什么。你在左边写的：

```c
printf("Hello!\n");
```

在电脑看来是天书。**编译器（Compiler）**把整份代码从头到尾读一遍，做三件事：

1. **查语法**：每个词拼对没有？分号漏没漏？括号配对没有？——发现就报错，**拒绝继续**
2. **翻译**：把人类可读的 C 代码翻译成芯片能懂的机器指令（一串 0 和 1）
3. **产出**：翻译结果存成一个文件，交给运行

所以"编译报错"的本质是：**翻译官在翻译前检查你的句子，发现语法不合规矩，罢工了**。报错信息永远指向第一个出错的位置——从第一条报错开始修，往往修一条、后面的报错跟着消失一大半（后面的报错经常是第一条的连锁反应）。

### 报错信息快速翻译表（见到就对照）

| 报错关键词 | 人话 | 常见原因 |
| --- | --- | --- |
| `expected ';'` | 这里少个分号 | 上一行结尾漏了 `;` |
| `expected '}'` | 这里少个右花括号 | `{` 和 `}` 没配对，少了半个 |
| `expected declaration` | 这里出现了意外的代码 | 多写了 `}`，把 main 提前关掉了 |
| `undeclared identifier 'xxx'` | xxx 没声明过 | 变量名拼错了；或变量用在了声明之前 |
| `implicit declaration of function` | 这个函数没见过 | 函数名拼错；或忘了 `#include` 对应头文件 |
| `warning: unused variable` | 定义了但没用过（只是警告） | 一般是忘写了使用它的代码 |

:::tip[本页的阅读方法]
每个例子都有三部分：**代码**（整段复制进在线编译器）、**输出**（运行后应该看到的）、**"试着改一改"**（按提示改代码再运行，体会变化）。改坏了不要紧，编译器报错就照着改回来——**报错是免费的家庭教师，不是失败**。

另外给自己定个规矩：**每个例子都不是"看完"，而是"抄一遍、跑一遍、改一遍"**。三遍下来，一个概念才真正长在你手上。全页 20 多个例子，就是 20 多次肌肉记忆训练。
:::

## 1. 逐行拆解：这七行到底在干嘛

```c
#include <stdio.h>              // ①

int main(void) {                // ②
    printf("Hello!\n");         // ③
    return 0;                   // ④
}                               // ⑤
```

一行一行抠：

| 行 | 在干什么 |
| --- | --- |
| ① `#include <stdio.h>` | "我要借用标准输入输出工具箱"（stdio = Standard Input Output）。`printf` 这个工具就装在这个箱子里，不借用就报 `implicit declaration`。以 `#` 开头的行叫**预处理指令**——它们不是 C 语句，是编译前给"装配工"的指示（第 13 节细讲）。现在当固定开头背下来 |
| ② `int main(void)` | 程序的**入口**。任何 C 程序都从 main 的第一行开始执行，main 结束程序就结束。拆开读：`int` 表示这个函数结束时"交还一个整数"（就是 ④ 里那个 0，约定 0 = 正常结束）；`main` 是全 C 世界唯一被强制规定的函数名；`(void)` 表示"它不收任何参数" |
| ③ `printf("Hello!\n");` | 往屏幕打印文字（f 是 format 的缩写——它能按格式打印，马上见分晓）。`\n` 是"换行"的暗号。**行尾的分号 `;` 不能漏**，它是每句话的句号 |
| ④ `return 0;` | main 结束，交还 0（"我正常跑完了"）。电脑里的调用者（操作系统）会看这个值判断程序成败 |
| ⑤ `}` | main 的范围到此为止。`{` 和 `}` 必须成对，像左右括号 |

**初学期的两个固定件**：`#include <stdio.h>` 和 `int main(void) { ... return 0; }`。以后所有例子都在这两个固定件中间填肉，你会逐渐理解它们，现在先照抄。

ESP32 上的程序没有 `main`，入口函数叫 `app_main`，但那是唯一区别，语法完全一样——你在这页练的所有本事直接迁移过去。

### `\n` 是什么：暗号字符

反斜杠 `\` 在 C 字符串里是"转义"暗号——`\"` 后面跟的字符有特殊含义：

| 写法 | 意思 |
| --- | --- |
| `\n` | 换行（newline） |
| `\t` | 制表符（对齐用） |
| `\\` | 想打印反斜杠本身 |
| `\"` | 想在字符串里打印双引号本身 |

验证一下：

```c
#include <stdio.h>

int main(void) {
    printf("第一行\n");
    printf("第二行\n");
    printf("名字\t分数\n");
    printf("小明\t95\n");
    printf("他说：\"你好！\"\n");
    return 0;
}
```

输出：

```text
第一行
第二行
名字	分数
小明	95
他说："你好！"
```

**试着改一改**：把 `\n` 全删掉再运行——所有字挤成一行。这就是 `\n` 存在的意义：`printf` 只管把字符吐出去，**吐到哪、换不换行全靠你写没写 `\n`**。

### 第一次报错练习（故意弄坏它）

报错是学习资源，现在主动制造三次：

**实验一**：把分号删掉再运行：

```c
printf("Hello!\n")      // 少了分号
```

编译器会报类似 `expected ';'` 的错——翻译是"这里少个分号"。**看到 `expected xxx` 的报错，意思就是"这里少了 xxx"**。

**实验二**：把 `"Hello!\n"` 的右引号删掉。报错类似 `missing terminating " character`——"字符串没有收尾的引号"。字符串必须被一对引号完整包住。

**实验三**：把 `printf` 拼成 `print`。报错类似 `implicit declaration of function 'print'`——"我不认识 print 这个函数"。**函数名错一个字母都不行**。
