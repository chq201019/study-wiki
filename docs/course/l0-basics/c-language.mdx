# C 语言核心（分页版）

这一篇原本是一整页 1400 多行，太长不好读。现在按主题拆成 9 页，
每页都在 150~300 行之间，**一次读一页**，读完点"下一页"。

每页仍然保持原来的风格：完整可运行的代码、预期输出、逐行追踪，以及"试着改一改"实验。

## 怎么用这套材料

1. **顺序读**。后面的页假设你已经看过前面的
2. **每段代码都自己敲一遍**，别看一眼就当会了
3. **改一改再跑**。改参数、改逻辑，看输出怎么变——这比读十遍有用
4. 卡住了先看同页的「常见错误」，再去查 `man`
