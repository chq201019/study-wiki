# 02 变量与类型

## 2. 变量：贴了标签的盒子

程序要干活就得记住数据。"记"靠**变量（Variable）**——把变量想成一个**盒子**：

- 盒子上贴着标签（变量名）
- 盒子有固定规格（类型），决定它能装什么样的数
- 盒子里装着此刻的值，**随时可以替换**

```c
#include <stdio.h>

int main(void) {
    int temperature = 25;            // 造一个整数盒子，贴标签 temperature，装入 25
    printf("%d\n", temperature);     // 打印盒子里现在的值

    temperature = 30;                // 换成 30（原来的 25 没了）
    printf("%d\n", temperature);

    temperature = temperature + 1;   // 右边先算出 31，再装回盒子
    printf("%d\n", temperature);

    return 0;
}
```

输出：

```text
25
30
31
```

逐行看清楚发生了什么：

**`int temperature = 25;` 这一句实际做了两件事**：

1. **声明（Declaration）**：`int temperature` —— 找内存要一个整数大小的盒子，贴上标签 temperature。从此程序里出现 `temperature` 就指这个盒子
2. **赋值（Assignment）**：`= 25` —— 把 25 装进盒子。声明时的第一次赋值也叫**初始化（Initialization）**

后面两行 `temperature = 30;` 是**纯赋值**——盒子早就造好了，只是换里面的东西。所以**声明一个变量只能一次，赋值可以无限次**：

```c
int x = 1;      // ✓ 声明 + 初始化
x = 2;          // ✓ 纯赋值
int x = 3;      // ✗ 编译报错：重复声明同名变量
```

**`temperature = temperature + 1;` 这行最值得盯**。它不是数学等式（数学上 x = x + 1 无解）！C 的 `=` 是"装进去"的动作，执行顺序严格分两步：

1. 先算**右边**：取出 temperature 现在的值（30），加 1，得 31
2. 再把 31 **装回**左边的盒子

"取出 → 计算 → 装回"，以后你会看到 `count++`、`sum += x` 都是它的简写（第 3 节）。

**声明之后必须初始化再用**。跑跑这个：

```c
#include <stdio.h>

int main(void) {
    int x;                    // 声明了，但没装东西
    printf("%d\n", x);        // 打印出来的是什么？
    return 0;
}
```

输出**不确定**——可能是 0，可能是 `32767`，可能是任何数。因为盒子虽然造了，里面是上一个程序留下的垃圾。**"用了未初始化的变量"是嵌入式事故常客**：在电脑上恰好是 0 能跑，换到板子上就出鬼。规矩：**声明变量的同一行就初始化**，拿不准就先给 0。

### 变量名的规矩和品味

规矩（编译器强制）：

- 只能由字母、数字、下划线组成；**不能以数字开头**（`count2` 可以，`2count` 不行）
- 区分大小写：`count`、`Count`、`COUNT` 是**三个**不同的变量
- 不能用 C 的保留字（`int`、`if`、`for`、`return`……）当名字

品味（让人看得懂）：

```c
int a;                    // ✗ 三天后你自己都不知道 a 是什么
int t;                    // ✗ t 是温度还是时间？
int temperature_c;        // ✓ 一眼看懂：温度，摄氏度
int retry_count;          // ✓ 重试次数
```

ESP-IDF 的惯例（后面所有代码都这样，现在就养成）：**变量全小写加下划线**（`sample_count`），**常量全大写**（`MAX_RETRY`），**类型名带 `_t` 结尾**（`sensor_data_t`），**全局变量加 `g_` 前缀**（`g_is_connected`）。跟着惯例写，别人（和三个月后的你）才读得懂。

### 一行多个变量与作用域初识

```c
int a = 1, b = 2, c = 3;      // 同类型可以一行声明多个，逗号隔开
```

还有一个重要事实现在埋下伏笔：**变量只在它所在的 `{ }` 里活着**。

```c
#include <stdio.h>

int main(void) {
    if (1) {
        int inner = 5;          // inner 造在这个花括号里
        printf("里面 %d\n", inner);
    }
    // printf("%d\n", inner);   // ✗ 打开注释就报错：inner 已经死了
    return 0;
}
```

**花括号就是变量的寿命边界**——出了花括号，盒子自动销毁。这个概念叫**作用域（Scope）**，第 5 节函数那里还会回来细讲。

### 试着改一改

1. 把 `temperature = temperature + 1;` 改成 `temperature = temperature * 2 + 10;`——从 30 出发输出会是多少？（70，先算右边再装回）
2. 在最上面加一行 `temperature = 100;`——会报错吗？（不会，`temperature` 在这行之前已经声明过了，之后随便改）
3. 把 `%d` 改成 `%f` 再运行——输出变成 `0.000000` 之类的鬼东西。**占位坑和数据类型必须配套**，下一节细讲
4. 声明一个变量 `int score;` 不初始化，运行三次看输出是否一样——体会"垃圾值"的随机性

## 2.1 类型：盒子有不同的规格

世界上的数据差别很大：开关状态只需 0/1，温度有小数点，毫秒时间戳能涨到几十亿。C 语言用**类型（Type）**规定盒子的大小和解读方式。

### 一个类型一个性格，逐个认识

**int：整数**

```c
int age = 20;
int minus = -5;          // 负数直接写
```

在 ESP32（以及绝大多数现代平台）上占 4 个字节，能装约 ±21 亿的整数。**没有小数点**——见 3 节的除法陷阱。

**float / double：小数**

```c
float temp = 25.5f;      // 注意尾巴的 f：告诉编译器"这是 float 小数"
double price = 999.99;   // double 默认，不加 f
```

`float` 占 4 字节、约 7 位有效数字；`double` 占 8 字节、约 15 位。日常传感数据 float 够用。

**char：一个字符**

```c
char grade = 'A';        // 单引号装"一个字符"
char first_letter = 'E';
```

**单引号装一个字符，双引号装一串文字**——`'A'` 是字符，`"A"` 是字符串，两者类型不同，别混。

**bool：真与假**

```c
bool ok = true;          // true=1，false=0
bool is_raining = false;
```

条件判断的基础（第 4 节大量使用）。

### 完整体验程序

```c
#include <stdio.h>

int main(void) {
    int    count   = 3;
    float  temp    = 25.5f;
    double precise = 0.1 + 0.2;
    char   grade   = 'A';
    bool   ok      = true;

    printf("整数    %d\n", count);
    printf("小数    %f\n", temp);           // %f 对应 float/double
    printf("保留两位 %.2f\n", temp);        // %.2f = 保留 2 位小数
    printf("精确    %.10f\n", precise);      // %.10f = 保留 10 位小数
    printf("字符    %c（编号 %d）\n", grade, grade);   // %c 按字符打，%d 按编号打
    printf("真假    %d\n", ok);              // bool 打印出来就是 1 或 0

    return 0;
}
```

输出：

```text
整数    3
小数    25.500000
保留两位 25.50
精确    0.3000000000
字符    A（编号 65）
真假    1
```

逐个看点门道：

- **`%f` 默认打 6 位小数**。想要 `25.5` 打成 `25.50` 用 `%.2f`（点号后的数字 = 保留几位）
- **`%.10f` 那行暴露了小数的真面目**：`0.1 + 0.2` 居然不是 0.3！因为 float/double 用二进制存小数，很多小数存不精确（就像十进制写不尽 1/3 = 0.333...）。**小数只能"约等于"**——判断两个小数相等要格外小心，工程上永远用"两数之差小于一个很小的值"来判断
- **字符 `A` 的编号是 65**：`char` 本质是个 1 字节小整数，`'A'` 只是"编号 65 的字符"的写法。试试 `char c = 'A' + 1;` 再 `%c` 打印——是 `'B'`！字符能做加法，因为它的本质就是数。这就是"一切皆数"的又一例证
- **bool 打出来是 1**：C 里真就是 1、假就是 0，而且**任何非 0 值当条件都算真**（`if (5)` 成立、`if (0)` 不成立——记住这条，14 节讲 esp_err_t 时会考）

### 占位坑对照表（记熟，天天用）

| 坑 | 配什么类型 | 例 |
| --- | --- | --- |
| `%d` | int、bool（打 1/0）、char（打编号） | `printf("%d", 3);` |
| `%f` / `%.2f` | float、double | `printf("%.2f", 3.14);` |
| `%c` | char（按字符打） | `printf("%c", 'A');` |
| `%s` | 字符串（第 7 节） | `printf("%s", "hi");` |
| `%u` | unsigned 类型（下一节） | `printf("%u", 42u);` |
| `%x` / `%X` | 按十六进制打 | `printf("%x", 255);` → ff |
| `%p` | 指针（地址） | 第 8 节 |
| `%%` | 想打印 % 本身 | `printf("100%%");` |

:::caution[占位坑与类型不匹配 = 未定义行为]
用 `%d` 打 float、用 `%f` 打 int，编译器可能只给个警告照常编译，但**输出是垃圾值**。而且"垃圾值输出"还是最好的情况——编译器有权对这类错误做任何事。**打印变量前，核对类型和坑**。
:::

### 试着改一改

1. 打印 `'z'` 的编号，再打印 `'A'` 和 `'a'` 的编号——差多少？（大写 A 是 65，小写 a 是 97，差 32。字符编号表叫 ASCII，查一下它，你会发现整个字母表 + 数字 + 符号都被编了号）
2. 把 `%.10f` 改成 `%.2f`，输出变成 `0.30`——看起来"正确"了，**但底层数据仍然不精确**，只是打印时四舍五入骗过你的眼睛
3. 写一行 `printf("%d", 1 + 2 * 3);`——输出 7 不是 9，先乘除后加减和数学一样（优先级详见第 3 节）
