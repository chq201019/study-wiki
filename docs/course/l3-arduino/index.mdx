## 核心结论

```mermaid
flowchart TD
  A[我要做个东西] --> B{时间 < 3 天 或 只是验证想法?}
  B -->|是| C[Arduino / Mixly]
  B -->|否| D{需要 多任务/深度睡眠/音频/AI/LVGL/双核?}
  D -->|是| E[ESP-IDF]
  D -->|否| F[混合：IDF 主工程 + arduino component]
```

一句话：Arduino 的边界不在"能不能做"，而在"要做对的时候有多痛苦"。
