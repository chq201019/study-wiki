# QS-4 GPIO 与按键

**时长 60 分钟 · 产出：按键控制灯**

:::tip[串口波特率]
所有示例程序里的串口都初始化成 9600（米思齐的默认值）。
在米思齐里点开串口窗口，把右下角的波特率也选成 `9600`，两边不一致串口就是乱码。
:::

## 先分清：「初始化」和「程序区」

米思齐的程序区天然分两块，别放错位置：

| 位置 | 对应代码 | 跑几次 | 放什么 |
| --- | --- | --- | --- |
| **初始化**（「控制」分类） | `setup()` | 只跑一次 | 设置类：管脚模式、屏幕初始化、串口参数 |
| **程序区（初始化以外）** | `loop()` | 一直循环 | 主逻辑：读按键、控灯、打印 |

程序区里直接摆的积木默认就在主循环里反复执行，**不需要再包一层循环积木**。

放错的典型症状：把「数字输出」放进初始化里，灯只动一下就没反应——因为它只执行了一次。另外主循环是个死循环，里面任何一块卡住（比如延时太长），整个程序就失去响应。

需要"按条件转圈"的循环（比如等松手、倒计数），再拖「控制」分类里的**「重复 执行（满足条件 …）」**积木——它是循环里的循环，见下面消抖一节的用法。

## GPIO 就两种用法

**控灯、蜂鸣器、继电器** = 「数字输出 管脚# X 设为 高/低」；**读按键** = 「数字输入 管脚# X」。

按键要配**上拉**：把「管脚模式 … 设为 上拉输入」（「输入/输出」分类，往下翻才找得到）放进「初始化」。

:::tip[上拉是什么、为什么要它]
按下按键 = 引脚接地 = 读出 LOW；不按下时内部上拉把引脚拉到 3.3V = HIGH。
好处：① 一根线就够了，不用再接电源；② 引脚不会悬空读到乱跳的随机值。
所以逻辑是**反的**：按下是 LOW。
:::

## 完整实战：按键控制灯（积木版）

用板载 BOOT 键（GPIO0，板上自带电阻，什么都不用接）：

```text
初始化                                ← 「控制」分类，只跑一次
  └─ Serial 打印 自动换行 "按键控制灯"

程序区（初始化以外）：
如果 <数字输入 管脚# 0 的值 = 0> 执行    ← 按下是 0
│    └─ 数字输出 管脚# 4 设为 高
否则
│    └─ 数字输出 管脚# 4 设为 低
延时 20 毫秒
```

| 积木 | 在哪个分类 | 要改的参数 |
| --- | --- | --- |
| 数字输入 管脚# | 输入/输出 | 选 `0`（就是板载 BOOT 键，按下读到 0） |
| 数字输出 管脚# 设为 | 输入/输出 | 选 `4`，高/低对应亮/灭 |
| 如果/否则 | 控制 | 把比较条件咬进菱形口里；「否则」点积木上的小齿轮加出来 |
| 延时 | 控制 | 20 毫秒 |

想接**外接按键**：GPIO5 → 按键 → GND，「数字输入」管脚改成 5，再在「初始化」里加一块「管脚模式 5 设为 上拉输入」。

## 消抖：按一下跳好几格怎么办

机械按键按下/松开的瞬间会反复通断几十次（持续 1～10ms），不做处理就"按一下跳好几格"。会用就行级的最简单办法：**在"按下"分支的末尾，等它松手再往下走**——「重复 执行（满足条件：数字输入 = 0）」里面只放一块「延时 5 毫秒」，松手才出循环。

要"按一下切换一次"（记状态 + 严格消抖），用积木拼会很绕，这种时候才值得写代码，去 [L4 · GPIO](../course/l4-peripherals/gpio) 看 `millis()` 消抖的标准写法。

## 中断：知道有这回事就行

循环里"盯着看"响应再快也有延时；中断是"一按立刻触发"。积木里就有——「输入/输出」往下翻的**「硬件中断 管脚# … 模式 上升/下降 执行…」**，做按键计数这种够用：

```text
硬件中断 管脚# 5 模式 下降 执行
  └─ 把 次数 增加 1        ← 「变量」分类；中断里只放最轻的事
```

写代码时的中断规则（`IRAM_ATTR`、`volatile` 这些）是进阶内容，去 [L4 · GPIO](../course/l4-peripherals/gpio)。

## 接线

积木版用板载 BOOT 键，什么都不用接。灯就用 GPIO4 外接那颗 LED——板载 RGB 灯是 WS2812，「数字输出」积木点不亮（要用 RGB灯 积木，见 [QS-1](./mixly-setup)）。接外设的话：

| 元件 | 接法 |
| --- | --- |
| LED | GPIO4 → 220Ω 电阻 → LED 阳极；LED 阴极 → GND |
| 外接按键 | GPIO5 → 按键 → GND（记得在初始化里设上拉） |
| 面包板 | 断电后再接线；先在板上确认丝印数字对应 GPIO 号 |

## 验证

- [ ] 接好 GPIO4 的 LED 后上传：按住 BOOT 键灯亮，松开灭，串口跟着变
- [ ] 快速连按，不会疯狂乱闪（延时 + 等松手生效）

## 常见坑

| 现象 | 原因 |
| --- | --- |
| 灯完全不亮 | LED 极性反了（长脚是阳极）；或 GPIO 接错排针 |
| 按键读数乱跳 | 没设上拉（初始化里加「管脚模式 … 上拉输入」）；或按键另一端没接 GND |
| 按一下跳很多格 | 没做消抖 |
| 用 GPIO35/36/37 后程序异常 | 这三个脚被 Flash/PSRAM 占用，换脚 |
