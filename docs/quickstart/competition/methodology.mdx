# 从规划到执行

核心产出物是一张纸（或一个 md 文件），不是代码。大多数队伍失败在没定方案就开工。

## 第一阶段：规划——把赛题变成清单

### 逐条抄需求，不要总结

把赛题文件里每一条要求原样抄成清单，每条后面标上"怎么验证我做没做到"：

```markdown
- [ ] 设备实时采集温湿度，采样间隔 ≤ 2s
- [ ] 数据通过 WiFi 上传到指定服务器，格式为 JSON
- [ ] 网页端能实时显示，超过阈值时报警
- [ ] 支持手机远程控制开关
- [ ] 断网后恢复网络能自动重连并续传数据
- [ ] 整机工作功耗 < 50mA
```

这一步不能省。赛题文件里 60% 的分数藏在那些不起眼的细节里（比如"异常情况下应能恢复"这种兜底条款）。

### 标出可量化评分项

把清单分成三类，决定投入比例：

| 类型 | 例子 | 投入 |
| --- | --- | --- |
| **硬性门槛** | 不满足直接不参赛（尺寸限制、必须联网） | 100% 满足 |
| **可量化评分** | 精度 ±1℃ 以内、响应 < 200ms | 重点优化 |
| **主观分** | 外观、完成度、演示效果 | 最后 20% 时间 |

## 第二阶段：选型——定硬件方案

对着需求清单逐条问"这需要什么"：

| 需求 | 硬件 | 说明 |
| --- | --- | --- |
| 温湿度采集 | 传感器 | 见下面的选型原则 |
| 联网 | 板载 | ESP32-S3 自带 WiFi |
| 显示 | 0.96" OLED | I2C 接口，积木现成 |
| 数据留存 | SD 卡模块 | 写代码才用得上，按需 |
| 报警 | 有源蜂鸣器 + LED | 最便宜的评分项 |

:::tip[传感器选型：模拟和 I2C 怎么挑]
别默认"数字模块 = 高级 = 更好"，看场景：

- **模拟输出（光敏、热敏、电位器）**：几块积木就能读，没有库、地址、上拉这些坑，现场不容易出幺蛾子。精度要求不高时（绝大多数赛题够用）反而更稳。
- **I2C 数字模块（SHT30、BME280 这类）**：参数好、接线少，但依赖库版本、设备地址、上拉电阻，现场排错成本高。

评分点只看数据对不对、稳不稳。拿不准就用模拟方案先保底，I2C 模块赛前测过确实稳再换。
:::

其他选型原则：

1. **传感器备两份**，实验室事故率高
2. **所有模块提前一天通电测一遍**，不要在比赛当天第一次碰
3. **供电算一遍峰值**，舵机 + 电机 + WiFi 一起工作时的电流是平时的好几倍

选型定了就画一张系统框图——有哪些模块、怎么连、数据怎么流。框图定了，代码结构也就定了。

## 第三阶段：执行——排期、风险、验证

### 倒排时间表

```markdown
| 时间 | 任务 | 完成标志 |
| --- | --- | --- |
| D-3 晚 | 硬件全部通电自测 | 每个模块单独能用 |
| D-3 | 采集链路打通 | 串口稳定打印数据 |
| D-2 | 本地存储 + 显示 | SD 有文件，OLED 有数据 |
| D-2 晚 | 联网打通 | 能 ping 通服务器 |
| D-1 | 云端打通 | 网页看到实时数据 |
| D-1 晚 | 控制回路 | 手机能控制开关 |
| **D-1 晚** | **冻结功能，只做调试** | —— |
```

关键是那个"冻结功能"的时刻。最后一天改代码基本等于自杀。

### 先打通最险的链路

不要从最简单的部分开始，**先做最可能失败的那一条**，失败了就还有时间换方案。按经验，风险排序通常是：

1. 现场网络接入（不知道现场路由器密码、有没有独立 SSID）→ 立刻就去确认
2. 云端平台对接（平台是不是能用、账号是不是能注册）
3. 传感器精度（能不能满足评分精度要求）
4. 功耗指标（如果要算功耗）

### 工程习惯（两条路线都适用）

| 习惯 | 原因 |
| --- | --- |
| 每个功能都有独立的串口开关 | 演示哪段开哪段，出问题能立刻跳过 |
| 所有配置走参数而非硬编码 | 现场网络不一样 |
| 加一个"演示模式" | 自动循环播放全部功能，不依赖操作者 |
| 提前录一段视频 | 万一硬件挂了，至少有视频 |

## 两条路线的执行差异

### 现场制作版：赛前完整跑通一遍，现场只做复现

- **赛前把整机连所有评分项完整做一遍**——这不是"预演"，这一遍的产物就是参赛作品
- 代码用验证过的版本，现场**只改配置（WiFi 名密码、服务器地址），不改逻辑**
- D 日上午的唯一任务：用现场真实网络完整跑一遍，逐条对照需求清单
- 备一份源码 + 一份编译好的 `.bin`，换机子直接烧

### 提前提交版：交付物就是作品本身

- 时间表反过来排：**先定提交截止日，往前留出一周做验证和材料**，不要卡着截止日写文档
- 评委看不到你操作，**可复现性就是分数**：说明文档写到"照着就能跑"，视频拍清楚每个评分项
- 提交前按 [交付自检清单](./checklist) 的"提前提交版"部分逐项打勾
