# 赛事实战

## 先分清你参加的是哪种比赛

| | **现场制作版** | **提前提交版** |
| --- | --- | --- |
| 形式 | 比赛现场搭硬件、调程序、答辩 | 赛前做完，提交作品 + 材料评审 |
| 核心策略 | **赛前把整机完整做一遍验证**，现场是复现和适配 | **提前留出验证余量**，重心放在交付物质量 |
| 代码 | 直接用赛前验证过的版本，现场只改配置不改逻辑 | 提交前冻结，保证评委拿到就能跑 |
| 最大风险 | 现场网络/供电/环境跟赛前不一样 | 材料不全、评委复现失败 |

不管哪条路线，前面的「规划 → 选型 → 执行」流程都一样，差别在执行阶段的重点。详见 [从规划到执行](./methodology)。
