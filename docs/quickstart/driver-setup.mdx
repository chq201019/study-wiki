# QS-0.5 装驱动，让电脑认出板子

**时长 15 分钟 · 产出：设备管理器里出现一个 COM 口，米思齐能选到板子**

## 为什么还要装驱动

板子上的 Type-C 口**不是直接连到芯片的**，中间隔了一颗 **USB 转串口芯片**。Windows 不认识这颗芯片，就不会给它分配 COM 口；没有 COM 口，米思齐根本找不到板子，点上传只会报错。

Windows 10/11 自带一部分驱动，但**不是全部**。所以：

> **插上板子看不到新的 COM 口，第一大原因是缺驱动，第二大原因才是线坏。**

很多人卡在这里，误以为是板子或线的毛病，换了一堆线也没用。

## 第一步：看电脑认出了什么

把数据线插到板子**丝印 `COM`** 那个 Type-C 口（别插 `USB` 那个，两个口怎么分见 [QS-0](./board)），然后打开设备管理器：

- **Win10 / Win11**：右键左下角「开始」→ **设备管理器**
- 或者按 `Win + X` → 设备管理器

展开 **端口 (COM 和 LPT)** 这一项，对照下表：

| 你看到的 | 意思 | 怎么办 |
| --- | --- | --- |
| `USB-SERIAL CH340 (COM3)` 这一类 | CH340 / CH343 驱动已就绪 | ✅ 跳到第二步验证 |
| `Silicon Labs CP210x ... (COM4)` | CP210x 驱动已就绪 | ✅ 跳到第二步验证 |
| **其他设备** 下有带黄色感叹号的 `USB2.0-Serial`、`USB Serial` 或「未知设备」 | **缺驱动** | 按下面装驱动 |
| 端口里什么都没有，也没有黄色感叹号 | 插错口，或线只能充电 | 换 `COM` 口、换数据线；还是没有就回 [QS-0](./board) 排查 |

:::tip[看不到「端口 (COM 和 LPT)」这一项]
设备管理器菜单 **查看 → 显示隐藏的设备**，还是没有就说明当前电脑没认到任何串口设备，按上表最后一行排查。
:::

## 第二步：缺驱动就装对应那一颗

**芯片是哪一种，看设备管理器里显示的名字，不要靠猜板子批次。**

### CH340 / CH343（国产，最常见）

去沁恒官网下载 [CH341SER.EXE](https://www.wch.cn/downloads/CH341SER_EXE.html)，双击运行，点「安装」，等它提示成功。

> CH340 和 CH341 用的是同一个驱动包，**名字看着不对是正常的**。

### CP210x（Silicon Labs）

去 [CP210x VCP 驱动页](https://www.silabs.com/software-and-tools/usb-to-uart-bridge-vcp-drivers) 下载 Windows 版，解压后运行里面的安装程序（或右键 `silabser.inf` → 安装）。

:::info[两个都装也不冲突]
拿不准是哪种芯片时，**两个驱动都装一遍最快**。它们互不干扰，也不会影响原本正常的那个口。
:::

## 第三步：验证

装完必须**拔掉板子重新插上**（驱动只在插入时加载），再看设备管理器：

- **端口 (COM 和 LPT)** 下面出现 `… (COMx)`，x 是数字 → 成功了
- 打开米思齐，右上角的 COM 下拉框里也能看到这个 `COMx`（怎么选见 [QS-1](./mixly-setup)）

## 常见坑

| 现象 | 原因 | 怎么解决 |
| --- | --- | --- |
| 装驱动提示"需要管理员权限" | 学校机房账号受限 | 找老师用管理员账号装；或换一台自己的电脑 |
| 装完还是黄色感叹号 | 没拔插，或装成了另一种芯片的驱动 | 拔插一次；两个驱动都装上 |
| 安装程序被杀毒软件拦下 | 安全软件误报 | 临时关掉安全软件再装，装完再打开 |
| 端口出现了，米思齐下拉框里却没有 | 米思齐要重启才刷新列表 | 关掉米思齐重开 |
| 同一个板子冒出两个 COM 口 | 插到 `USB`（OTG）口了 | 只插丝印 `COM` 的口，见 [QS-0](./board) |
| COM 口时有时无 | 线接触不良，或 USB 供电不足 | 换线，直插电脑本体接口，别用扩展坞 |

## 检查清单

- [ ] 设备管理器 **端口 (COM 和 LPT)** 下能看到 `… (COMx)`
- [ ] 没有带黄色感叹号的未知设备
- [ ] 米思齐的 COM 下拉框里能看到同一个 `COMx`
- [ ] 知道 `COM1` 是主板自带的，**不要选它**
- [ ] 板子插到的是丝印 `COM` 的口，不是 `USB` 口
