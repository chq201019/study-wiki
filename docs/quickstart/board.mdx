# QS-0 开始前必须知道的几件事

**时长 10 分钟 · 不产出作品，但能帮你省掉后面 90% 的"板子坏了"**

这一页不讲芯片有多强，只讲**新手最容易踩、而且踩了会怀疑人生**的几个坑。

## 1. 板子上有两个 USB 口，别搞混

先认一下这块板。正面：金色模块是 ESP32-S3 主控，板上有 RST（复位）、BOOT 两个按键和一颗 RGB 灯，底下两个 Type-C 口；背面丝印印着每个引脚的编号。

![板子正面：主控模块、RST/BOOT 键、RGB 灯、两个 Type-C 口](/img/board-front.jpg)

![板子背面：引脚编号丝印，COM 和 USB 两个口](/img/board-back.jpg)

两个 Type-C 长得一模一样，**看丝印区分**：

| 接口 | 丝印 | 干什么用 | 你要怎么做 |
| --- | --- | --- | --- |
| **USB-UART** | `COM` | 供电、烧录、串口日志 | ✅ **只用这一个** |
| USB OTG | `USB` | 芯片自带的原生 USB | ❌ 平时不用碰 |

插 USB OTG 口时，Windows 有时会冒出**两个** COM 口，导致新手不知道该选哪个。**记住规则：认准丝印 `COM` 的那个口。**

## 2. 这几个引脚绝对不能接东西

侧边排针上印的数字就是引脚号。**接线前先记住这四个：**

| 引脚 | 原因 | 后果 |
| --- | --- | --- |
| **35 / 36 / 37** | 这三个脚被板子上面的存储器**内部占用了** | ⚠️ **最严重**：接东西可能导致程序写不进去、板子变砖 |
| **43 / 44**（丝印 `TX` `RX`） | 这是串口日志口 | 占了就看不到程序打印的内容，调试瞎了 |
| **0**（BOOT 键） | 板子上已经接了一个按键 | 你再在上面接模块，复位瞬间可能把板子带进下载模式 |
| **19 / 20** | 原生 USB 用 | 插 USB OTG 口时会被占用 |

:::danger[35 / 36 / 37 千万别用]
这是新手最容易犯、后果又最严重的错误——因为**不接任何东西反而没事**，一旦你按"中间那排应该都能用"的直觉接上去，板子可能直接变砖。

开发板附带的排针通常已经把 35/36/37 跳过了，但你**自己用杜邦线接**的时候，务必避开。拿不准就只用 **GPIO 1～18、21 和 GPIO 38～42、45～48**（GPIO 0、19、20、43、44 也别接，原因见上面那张表）。
:::

完整的引脚能不能用、能干什么，见[引脚速查](../reference/pinout)。

## 3. 传不上程序？手动进下载模式

正常情况下点一下上传就行。但如果反复报 `Failed to connect`，手动进一次下载模式：

```mermaid
flowchart LR
  A[按住 BOOT 不松手] --> B[短按一下 RST]
  B --> C[松开 BOOT]
  C --> D[板子进入下载模式<br/>可以传程序了]
```

就三步，记住口诀：**按住 BOOT，点一下 RST，松手**。

进下载模式后串口助手会显示芯片在等待上传，这时候立刻点 IDE 的上传按钮。

## 4. 供电：十次「莫名其妙重启」有八次是这个

| 现象 | 原因 |
| --- | --- |
| 一连 WiFi 就重启 / 一开电机就重启 | **电流不够**，板子瞬间"饿死了" |
| 传到一半断开 | 同上 |
| 换了台电脑就正常 | 那台电脑的 USB 口供电能力弱 |

**三个应对办法**：

1. **换一根粗一点的、能传数据的数据线**。很多充电线只有两根线，通不了数据，也带不动电流
2. **别插在 USB 集线器或扩展坞上**，直插电脑本体接口
3. **电机、舵机必须单独供电**（5V/2A 以上），并且和开发板**共地**（把两边的 GND 接一起）

:::tip[怎么判断是不是供电问题]
把程序里的联网部分注释掉，只跑个点灯循环。如果不重启了，一开 WiFi 就重启 → 基本确定是供电，换线换电源。
:::

## 5. 确认板子没坏

插上 USB-UART 口，点米思齐**左上角的串口按钮**选好 COM 口，然后按一下 RST。

:::warning[这一步的波特率是 115200，不是 9600]
下面这两行是**芯片自己的出厂启动信息**，硬件固定用 115200 输出，跟你的程序无关。

程序一旦跑起来，串口就变成 **9600**（米思齐的默认值）了。

所以：**看板子有没有活着 → 115200；看程序输出 → 9600。**
:::

能看到类似这样的一串字符就说明板子是好的：

```text
ESP-ROM:esp32s3-20210327
rst:0x1 (POWERON_RESET),boot:0x13 (SPI_FAST_FLASH_BOOT)
```

- **看不到任何输出** → 换 USB 口、换线，再不行就按第 3 条手动进下载模式试试
- **输出一堆乱码** → 波特率不对，这一步要 **115200**
- **Windows 设备管理器里根本没有新设备** → 先别急着换线。可能是**缺 USB 转串口驱动**，也可能是线的问题。按 [QS-0.5](./driver-setup) 一步步排，那里有判断表
